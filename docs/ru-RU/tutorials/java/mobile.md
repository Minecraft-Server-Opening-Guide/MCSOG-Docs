Многие играют в Minecraft только на **телефоне / планшете / консоли** — это **Bedrock Edition**. По умолчанию игроки Bedrock **не могут зайти на сервер Java Edition** — протоколы двух версий полностью разные.

**Geyser** открывает этот путь и позволяет мобильным игрокам заходить на ваш Java-сервер.

## 1. Geyser работает в одну сторону (это нужно понять сразу)

Официальный FAQ Geyser говорит прямо:

> **Можно ли через Geyser пустить игроков Java на мой сервер Bedrock?**
> **Нет. Это инструмент преобразования, который пускает игроков Bedrock на сервер Java, но не наоборот.**

Поэтому:

| Направление | Возможно ли | Решение |
| --- | --- | --- |
| Игроки Bedrock → **сервер Java** | Возможно | **Geyser** (+ Floodgate) |
| Игроки Java → сервер Bedrock | Официального решения нет | Не существует |

**Geyser ставится на стороне сервера Java**; на официальный сервер Bedrock (BDS) **Geyser поставить нельзя**.

## 2. Куда и как ставить

У Geyser есть несколько форм — выбирайте по типу вашего Java-сервера:

- **В виде плагина**: Spigot / Paper / Purpur и другие плагинные ядра (самое частое)
- **В виде прокси**: Velocity / BungeeCord (при связке серверов ставится на прокси)
- **В виде мода**: Fabric / NeoForge
- **Отдельная форма (standalone)**: не зависит от перечисленных платформ, работает самостоятельно

После установки перезапустите сервер — Geyser создаст свой конфигурационный файл.

## 3. Главное: откройте UDP-порт

Это самый часто пропускаемый шаг:

| Порт | Протокол | Назначение |
| --- | --- | --- |
| `25565` | **TCP** | Подключение игроков Java |
| `19132` | **UDP** | **Подключение игроков Bedrock (слушает Geyser)** |
| `19133` | UDP | Порт Bedrock по умолчанию для IPv6 |

:::warn Открытый только TCP — причина №1, почему мобильные игроки не подключаются
Разрешите **UDP 19132** и в security group облачного сервера, и в системном firewall — **в обоих местах**. Многие открывают только TCP 25565 и потом недоумевают, «почему телефон не подключается».
:::

В «Добавить сервер» мобильный игрок указывает: **адрес = ваш IP или домен, порт = 19132**.

## 4. Floodgate: мобильным игрокам не нужен аккаунт Java

По умолчанию на Java-сервере включена проверка лицензии, а у игроков Bedrock **нет аккаунта Java**, поэтому их не пустят.

**Floodgate** решает именно это: игроки Bedrock **входят напрямую с аккаунтом Xbox**, покупать Java Edition не нужно.

Ключевые моменты:

- Floodgate обычно ставится вместе с Geyser;
- имя игрока Bedrock получает **префикс** (по умолчанию `.`), чтобы отличать их от игроков Java;
- поэтому в **белом списке, банах и командах** учитывайте этот префикс и при необходимости заключайте имя в кавычки;
- можно также использовать привязку аккаунтов Floodgate, чтобы связать аккаунт Bedrock с существующим аккаунтом Java.

## 5. Известные ограничения (предупредите игроков заранее)

- **Ограничения на консолях**: игроки Xbox / PlayStation / Switch **не могут подключиться, просто введя IP**; обычно доступны только **собственный DNS** или **локальная сеть**.
- **Визуальные артефакты на больших расстояниях**: клиент Bedrock 32-битный, Java — 64-битный; при уходе далеко могут появляться странные проблемы с позицией/рендером (в сообществе есть неофициальные обходные решения).
- **Часть плагинов несовместима**: Geyser имитирует клиент Java; подавляющее большинство плагинов работает, но некоторые плагины, глубоко вмешивающиеся в вход/протокол, конфликтуют.
- **Ресурспаки нужно конвертировать**: Bedrock не читает ресурспаки Java; их нужно перевести в формат Bedrock и уже потом использовать с Geyser.
- **Модовые серверы ограничены**: если для входа требуется клиент с модами, Geyser их не передаст («Geyser может войти только туда, куда входит ванильный клиент»).

## 6. Включать ли кроссплатформу

**Стоит включать**: если хотите расширить приток игроков, на сервере есть мобильная аудитория, а геймплей ближе к выживанию/строительству (не чувствителен к точному редстоуну).

**Осторожно**: на **техническом сервере**. Поведение редстоуна в Bedrock и Java изначально различается, кроссплатформенные игроки видят разные механики — это легко вызывает споры.
