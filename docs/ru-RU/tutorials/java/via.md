Игрок не может зайти, ему пишут «несовместимая версия» или «слишком старый клиент» — один из самых частых вопросов при запуске сервера. Причина проста: сервер и клиент говорят на разных версиях одного протокола и не понимают друг друга. Плагин совместимости версий работает переводчиком между ними.

Эта статья объясняет, за какое направление отвечает каждый плагин семейства Via, куда его ставить, кто от кого зависит и чего они не умеют. Предварительные знания — в [Введении в плагины](/tutorials/java/plugins).

## 1. Почему игрок не может зайти

Клиент и сервер Java Edition общаются по бинарному протоколу. Каждая версия игры меняет этот протокол: добавляются новые пакеты, меняется порядок полей, меняется смысл значений. Если версии протокола не совпадают, рукопожатие завершается ошибкой, и игрок обычно видит сообщение о несовпадении версии.

Сервер принимает только клиентов своей версии (и небольшого числа совместимых). Поэтому:

- сервер 1.20.4, игрок с клиентом 1.21: не зайдёт.
- сервер 1.21, игрок с клиентом 1.8: тоже не зайдёт.

Плагин совместимости на стороне сервера принимает пакеты игрока, переводит их в понятную серверу форму, а ответы сервера переводит обратно в версию протокола игрока. **Игроку ничего устанавливать не нужно.**

:::warn Совместимость версий — не универсальное решение
Он переводит протокол, а не геймплей. Чем больше разрыв версий, тем меньше совпадающего и тем заметнее падает качество игры; подробнее в разделе 5.
:::

## 2. За что отвечает каждый из трёх плагинов Via

Via — это семейство; три плагина отвечают за разные направления. Запомните: **«вверх» — пустить более новый клиент, «вниз» — пустить более старый клиент.**

| Плагин | Направление | Назначение | Зависимость |
| --- | --- | --- | --- |
| **ViaVersion** | Совместимость вверх | Пускает клиенты новее сервера | Нет, это ядро |
| **ViaBackwards** | Совместимость вниз | Пускает клиенты старее сервера | Нужен ViaVersion |
| **ViaRewind** | Совместимость с более старыми версиями | Поддерживает клиенты 1.7.x и 1.8.x | Нужен ViaVersion, обычно ставится вместе с ViaBackwards |

Примеры покрытия:

- сервер 1.9.x, только ViaVersion: пускает клиенты от 1.9.x до последней версии.
- сервер 1.21.x, ViaVersion + ViaBackwards: пускает клиенты от 1.9.x до 1.20.x.
- плюс ViaRewind: покрывает 1.7.x и 1.8.x.

Вместе три плагина покрывают примерно весь диапазон от 1.7 до последней версии.

:::note Поддержка Java 8
Новые версии Via больше не поддерживают Java 8, поэтому на очень старых серверах их нельзя использовать напрямую. Если нужно, чтобы работали серверы от 1.8 до 1.21, берите с сайта сборок специальную ветку для Java 8.
:::

:::tip Версии должны совпадать
Ставя ViaVersion и ViaBackwards вместе, выбирайте версии одного периода. После обновления прокси не забудьте обновить и Via до последней версии, иначе получится «совместимость поставлена, а версия всё равно не поддерживается». Даже без прокси рекомендуется обновлять хотя бы раз в месяц.
:::

## 3. Куда ставить: на сервер или на прокси

Via можно ставить на BungeeCord, Velocity и различные серверы Minecraft, но от места установки зависят и эффект, и подводные камни.

| Место установки | Плюсы | Цена |
| --- | --- | --- |
| Бэкенд-сервер | Бэкенд получает **реальную версию клиента** игрока, античит и плагины работы с пакетами работают нормально | На каждый бэкенд нужно ставить свой экземпляр и отдельно поддерживать конфигурацию |
| Прокси | Ставится один раз, перевод выполняется до входа на любой бэкенд | Бэкенд видит **версию прокси**, а не реальную версию клиента игрока |

Если вы используете античит или плагины против ботов, активно обрабатывающие пакеты, установка Via на прокси легко создаёт проблемы совместимости — будьте осторожны. Наоборот, если бэкенд один или нужно, чтобы перевод происходил до выбора сервера, на прокси проще.

:::warn Совместимость версий и модовые ядра
Схема совместимости версий не подходит для модовых серверов. Моды меняют протокол и содержимое реестров, а плагин совместимости не может перевести эти пользовательские части; вместе они дают много проблем.
:::

## 4. Порядок установки и взаимосвязи

Три плагина зависят друг от друга по цепочке:

1. **Сначала ViaVersion**. Это ядро; одного его достаточно для совместимости вверх.
2. **Для совместимости вниз добавьте ViaBackwards**. Он откатывает протокол новой версии к виду, понятному старым.
3. **Для поддержки 1.7 и 1.8 добавьте ViaRewind**. Полную совместимость он даёт вместе с ViaRewind Legacy Support.

По порядку загрузки достаточно, чтобы ViaVersion загружался первым, а ViaBackwards и ViaRewind — после; обычно сервер сам выстраивает это по зависимостям, вмешиваться не нужно. После установки перезапустите сервер и убедитесь в консоли, что все три плагина загрузились.

## 5. Что умеет и чего не умеет

Здесь чаще всего возникает непонимание: **Via переводит протокол, но не добавляет контент.**

| Что увидит игрок | Причина |
| --- | --- |
| Клиент новой версии на старом сервере не может пользоваться функциями новых предметов | У сервера просто нет логики этих предметов; показываются похожие по текстуре предметы старых версий |
| Клиент старой версии не видит текстуры новых предметов | У клиента нет соответствующих моделей и текстур, а официальный плагин это не обрабатывает; для 1.16+ есть обходные пути, но это не официальная возможность |
| Клиенты ниже 1.17 не видят блоки ниже y=0 | Протокол и рендер старых клиентов не поддерживают отрицательную высоту; официально заявлено, что это не будет исправлено |
| После входа странное поведение: отбрасывание назад, рассинхрон действий, смещённый интерфейс | Слишком большой разрыв версий, слишком мало общих понятий |
| Кик с сообщением о слишком большом числе пакетов | Сработал лимит pps с одной из сторон, см. ниже |

Чем больше разрыв версий, тем заметнее падает качество. Если вы не можете обеспечить старым клиентам достойный опыт, не гонитесь за «поддержкой всех версий».

### Частые параметры конфигурации

| Параметр | Назначение |
| --- | --- |
| `serverside-blockconnections` | Если неправильно отображаются текстуры или соединения блоков, попробуйте `true` |
| `max-pps` | Настраивается, когда игроков кикает за избыток пакетов; в ветке Paper можно сразу поставить `-1` и отдельно настроить лимит pps самого Paper |
| `fix-1_13-face-player` | Преобразует пакет скина 1.13 для игроков 1.12; нужен дополнительный кэш |
| `handle-pings-as-inv-acknowledgements` | Для клиентов ниже 1.17 отправляет подтверждение инвентаря вместо ping; помогает совместимости с античитами |
| `replace-adventure` | Параметр ViaRewind: заменять ли частицы 1.9 приближёнными частицами 1.8 и ниже |

:::warn Не отключайте лимит pps полностью
Повышать лимит пакетов нужно, чтобы обычных игроков не выкидывало, но полное отключение даёт злоумышленникам возможность уронить сервер пакетной атакой. Достаточно уровня, «до которого обычный игрок не доходит».
:::

## 6. Отдельная версия: ViaProxy

Если менять само серверное ядро неудобно, есть отдельное решение: **ViaProxy**. Это самостоятельная прокси-программа, позволяющая любому клиенту подключаться к любому серверу без установки плагинов на сервер.

Его покрытие гораздо шире плагинной версии: древние Alpha, Beta и Classic, первоапрельские снапшоты, снапшоты боевых тестов, и даже подключение игроков Bedrock через Geyser. Скачать можно в GitHub Releases ViaVersion и на официальном сайте сборок.

:::note Когда его использовать
Когда нужно пустить современный клиент на сервер десятилетней давности или просто временно проверить совместимость версии, ViaProxy гораздо проще переделки сервера. Но это отдельный процесс: лишний слой пересылки и ещё одно место для обслуживания и диагностики.
:::

## 7. Быстрая диагностика

| Симптом | Что проверить первым |
| --- | --- |
| После установки всё ещё «версия не поддерживается» | Актуальна ли версия Via; обновили ли Via после обновления прокси |
| Часть игроков не заходит, остальные нормально | Не выходят ли версии клиентов этих игроков за покрытие плагина |
| Неправильные текстуры | `serverside-blockconnections`; отсутствие текстур новых версий на старых — ожидаемо |
| Игрока кикает с сообщением о лишних пакетах | `max-pps` и лимит pps Paper |
| Античит ложно срабатывает или ведёт себя странно | Не стоит ли Via на прокси; бэкенд видит версию прокси, а не реальную версию игрока |
| Игроков старых версий сильно отбрасывает ниже y=0 | Известное ограничение, исправляться не будет |
