После запуска сервера в каталоге появляется куча файлов и папок. **Понимание того, что можно трогать, а что нельзя**, — основа всех дальнейших действий (установка плагинов, копирование, миграция).

Ниже — на примере плагинного ядра (Paper / Purpur и подобных).

## 1. Папки

| Папка | Назначение | Можно ли трогать |
| --- | --- | --- |
| `plugins/` | Сюда кладутся плагины | Трогаем часто |
| `world/` | Данные **основного мира** | Только копировать целиком, не править вручную |
| `world_nether/` | Данные Нижнего мира | То же |
| `world_the_end/` | Данные Энда | То же |
| `logs/` | Рабочие логи, по ним ведётся диагностика | Старые можно удалять |
| `crash-reports/` | Отчёты о крашах; при ошибке смотреть в первую очередь | Старые можно удалять |
| `config/` | Конфигурация ядер семейства Paper (например, `paper-world-defaults.yml`) | Копия перед правкой |
| `libraries/` `versions/` `cache/` | Библиотеки зависимостей и кэш, **создаются автоматически** | Не трогать |
| `mods/` | Есть только на **модовых** (Fabric / Forge) и гибридных ядрах | Трогаем часто |

## 2. Ключевые файлы в корне

| Файл | Назначение |
| --- | --- |
| `server.properties` | **Базовая конфигурация сервера** (порты, проверка лицензии, дальность прорисовки…) |
| `eula.txt` | Файл согласия с лицензией; должно быть `eula=true` |
| `<core-name>.jar` | Само серверное ядро |
| `ops.json` | Список OP (администраторов) |
| `whitelist.json` | Белый список |
| `banned-players.json` / `banned-ips.json` | Списки банов |
| `usercache.json` | Кэш имён игроков и UUID |
| `bukkit.yml` / `spigot.yml` | Конфигурация уровня Bukkit / Spigot (есть во всех ядрах семейства Paper) |
| `purpur.yml` / `paper.yml` | Собственная конфигурация соответствующего ядра (появляется только при его использовании) |
| `commands.yml` | Псевдонимы команд и перенаправление перехвата |
| `permissions.yml` | Определения прав по умолчанию |

## 3. Что находится в папке мира

Настоящее сохранение находится внутри `world/`; **копируйте весь `world` целиком**:

| Подкаталог | Содержимое |
| --- | --- |
| `region/` | **Данные чанков** (блоки и рельеф — здесь; самый большой объём) |
| `playerdata/` | Инвентарь, позиция и здоровье игроков |
| `entities/` | Данные сущностей (дроп, мобы, сделки жителей и т. д.) |
| `poi/` | Точки интереса (рабочие места жителей, кровати и т. п.) |
| `data/` | Данные уровня мира (карты, счётные таблицы и т. д.) |
| `datapacks/` | Датапаки |
| `advancements/` `stats/` | Достижения и статистика |

:::warn Не редактируйте файлы мира вручную
Прямое изменение файлов в `region/` с большой вероятностью **повредит сохранение**. Для правки мира используйте плагины вроде `WorldEdit` или сначала остановите сервер.
:::

## 4. Три вывода из этой структуры

1. **Что копировать**: три папки миров `world*` + конфигурацию из `plugins/` + `server.properties`; остальное в основном пересоздаётся автоматически. Подробнее — в «Резервном копировании и восстановлении».
2. **Как переносить**: скопируйте весь каталог сервера на новую машину и установите ту же версию Java; в пути не должно быть не-ASCII символов и пробелов.
3. **Где смотреть диагностику**: сначала `logs/latest.log`, при краше — `crash-reports/`.
