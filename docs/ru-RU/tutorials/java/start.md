Предпосылки готовы: **Java установлена, порт открыт, каталог создан, ядро выбрано и скачано**. Эта статья — о том, как реально запустить сервер.

:::note Новые Forge и NeoForge могут пропустить эту статью
Новые **Forge** и **NeoForge** после установки официальным **инсталлятором** **сами создают в каталоге сервера скрипт запуска** (`run.bat` / `run.sh`). Если вы ими пользуетесь, просто запустите этот скрипт — писать скрипт вручную не нужно.
:::

## 1. Пишем скрипт запуска

Положите скачанное серверное ядро (`.jar`) в каталог развёртывания, например:

```
C:\mcserver\survival\        (в Linux соответствует /opt/mcserver/survival/)
├── paper-1.21.4.jar         ← скачанное ядро
└── (остальные файлы создаются автоматически при первом запуске)
```

### Windows: `start.bat`

1. Создайте в этом каталоге **текстовый документ** и переименуйте его в `start.bat` (расширение с `.txt` на `.bat`).
2. Щёлкните правой кнопкой → откройте в текстовом редакторе, впишите следующее и сохраните:

```bat
@echo off
cd /d "%~dp0"
java -Xms2G -Xmx2G -jar server.jar --nogui
pause
```

Замените `server.jar` на фактическое имя файла (например, `paper-1.21.4.jar`).

- `cd /d "%~dp0"` фиксирует рабочий каталог в папке скрипта, чтобы при двойном щелчке ядро находилось.
- `--nogui` отключает встроенное графическое окно сервера, весь вывод идёт в командную строку (`nogui` — старый псевдоним, они равнозначны).
- `pause` не даёт окну **закрыться сразу** после выхода сервера, чтобы можно было увидеть ошибки; подробнее в «Дополнительно» ниже.

### Linux: `start.sh`

```bash
#!/bin/sh
cd "$(dirname "$0")"
exec java -Xms2G -Xmx2G -jar server.jar --nogui
```

Дайте право на выполнение и запустите:

```bash
chmod +x start.sh
./start.sh
```

## 2. Первый запуск: дождитесь загрузки и примите EULA

**При первом запуске сначала скачиваются необходимые файлы**, в консоли появляется вывод вроде `Downloading mojang_x.x.x.jar` — это нормально, **просто дождитесь окончания загрузки** (если сеть в материковом Китае всё время висит, нужны собственные средства ускорения).

После загрузки сервер **не запустится сразу**, а выдаст:

```
You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

Откройте в текстовом редакторе **автоматически созданный в каталоге `eula.txt`** и замените:

```
eula=false
```

на:

```
eula=true
```

Сохраните и **снова запустите скрипт запуска**. Этим вы подтверждаете, что прочитали и приняли [Minecraft EULA](https://aka.ms/MinecraftEULA).

:::warn Без этого сервер не запустится
При `eula=false` сервер **сразу завершается после запуска** — самая частая точка, где застревают новички.
:::

## 3. Как понять, что запуск удался

Когда в консоли появится строка ниже, сервер **успешно запущен**:

```
Done (6.554s)! For help, type "help"
```

Число секунд в скобках зависит от машины. Теперь:

- с **самой машины** можно зайти через `localhost:25565`;
- другие заходят по **вашему публичному IP** (или домену) с портом по умолчанию `25565`;
- команда `stop` в консоли **безопасно выключает** сервер (**не закрывайте окно крестиком** — легко повредить сохранение).

## 4. Дополнительно: три полезных приёма

### 1. Добавьте `pause`, чтобы видеть логи при краше

При запуске `.bat` двойным щелчком в Windows окно при краше сервера **мелькнёт и закроется**, и вы ничего не увидите. Достаточно добавить `pause` в **последнюю строку** скрипта:

```bat
java -Xms2G -Xmx2G -jar server.jar --nogui
pause
```

Тогда после выхода сервера окно останется, и ошибки можно будет прочитать (в Linux эквивалент — добавить в конец скрипта `read -n 1 -p "Нажмите любую клавишу..."`).

### 2. Шаблоны в имени, чтобы не менять скрипт при смене версии ядра

Менять имя файла в скрипте при каждом обновлении ядра утомительно. Можно использовать **шаблон**:

```bash
java -jar *.jar
java -jar paper-*.jar
java -jar leaf-*.jar
```

:::warn В .bat под Windows шаблон не работает
Это **проверенное на практике** различие: **shell в Linux / macOS раскрывает шаблон**, а **cmd в Windows — нет**: он передаёт `*.jar` в Java как есть, и Java не находит такой файл и выдаёт ошибку.

В Windows того же эффекта можно добиться циклом `for`:

```bat
@echo off
cd /d "%~dp0"
for %%f in (paper-*.jar) do (
  java -Xms2G -Xmx2G -jar "%%f" --nogui
  goto :done
)
:done
pause
```

Замените `paper-*.jar` на префикс вашего ядра (например, `leaf-*.jar`), и при обновлении версии скрипт менять не придётся.
:::

### 3. Автоперезапуск после краша

**Windows** (`start.bat`):

```bat
@echo off
cd /d "%~dp0"
:start
java -Xmx4G -Xms1G -jar server.jar nogui
echo Сервер упал, перезапуск через 3 секунды...
timeout /t 3
goto start
```

**Linux** (`start.sh`):

```bash
#!/bin/bash
cd "$(dirname "$0")"
while true; do
    java -Xmx4G -Xms1G -jar server.jar nogui
    echo "Сервер остановлен, перезапуск через 3 секунды..."
    sleep 3
done
```

:::warn Прежде чем включать автоперезапуск, подумайте
Автоперезапуск подходит для **долго работающего сервера без присмотра**. Но если сервер не запускается из-за **ошибки конфигурации** (не та версия Java, занятый порт), он будет **перезапускаться каждые 3 секунды и забивать вывод**, скрывая настоящую ошибку. **При первой отладке не используйте автоперезапуск** — сначала добейтесь ручного запуска.
:::

:::tip Для долгой работы в Linux лучше systemd
Цикл `while` выше будет убит при разрыве SSH. Чтобы сервер **запускался при загрузке, перезапускался после краша и не останавливался при выходе из SSH**, лучше поручить его systemd — см. шаг 5 «Подготовки среды (Windows и Linux)».
:::
