Для запуска сервера **подходят и Linux, и Windows**, причём работает одна и та же серверная программа. Разница не в «можно или нельзя», а в **стабильности, потреблении ресурсов и стоимости дальнейшего обслуживания**.

| Ваша ситуация | Рекомендация |
| --- | --- |
| Долгосрочный сервер на облаке, важны стабильность и низкое потребление | **Linux** (Ubuntu или Debian) |
| Свой компьютер, игра изредка с друзьями, командная строка незнакома | **Windows** |
| Ни то ни другое не знакомо, но хочется меньше проблем | Начните с **Windows**, потом перейдите на Linux |

**Порядок запуска в обеих системах одинаков**: поставить нужную Java → открыть порт → создать каталоги → положить ядро → запустить. Различается только запись команд, поэтому в разделе подготовки среды **обе системы разобраны вместе**.

## Сравнение

| Критерий | Linux | Windows |
| --- | --- | --- |
| Потребление ресурсов | Низкое (особенно без графической оболочки) | Выше (сама среда рабочего стола ест память) |
| Долгосрочная стабильность | Высокая, месяцами без перезагрузки | Средняя, обновления и сон легко прерывают работу |
| Стоимость лицензии | Бесплатно | Требуется лицензия (серверная редакция — отдельно) |
| Командная строка и автоматизация | Сильная сторона, удобны скрипты и копирование по расписанию | В PowerShell тоже можно, но обычно предпочитают графический интерфейс |
| Удалённое управление | Достаточно одной команды SSH, минимальный трафик | Удалённый рабочий стол тяжелее, при плохой сети заметно хуже |
| Порог освоения | Нужно знать базовые команды | Графический интерфейс нагляден, запуск двойным щелчком |
| Управление службой | systemd, перезапуск после краша | Планировщик заданий или сторонние инструменты, настройка чуть сложнее |
| Частые проблемы | Права, регистр в путях, неверная версия Java | Пути с китайскими символами или пробелами, firewall блокирует порт, сон отключает сеть |

## Какой дистрибутив выбрать (если выбран Linux)

- **Ubuntu LTS**: больше всего материалов, проще искать решения, первый выбор новичка.
- **Debian**: компактнее и стабильнее, для тех, кто знаком с Linux.
- **Семейство CentOS (включая AlmaLinux / Rocky)**: обычно в корпоративной среде, пакетный менеджер `dnf`, команды немного отличаются от Ubuntu.
:::tip На облачный сервер не ставьте версию с рабочим столом
Достаточно версии **Server / minimal**. Графический рабочий стол зря занимает сотни МБ памяти и никак не помогает серверу.
:::

## Частые заблуждения

- **«Linux производительнее, поэтому игра плавнее»**: неверно. На том же железе и ядре ощущения игроков почти одинаковы; преимущества Linux — **меньше потребление, стабильность, экономия на лицензиях**.
- **«На Windows не поднять большой сервер»**: тоже неверно. Для небольшого плагинного сервера Windows вполне подходит; узкое место обычно в канале и частоте одного ядра, а не в системе.
- **«Профессионально — только на Linux»**: выбор зависит от ситуации. Для игры с друзьями локально Windows, наоборот, проще.
