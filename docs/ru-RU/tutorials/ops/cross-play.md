Многие игроки хотят заходить на сервер Java Edition с клиента Bedrock. Мы собрали весь процесс в шпаргалку на одну страницу.

## Ключевые моменты

:::step Принцип
Geyser переводит протокол Bedrock в протокол Java, а Floodgate позволяет игрокам Bedrock проходить проверку входа без аккаунта Java.
:::

:::step Куда ставить
Можно на прокси (Velocity, BungeeCord), можно на отдельный сервер Paper. На прокси удобнее централизованное управление.
:::

:::step Какие порты открыть
Java по умолчанию использует TCP 25565, Bedrock — UDP 19132. Открыть нужно и в межсетевом экране, и в группе безопасности облачного сервера.
:::

:::danger
Не отключайте проверку лицензии на публичном сервере, чтобы «решить» проблему входа: это значит пустить кого угодно под любым именем. Правильный путь — настроить Floodgate.
:::

Полные шаги — в статье «Поддержка мобильных игроков».
