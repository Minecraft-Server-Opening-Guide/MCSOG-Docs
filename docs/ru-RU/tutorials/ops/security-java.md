Как только сервер становится публичным, безопасность делится на три слоя: **кто есть кто** (идентификация), **можно ли потом разобраться** (логирование и откат), **кто что может** (права). У каждого слоя есть зрелые плагины; ниже только те, у которых **есть официальный репозиторий**.

## 1. Идентификация: AuthMe

**AuthMeReloaded** — плагин идентификации для семейства Bukkit / Spigot (сам автор описывает его как «плагин аутентификации для Bukkit/Spigot API»).

- Репозиторий: <https://github.com/AuthMe/AuthMeReloaded>
- **Когда он нужен**: только при **офлайн-режиме** (`online-mode=false`). На лицензионном сервере аккаунт проверяет Mojang, дополнительный вход не нужен.
- **Что он решает**: в офлайн-режиме «ID может присвоить любой», а AuthMe **регистрацией + входом по паролю** связывает ID с паролем, и самозванец не войдёт.
- **Что он не решает**: коренные проблемы офлайн-режима (блокировку можно обойти сменой ID, скин и UUID привязать нельзя) остаются. **На публичном сервере всё равно рекомендуется включить проверку лицензии**.

:::warn Цена офлайн-режима не исчезает от установки плагина входа
Плагин входа лишь «добавляет дверь в офлайн-режим», а не превращает офлайн-сервер в лицензионный. Безопасность аккаунтов, скины и действенность блокировок всё равно урезаны.
:::

## 2. Логирование и откат: CoreProtect

**CoreProtect** — инструмент логирования данных и защиты от разрушения (официальное описание: *blazing fast data logging and anti-griefing tool*).

- Репозиторий: <https://github.com/PlayPro/CoreProtect>
- **Что он записывает**: установку и разрушение блоков, доступ к контейнерам, действия с сущностями и команды — всё пишется в базу данных.
- **Что он умеет**: узнать «кто и когда сломал этот участок», посмотреть, что недавно делал игрок, **массово откатить** по времени или по игроку и вернуть разрушенную область в исходное состояние.
- **Почему он первый в приоритете**: без логов вы даже не узнаете, «кто это сделал», и ни блокировка, ни откат не имеют смысла.

:::tip Чем раньше, тем лучше
CoreProtect записывает только то, что произошло **после установки**. Если поставить его после разрушения, прошлое уже не найти.
:::

## 3. Права: LuckPerms

**LuckPerms** — плагин прав для серверов Minecraft (официальное описание: *A permissions plugin for Minecraft servers.*).

- Репозиторий: <https://github.com/LuckPerms/LuckPerms>
- **Что он решает**: в ванили есть только «дать OP или нет», а права OP огромны. LuckPerms даёт тонкое управление через **группы прав + узлы прав**: кто какую команду может использовать и какие блоки трогать — всё настраивается отдельно.
- **Смысл для безопасности**: «администратор» разбивается на роли (поддержка, строитель, ведущий мероприятий), и **каждый получает ровно те права, что ему нужны**, что снижает риск, когда один человек получает всё.
- **Полезная привычка**: регулярно пересматривать группы прав и список OP.

## 4. Античит: Grim

**Grim** — **открытый, асинхронный многопоточный, прогнозирующий** античит (автор также указывает поддерживаемый диапазон версий 1.8–1.21, актуальность уточняйте в текущем описании репозитория).

- Репозиторий: <https://github.com/GrimAnticheat/Grim>
- **Идея**: он не ждёт реального нарушения, а **предсказывает**, где и в каком состоянии игрок должен быть, и отклонение считается нарушением, поэтому он чувствителен к классическим читам «с подменой пакетов».
- **Плюс открытости**: логику проверки можно посмотреть и проверить, не нужно слепо верить чёрному ящику.

:::warn Ложные срабатывания античита вредят игрокам сильнее, чем пропуски
С любым античитом **сначала поработайте в режиме «только логировать, не наказывать»** и убедитесь, что нет ложных срабатываний, и только потом включайте наказания. Обычные игроки, которых выкидывает, откатывает или блокирует, просто уходят.
:::

## 5. Выбирайте по категории, а не по известности

| Категория | Представитель | Приоритет |
| --- | --- | --- |
| **Логирование и откат** | CoreProtect | Обязательно (первый приоритет) |
| **Права** | LuckPerms | Обязательно |
| **Идентификация** | AuthMe (нужен только в офлайн-режиме) | Обязательно для офлайн-сервера, для лицензионного не нужен |
| **Античит** | Что-то вроде Grim | Плюс к оценке, требует осторожной настройки |
| **Барьер на входе** | Белый список / модерация | Настоятельно рекомендуется для небольших серверов с высокими требованиями |

## 6. Общие принципы

1. **Скачивайте только из официальных источников**: плагин — это сторонний код, работающий с правами сервера, и jar, перезалитый на форуме или в файлах чата, самый рискованный (могут подложить бэкдор).
2. **Сначала попробуйте на тестовом сервере**: не ставьте плагины неизвестного происхождения сразу на основной.
3. **Минимум прав**: если можно не давать OP — не давайте, заменяйте узлами прав.
4. **Резервная копия — последняя линия обороны**: ни античит, ни логи не спасут от «худшего случая», внешняя резервная копия всё равно обязательна (см. «Резервное копирование и восстановление»).
5. **Действия администрации должны оставлять след**: кто кого заблокировал и кто что выдал — всё должно быть проверяемо, чтобы избежать обвинений в «злоупотреблении правами».
