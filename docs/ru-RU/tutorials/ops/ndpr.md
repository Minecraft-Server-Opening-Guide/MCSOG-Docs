**NDPReforged (NDPR)** — это кроссплатформенная **система объединённых блокировок для серверов Minecraft**: несколько серверов используют одну базу блокировок, что даёт **единые блокировки и синхронизацию в реальном времени**. Система построена на RESTful API, официальная документация — <https://ndpreforged.com/wiki.php>, сайт и панель владельца — <https://ndpreforged.com/>.

Статья составлена по официальной документации (текущая версия **2.1.0**, документация обновлена 2026-08-16); все параметры конфигурации и значения по умолчанию приведены по официальной документации.

## 1. Какую проблему она решает

Боль одиночных блокировок: вы забанили разрушителя на сервере A, а он спокойно играет на сервере B; между владельцами остаются только скриншоты и устные договорённости. NDPR выносит данные блокировок в облако, и все подключённые серверы **используют один и тот же список**.

Основные возможности по официальному описанию:

| Возможность | Описание |
| --- | --- |
| Безопасная аутентификация | Аутентификация по Token + управление правами |
| Кроссплатформенность | MCDR, Bukkit/Paper, моды (Fabric/Forge/NeoForge), Velocity/BungeeCord, Bedrock |
| Синхронизация в реальном времени | Данные блокировок между серверами синхронизируются мгновенно |
| Проверка устройства HWID | Сбор отпечатка браузера, проверка машины против читов |
| Модерация блокировок | Заявка на блокировку, синхронизация после проверки в облаке |
| Статистика | Полная статистика блокировок |
| Совместимость со старым | Совместимость со старым протоколом NDP |

Архитектурно система делится на четыре уровня: **панель управления (Web) → уровень сервисов API (аутентификация Token / управление блокировками / управление пользователями / рассылка данных / проверка устройства HWID / модерация) → уровень данных (MySQL)**.

## 2. Матрица поддержки

| Сервер | Статус поддержки |
| --- | --- |
| MCDR 2.8+ | Поддерживается |
| Java: Spigot / Bukkit / Paper / Folia | Поддерживается |
| Fabric / Forge / NeoForge (моды) | Поддерживается |
| Velocity / BungeeCord (прокси) | Поддерживается |
| Bedrock: LeviLamina / BDSX / BDSpyrunner / gomint / Allay / Nukkit | Поддерживается |

:::tip На прокси проще всего
Установите один раз на **Velocity или BungeeCord** — **все дочерние серверы автоматически получат защиту блокировок**, ставить клиент на каждый дочерний сервер не нужно.
:::

## 3. Установка

### 1. MCDR (Java Edition)

Требования: **MCDR 2.8+**, **Python 3.8+**.

```bash
!!MCDR plugin install ndpr
```

Можно также скачать вручную со страницы релизов GitHub и положить файл в каталог плагинов MCDR.

### 2. Плагинная часть (Bukkit / Spigot / Paper / Folia)

Требования: **MC 1.20.1+**, **Java 17+**.

1. Положите `NDPR-Bukkit-2.1.0.jar` в каталог `plugins/` сервера
2. Запустите сервер, плагин автоматически создаст файл конфигурации

**Один jar подходит для Bukkit / Spigot / Paper / Folia.**

### 3. Мод (Fabric / Forge / NeoForge)

Поддерживаемые версии: **1.20.4 / 1.20.6 / 1.21.1 / 1.21.4 / 1.21.6 / 1.21.9 / 1.21.11 / 26.2**.

Положите `NDPR-MOD-2.1.0.jar` в каталог `mods/` и запустите игру или сервер. **Один и тот же jar поддерживает все три загрузчика.**

### 4. Прокси (Velocity / BungeeCord)

Требования: **Velocity 3.x** или **BungeeCord (MC 1.20.1+)**, **Java 17+**.

Положите `ndpr-proxy.jar` в каталог `plugins/` прокси и перезапустите прокси.

### 5. Bedrock

| Платформа | Способ установки |
| --- | --- |
| BDSpyrunner | Положите `ndpr.py` в каталог `plugins/` |
| BDSX | Пакет npm в каталог `plugins/ndpr/` |
| LeviLamina | `plugins/ndpr/` (dll + `manifest.json`) |
| Nukkit / Allay / gomint | Положите `ndpr.jar` в каталог `plugins/` |

## 4. Конфигурация (пять шагов)

### Шаг 1: получить UUID

**На стороне MCDR** есть два способа:

Способ первый — найти в журнале запуска:

```text
[MCDR] [20:21:33] [TaskExecutor/INFO] [ndpr]: Тип сервера: xx
[MCDR] [20:21:33] [TaskExecutor/INFO] [ndpr]: UUID: xxxx-xxxx-xxxx-xxxx-xxxx-xxxx-xxxx-xxxx
[MCDR] [20:21:34] [TaskExecutor/INFO] [ndpr]: Плагин NDPR загружен
```

Способ второй — после второго запуска прочитать из файла конфигурации, путь `корень MCDR\config\ndpr\config.toml`:

```toml
uuid = "xxxx-xxxx-xxxx-xxxx-xxxx-xxxx-xxxx-xxxx"
```

**На всех остальных платформах** (плагин / мод / прокси / Bedrock) **при первом запуске UUID получается автоматически и записывается в файл конфигурации**, вручную заполнять не нужно. Если нужно проверить вручную, ищите по таблице ниже:

| Платформа | Расположение файла конфигурации | Поле |
| --- | --- | --- |
| Bukkit/Paper | `plugins/NDPR-Bukkit/config.yml` | `uuid` |
| Мод | `.minecraft/config/ndpr.json` | `uuid` |
| Velocity | `plugins/ndpr/config.toml` | `uuid` |
| BungeeCord | `plugins/NDPReforged-Proxy/config.toml` | `uuid` |
| Bedrock (BDSpyrunner/BDSX/LeviLamina/Nukkit/Allay/gomint) | `plugins/ndpr/config.json` | `uuid` |

### Шаг 2: получить Token

1. Откройте сайт <https://ndpreforged.com/>, нажмите **Управление владельца** сверху или в левом верхнем углу
2. Войдите или зарегистрируйтесь (слайдер-капчу проще пройти, если тянуть медленнее)
3. Нажмите слева **Управление Token**
4. В разделе «Создать новый Token» укажите UUID из предыдущего шага и сгенерируйте Token
5. Необязательно: нажмите слева **Права загрузки**, рядом с Token запросите права на загрузку и дождитесь проверки

### Шаг 3: настроить Token

**На стороне MCDR** (`корень MCDR\config\ndpr\config.toml`):

```toml
token = "xxxxxxxxxxxxxxxxxxxx"
```

Расположение поля на других платформах:

| Платформа | Файл конфигурации | Поле |
| --- | --- | --- |
| Bukkit/Paper | `plugins/NDPR-Bukkit/config.yml` | `token` |
| Мод | `.minecraft/config/ndpr.json` | `token` |
| Velocity / BungeeCord | `plugins/ndpr/config.toml` | `token` |
| Bedrock | `plugins/ndpr/config.json` | `token` |

:::warn Token не заполнен — значит не установлено
**Token включает функцию блокировок; без него плагин не выполняет проверку блокировок.** Если только установить плагин и не заполнить Token, защиты не будет.
:::

### Шаг 4: настроить тип сервера

**На стороне MCDR**:

```toml
onlinemode = true   # true = лицензионный сервер, false = офлайн-сервер
```

| Платформа | Файл конфигурации | Поле |
| --- | --- | --- |
| Bukkit/Paper | `plugins/NDPR-Bukkit/config.yml` | `onlinemode` (обязательно) |
| Мод | `.minecraft/config/ndpr.json` | `onlinemode` (обязательно) |
| Velocity / BungeeCord | `plugins/ndpr/config.toml` | `onlinemode` (пусто — используется режим самого прокси) |
| Bedrock | `plugins/ndpr/config.json` | `onlinemode` (в Bedrock единый вход Xbox, передаётся как есть) |

:::warn В Java Edition onlinemode обязателен
**На всех платформах Java Edition поле `onlinemode` обязательно, иначе плагин не загрузится нормально.**
:::

### Шаг 5: остальные параметры конфигурации

| Параметр | Описание | Значение по умолчанию |
| --- | --- | --- |
| `api_url` | Адрес API | `https://api.ndpreforged.com` |
| `language` | Язык (`zh_CN` / `en_us`) | `zh_CN` |
| `download_interval` | Интервал автообновления базы блокировок (секунды), `0` = отключено | `900` |
| `check_hwid` | Включить проверку устройства HWID | `false` |
| `check_interval` | Сколько дней не проверять после успешной проверки | `3` |
| `fail_closed` | Отказывать во входе при отсутствии базы блокировок (приоритет безопасности) | `false` |
| `verify_timeout` | Таймаут проверки HWID (секунды, 30~600) | `60` |
| `freeze_interval` | Интервал возврата координат во время проверки (секунды, 1~60) | `1` |

**Полный пример для стороны MCDR** (`корень MCDR\config\ndpr\config.toml`):

```toml
uuid = "xxxx-xxxx-xxxx-xxxx-xxxx-xxxx-xxxx-xxxx"
token = "xxxxxxxxxxxxxxxxxxxx"
onlinemode = true
api_url = "https://api.ndpreforged.com"
language = "zh_CN"
download_interval = 900
check_hwid = false
check_interval = 3
fail_closed = false
verify_timeout = 60
freeze_interval = 1
```

## 5. Команды

### Сторона MCDR

Основная команда `!!NDPR` или `!!ndpr`.

| Команда | Описание |
| --- | --- |
| `ban <ID> <причина>` | Заблокировать игрока |
| `check <ID>` | Проверить статус блокировки игрока |
| `download` / `d` | Обновить данные блокировок |
| `checkupdate` / `cu` | Проверить обновления |
| `help` | Показать справку |
| `reload` | Перезагрузить файл конфигурации |
| `auth <игрок>` | Принудительно запустить проверку устройства игрока |

### Другие платформы (плагин / мод / прокси / Bedrock)

Префикс команд единый — `/ndpr` (на прокси и в Bedrock команд с префиксом `!!` нет).

| Команда | Описание | Права |
| --- | --- | --- |
| `/ndpr`, `/ndpr help` | Справка | Все |
| `/ndpr d`, `/ndpr download` | Вручную скачать базу блокировок | `ndpr.admin` |
| `/ndpr ban <игрок> <причина>` | Отправить заявку на блокировку | `ndpr.admin` |
| `/ndpr check <ID/IP/UUID>` | Проверить статус блокировки (при отсутствии совпадений выдаёт приблизительные подсказки) | Все |
| `/ndpr reload` | Перезагрузить конфигурацию и заново скачать базу блокировок | `ndpr.admin` |
| `/ndpr cu`, `/ndpr checkupdate` | Проверить обновления плагина | `ndpr.admin` |
| `/ndpr auth <игрок>` | Принудительно запустить проверку устройства игрока | `ndpr.admin` |

`ndpr.admin` по умолчанию выдаётся **OP** (в MCDR — уровень прав 2).

## 6. Несколько пунктов, которые нужно взвесить самому

1. **`fail_closed`: безопасность против доступности**. По умолчанию `false` — если облачная база блокировок не скачивается, **доступ разрешается**, сервер работает как обычно; при `true` — **вход запрещается**, приоритет безопасности, но при сбое облака игроки останутся за дверью. У публичного сервера и сервера для друзей выбор может быть противоположным.
2. **`check_hwid`: античит против приватности**. После включения используется **сбор отпечатка браузера** для проверки машины (в связке `verify_timeout` — таймаут проверки, `freeze_interval` — интервал возврата координат во время проверки, `check_interval` — дни без повторной проверки). Это **более сильная идентификация, чем IP**, но она связана со сбором информации об устройствах игроков — официальная документация объясняет назначение, **и вам следует указать это игрокам в правилах сервера** перед включением.
3. **`download_interval`**: по умолчанию синхронизация раз в 900 секунд (15 минут). Слишком малое значение повышает частоту запросов, слишком большое замедляет вступление блокировок в силу; `0` означает отключение автообновления (тогда остаётся только ручная загрузка через `/ndpr d`).
4. **Приоритет прокси**: если у вас архитектура Velocity/BungeeCord, установка на прокси один раз покрывает все дочерние серверы и меньше подвержена пропускам, чем установка на каждый дочерний сервер.

## 7. Быстрая диагностика

| Симптом | Что проверить первым |
| --- | --- |
| Плагин загрузился, но блокировок нет | **Заполнен ли Token** (не заполнен = не проверяет) |
| Плагин не загружается / не работает | Заполнен ли **`onlinemode`** в Java Edition (обязательно) |
| База блокировок не скачивается | Правилен ли `api_url` (по умолчанию `https://api.ndpreforged.com`), не равен ли `download_interval` нулю и есть ли у хоста доступ в интернет |
| Заблокированный игрок всё равно заходит | Установлено ли на **прокси**, не обходят ли дочерние серверы прокси прямым подключением, синхронизирована ли база блокировок |
| Хочу обновить список вручную | `/ndpr d` (в MCDR — `!!ndpr d`) |
| Хочу, чтобы изменения конфигурации вступили в силу сразу | `/ndpr reload` (перезагрузит конфигурацию и заново скачает базу блокировок) |
