Экосистема ядер Bedrock гораздо меньше, чем у Java Edition: основных всего четыре.

| Ядро | Язык | Плагины | В двух словах |
| --- | --- | --- | --- |
| **BDS** | C++ | Нужен загрузчик от сообщества | Официальный сервер, **лучшая совместимость** |
| **Nukkit (NK)** | Java | Родные | Лёгкий, «Bukkit для Bedrock» |
| **PowerNukkitX (PNX)** | Java | Родные | Современный наследник Nukkit, **многоядерная оптимизация** |
| **PocketMine-MP (PMMP)** | PHP | Родные | Огромная экосистема плагинов, писать на PHP |

> Полное построчное сравнение (производительность, плагины, экосистема, сценарии) — в разделе «Сравнение ядер Bedrock» статьи **[Сравнение серверных ядер](/wiki/compare#mcsog-h-%E5%9F%BA%E5%B2%A9%E7%89%88%E6%A0%B8%E5%BF%83%E5%AF%B9%E6%AF%94)**.

## 1. BDS (официальный)

Официальный сервер Bedrock от сайта Minecraft, находится на той же странице, что Vanilla для Java Edition.

**Преимущества**

- **Официальная поддержка**: обновляется вместе с официальной игрой, лучшая совместимость с клиентом последней версии;
- **Стабильность**: официальный продукт, надёжная работа;
- **Использование ресурсов**: оптимизирован под Bedrock, эффективно расходует ресурсы сервера;
- **Обновления безопасности**: официальные исправления проблем безопасности выходят чаще.

**Недостатки**

- **Не поддерживает плагины**: в официальном сервере нет системы плагинов, ставить их можно только через **загрузчик плагинов от сообщества**;
- **Узкое место одного потока**: **обсчёт сущностей идёт в одном потоке**, поэтому плавность **в основном зависит от производительности одного ядра CPU**; чем больше карта, тем сильнее лаги, в целом он уступает Java-серверам с поддержкой нескольких ядер;
- **Нет продвинутых функций**: кастомная генерация мира, продвинутое управление правами и подобное обычно требуют сторонних решений;
- **Медленный рост памяти**: потребление постепенно растёт, в тяжёлых случаях похоже на утечку. Учтите: **принудительное освобождение памяти приводит к зависанию полосы загрузки у игроков, скачивающих паки ресурсов/аддоны**, и помогает только перезапуск сервера.

**Кому подходит**: серверам, которым нужны официальная поддержка и совместимость без сложной кастомизации. **Первый выбор для выживача**.

## 2. Nukkit (NK)

«Bukkit» для Bedrock — написан на **Java**, экосистемой и подходом к разработке очень похож на плагинные серверы Java Edition.

**Преимущества**: лёгкий (низкие требования к ресурсам), неплохая производительность, **родная система плагинов**, кроссплатформенность (Windows/Linux/macOS), прост в освоении.

**Недостатки**: **обновления запаздывают** (может отставать от последней версии и новых возможностей), экосистема плагинов меньше, чем у Spigot/Paper, многоядерная оптимизация недостаточна, качественной документации мало, у открытых проектов случаются проблемы со стабильностью.

**Кому подходит**: новичкам и небольшим серверам. **Учтите**: оригинальный Nukkit уже неактивен, на практике лучше брать его современную ветку (см. ниже).

## 3. PowerNukkitX (PNX)

**Современный наследник** Nukkit, сегодня основная сила среди сторонних ядер Bedrock.

**Преимущества**

- **Поддержка новейшего протокола Bedrock**, успевает за новыми версиями;
- **Многоядерная оптимизация**: главное преимущество перед BDS и старым Nukkit;
- **Высота мира 384 блока**;
- Встроенный генератор рельефа **Terra** для богатого ландшафта;
- **Полностью открытый исходный код, открытый API**, плагины можно писать на Java / Kotlin / Scala / Python / JavaScript / Lua и других языках JVM;
- **Совместимость с массой плагинов экосистемы Nukkit**.

**Недостатки**: темп разработки зависит от изменений в команде исходного Nukkit; экосистема всё ещё меньше, чем у основных Java-серверов; плагинов много, новичку учиться дорого.

**Кому подходит**: владельцам серверов, которым нужны **высокая производительность + глубокая кастомизация**.

## 4. PocketMine-MP (PMMP)

Сервер Bedrock на **PHP** с самой большой экосистемой плагинов.

**Преимущества**: огромная экосистема плагинов, кроссплатформенность, **низкий порог PHP** (плагины можно писать, если знаете PHP), активное сообщество, высокая степень кастомизации.

**Недостатки**: **узкое место по производительности при высокой нагрузке игроков** (управление памятью и эффективность CPU); обновления запаздывают; при нескольких плагинах стабильность падает; PHP — интерпретируемый язык, **расход ресурсов заметнее**; настройка и управление плагинами требуют обучения.

**Кому подходит**: владельцам серверов, которым важны **функции плагинов и кастомизация** и которые готовы принять определённые компромиссы по производительности.

## 5. Как выбрать

```
Нужна стабильность + официальная совместимость + ванильный выживач
   → BDS (нужны плагины — ставьте загрузчик от сообщества, см. «Сервер BDS»)

Нужна высокая производительность + многоядерность + глубокая кастомизация
   → PowerNukkitX

Нужна самая большая экосистема плагинов, знаете PHP
   → PocketMine-MP

Хотите начать с простого, интересует экосистема Nukkit
   → семейство Nukkit (но выбирайте активную ветку)
```

:::tip Сначала проверьте на минимальном масштабе
Когда ядро выбрано, **сначала запустите его в малом масштабе** (несколько человек, немного плагинов) и только потом открывайте доступ. Подводных камней с совместимостью у ядер Bedrock больше, чем в Java Edition, — не ставьте сразу весь набор плагинов.
:::
