Прежде чем поднимать сервер Bedrock, решите, **какой тип сервера вы открываете**. Тип определяет, какое ядро можно взять, что можно установить и во сколько обойдётся обслуживание.

В Bedrock Edition есть пять основных типов:

## 1. Ванильный сервер (чистый)

Работает **строго по официальным правилам**, без плагинов и без аддонов.

- Плюс: аутентично, максимально стабильно и почти не требует обслуживания (не нужно следить за совместимостью и обновлениями плагинов)
- Минус: возможностей ровно столько, сколько даёт ваниль
- Кому подходит: тем, кто хочет предложить **честный и стабильный** ванильный опыт; лучше всего подходит **BDS**

## 2. Сервер с аддонами (только BDS)

На официальный **BDS** загружаются официально поддерживаемые **аддоны** (паки поведения / паки ресурсов), расширяющие контент.

- Плюс: официальная поддержка, хорошая совместимость с версиями, небольшое влияние на стабильность
- Минус: ограниченные возможности кастомизации (можно добавлять блоки, предметы и мобов, но нельзя менять серверную логику)
- Кому подходит: тем, кто хочет сохранить официальные возможности и добавить немного своего контента

## 3. Сервер с плагинами

Использует **стороннее ядро сервера** (Nukkit / PowerNukkitX / PocketMine-MP и т. п.) с плагинами, что серьёзно расширяет функциональность.

- Плюс: высокая степень кастомизации, много видов плагинов, много руководств от сообщества
- Минус: возможны проблемы совместимости плагинов и стабильности; **официальный BDS сам по себе не поддерживает плагины**, нужен загрузчик от сообщества
- Кому подходит: тем, кто хочет сделать особенную механику и готов потратить время на настройку плагинов

## 4. Сервер мини-игр (разновидность сервера с плагинами)

Ориентирован на мини-игры вроде «Стены», скайблока и лабиринтов.

- Плюс: высокая развлекательность, быстрый темп, подходит для коротких сессий
- Минус: контент нужно **постоянно обновлять**, иначе игроки уходят; высокие затраты на эксплуатацию
- Кому подходит: тем, кто делает соревновательный или казуальный режим и располагает людьми, способными постоянно производить контент

## 5. Гибридный сервер: аддоны + плагины (только BDS)

Использует и официальные аддоны, и загрузчик плагинов от сообщества.

- Плюс: сочетает официальные возможности и свободу плагинов
- Минус: сложная конфигурация, нужно вести обе стороны, больше проблем совместимости, выше требования к производительности
- Кому подходит: **опытным** владельцам серверов, которые умеют разбираться с проблемами совместимости

## Как выбрать

| Ваша цель | Рекомендация |
| --- | --- |
| Ванильный выживач, стабильно и без хлопот | **Ванильный сервер + BDS** |
| Добавить контент, но не связываться с плагинами | **Сервер с аддонами + BDS** |
| Богатая механика, готовы возиться | **Сервер с плагинами** (Nukkit / PNX / PMMP) |
| Мини-игры | Сервер с плагинами + плагины мини-игр |
| Нужны и официальные возможности, и плагины | **BDS + загрузчик плагинов** |

Когда тип выбран, следующий шаг — выбрать конкретное ядро: см. [Выбор ядра сервера для Bedrock](/tutorials/bedrock/cores).
