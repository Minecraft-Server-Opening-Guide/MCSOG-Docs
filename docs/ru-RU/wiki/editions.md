Java Edition и Bedrock Edition — не одна и та же версия игры: редстоун, команды и механика модов различаются. Разберитесь в различиях, прежде чем решать, для какого издания открывать сервер.

> Номера портов и различия редстоуна заданы официально; в разных версиях детали могут незначительно меняться, точные сведения — в официальном описании соответствующей версии.

## Сравнение

| Пункт | Java Edition | Bedrock Edition |
| --- | --- | --- |
| Редстоун и команды | Механика редстоуна полная (включая quasy-connectivity), команды наиболее функциональны | Поведение редстоуна отличается (нет quasy-connectivity, поршни и липкие блоки ведут себя иначе) |
| Моды и плагины | Fabric / Forge / NeoForge и экосистема плагинов | В основном аддоны (Add-on) |
| Выбор сервера | Paper / Purpur / Fabric / Forge / Velocity | BDS / Nukkit / PocketMine-MP |
| Порт по умолчанию | 25565 (TCP) | 19132 (UDP), для IPv6 — 19133 (UDP) |
| Кроссплатформенная игра | На сервер Java нужно установить Geyser, чтобы принимать игроков Bedrock (вместе с Floodgate вход без аккаунта Java) | Сервер Bedrock не может принимать игроков Java Edition |
| Производительность и оптимизация | Больше всего оптимизационных форков и параметров запуска | У официального BDS мало опций оптимизации, в основном системная настройка |
| Для кого | Тем, кто хочет плагины, моды, автоматизацию и крупные сетевые проекты | Игрокам на телефонах и консолях, игре «из коробки» |

## Примечание

Сервер Bedrock использует UDP 19132, сервер Java — TCP 25565. Самый частый случай «не подключается» — когда открыт только TCP.

Инструмент совместимости Geyser односторонний: он позволяет клиенту Bedrock подключаться к серверу Java Edition; обратного варианта (клиент Java на сервере Bedrock) официально нет. Geyser устанавливается на стороне сервера Java Edition, на официальный сервер BDS его поставить нельзя.
