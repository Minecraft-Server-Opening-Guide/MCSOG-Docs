На этой странице перечислены файлы cookie и данные локального хранилища, которые наш сайт записывает в ваш браузер, их назначение, а также способы просмотра, изменения и удаления этих данных; кроме того, здесь описано, что контролирует каждая из трёх категорий в панели «Настройки cookie». Об обработке данных аккаунта и журналов доступа читайте в [политике конфиденциальности](/privacy).

## Что такое cookie и локальное хранилище

Cookie — это небольшой фрагмент текста, который сайт записывает в браузер; при последующих обращениях к тому же сайту браузер возвращает его, чтобы запомнить состояние входа, язык и подобные сведения. Локальное хранилище (`localStorage`) и хранилище сеанса (`sessionStorage`) — тоже хранилища «ключ — значение», предоставляемые браузером: данные сохраняются на вашем устройстве, не отправляются на сервер с запросами, а читать и записывать их может только скрипт страницы.

На сайте термин «cookie» используется для всей этой группы технологий. Для каждого пункта ниже указано, где именно он хранится: в cookie, локальном хранилище или хранилище сеанса. Ни один из них не содержит исполняемого кода и не читает и не записывает другие файлы на вашем устройстве.

## Какие хранилища сайт использует на самом деле

:::note
Приведённые ниже имена ключей сверены по одному с работающим кодом; все они видны в панели Application (Приложение) инструментов разработчика браузера.
:::

### Записываются самим сайтом

| Имя ключа | Расположение | Назначение |
|---|---|---|
| `mcsog_consent` | Локальное хранилище | Базовый · сохранённое в «Настройках cookie» состояние согласия, JSON v2 фиксирует три пункта — необходимые, необязательные, сторонние — и время сохранения |
| `mcsog_session` | Cookie | Базовый · идентификатор сеанса после входа через сторонний аккаунт, поддерживает состояние входа |
| `mcsog_lang` | Cookie | Базовый · предпочтение языка интерфейса, позволяет серверу сразу выдавать первый экран на китайском или английском |
| `mcsog_locale` | Локальное хранилище | Базовый · языковое предпочтение фронтенда, используется вместе с `mcsog_lang` |
| `mcsog_theme` | Локальное хранилище | Предпочтение · светлая или тёмная тема |
| `mcsog_nav` | Локальное хранилище | Предпочтение · боковая панель развёрнута полностью или свёрнута в полосу значков |
| `mcsog_nav_groups` | Локальное хранилище | Предпочтение · развёрнутое или свёрнутое состояние групп боковой панели |
| `mcsog_news_read` | Локальное хранилище | Предпочтение · отметки прочитанных объявлений, повторно одно и то же объявление не показывается |
| `mcsog_download_agreement` | Локальное хранилище | Предпочтение · запись согласия с условиями на страницах загрузки и поиска |
| `mcsog_search_history` | Локальное хранилище | Предпочтение · история поисковых запросов, хранится только в вашем браузере |
| `mcsog_scroll:<path>` | Хранилище сеанса | Базовый · восстановление позиции прокрутки при возврате на предыдущую страницу, исчезает после закрытия вкладки |
| `mcsog_splash` | Хранилище сеанса | Базовый · проиграна ли заставка в текущем посещении |
| `mcsog_downloads_last` | Хранилище сеанса | Предпочтение · последний просмотренный раздел загрузок, используется для подсветки текущей категории |
| `mcsog_tutorials_first_seen` | Локальное хранилище | Предпочтение · показано ли новичкам вводное пояснение на странице руководств |
| `mcsog_edit` | Локальное хранилище | Предпочтение · переключатель режима редактирования, реально действует только для аккаунтов с правом редактирования |

:::tip
«Базовый» означает необходимость для работы сайта и запоминания вашего выбора, «предпочтение» — настройка под ваши привычки. Обе группы записываются кодом самого сайта и не содержат сторонних идентификаторов отслеживания.
:::

### Сторонние

| Имя ключа | Расположение | Назначение |
|---|---|---|
| `__51uvsct__…`, `__51vcke__…`, `__51vuft__…` | Cookie | Статистика посещений 51LA: различает посетителей и учитывает визиты и время на сайте, в конце — идентификатор статистики сайта |
| `__51huid__…` | Cookie | Идентификатор посетителя для анализа производительности 51LA |
| `__vtins__…` | Локальное хранилище | Сведения о сеансе посетителя 51LA |
| `HMACCOUNT` | Cookie | Идентификатор посетителя статистики Baidu |
| `Hm_lvt_…`, `Hm_lpvt_…` | Cookie и локальное хранилище | Время и число визитов статистики Baidu |

Скрипты этих двух сервисов загружаются с `sdk.51.la` и `hm.baidu.com`: 51LA даёт статистику посещений и анализ производительности страниц, статистика Baidu — статистику посещений. Новому посетителю по умолчанию разрешены все категории, поэтому при первом посещении они загружаются сразу; если в панели отключить «сторонние cookie» и сохранить настройки, при следующей загрузке страницы эти скрипты уже не запрашиваются и перечисленные ключи не записываются.

Если на сайте включён плавающий виджет ИИ, он сохраняет сеанс и позицию панели в собственных ключах `astrbot-widget-*`; эти ключи записывает сам виджет, и переключатель «сторонние cookie» на них не влияет.

## Что контролирует каждая из трёх категорий

| Категория | Что входит | Можно ли отключить |
|---|---|---|
| Базовые cookie | Сеанс, состояние согласия, позиция прокрутки, отметка заставки | Нет, необходимы для работы сайта |
| Необязательные cookie | Язык, тема, боковая панель, прочитанные объявления, запись согласия и другие предпочтения | Переключатель фиксирует ваше предпочтение; сами настройки всё равно сохраняются, чтобы при следующем визите всё осталось как было |
| Сторонние cookie | Статистика посещений и анализ производительности 51LA, статистика Baidu | Да, после отключения и сохранения при следующей загрузке запросов нет |

## Политика по умолчанию и изменение настроек

Новому посетителю по умолчанию разрешены все три категории. В любой момент можно нажать «Настройки cookie» в подвале сайта, переключить нужные пункты и нажать «Сохранить предпочтения cookie»; **изменения вступают в силу при следующей загрузке страницы**, уже загруженные скрипты не выгружаются и не подключаются сразу после сохранения.

## Как удалить данные

В настройках браузера откройте «Конфиденциальность и безопасность» → «Файлы cookie и другие данные сайтов»: там можно удалить данные нашего сайта отдельно или воспользоваться окном в режиме инкогнито. После удаления сайт снова предложит выбрать предпочтения cookie.

:::warn
Удаление `mcsog_session` аннулирует состояние входа, потребуется авторизоваться ещё раз; удаление `mcsog_consent` снова вызовет показ настроек cookie.
:::

## Отзыв согласия

Нажмите «Настройки cookie» в подвале сайта → отключите «сторонние cookie» → сохраните. После этого сайт больше не загружает скрипты 51LA и статистики Baidu. Сторонние cookie, уже записанные в браузер, истекают естественным образом по своим срокам; их можно удалить и вручную способом из предыдущего раздела. Отзыв согласия не мешает вам дальше читать руководства или скачивать ресурсы.
