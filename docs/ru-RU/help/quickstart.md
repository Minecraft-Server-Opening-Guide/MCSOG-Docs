## Сначала определитесь с изданием

- **Java Edition**: официальное издание для Windows / macOS / Linux, самый широкий выбор ядер сервера (Paper, Purpur, Fabric, Forge, Velocity).
- **Bedrock Edition**: издание для телефонов, консолей и Windows; официальный сервер — BDS, из решений сообщества есть Nukkit и PocketMine-MP.

Издания связываются через Geyser + Floodgate, так что игроки Bedrock могут подключаться напрямую к серверу Java Edition.

## Рекомендуемый порядок чтения
:::step Проверьте среду выполнения
Сначала посмотрите «Запуск сервера Java → JDK и соответствие версий», чтобы определиться с версией Java, а затем решите, какое ядро сервера использовать.
:::
:::step Разверните сервер
Пройдите «Развёртывание сервера Paper на Linux» или «Развёртывание официального сервера BDS» и добейтесь первого успешного запуска с нуля.
:::
:::step Завершите базовую настройку
Прочитайте «Разбор server.properties» и «Порты, межсетевой экран и туннелирование», чтобы игроки могли подключиться.
:::
:::step Долгосрочная эксплуатация
Настройте «Резервное копирование и откат» и научитесь находить лаги с помощью «Диагностики TPS / MSPT».
:::
:::note
Для загрузки ресурсов нужен вход. Сайт только собирает и перенаправляет ссылки, права на ресурсы принадлежат их авторам.
:::

## Карта обучения

Выше речь шла о том, «где искать»; ниже — о том, «в каком порядке читать». Руководств на сайте десятки, и двигаться по этапам стоит, чтобы не хвататься за всё сразу: сначала разобраться в терминах, затем решить, какой сервер открывать, потом запустить его локально, пустить других игроков, установить плагины, заняться эксплуатацией и только в конце — работой с сообществом.

### Три самые частые ошибки

1. **Обновление без резервной копии**: перед обновлением ядра, плагинов или MCDR сделайте резервную копию и убедитесь, что она **действительно восстанавливается**. См. [Резервное копирование и восстановление](/tutorials/java/backup) и [Обновление и обслуживание сервера, плагинов и MCDR](/tutorials/ops/updates).
2. **Публикация адреса без белого списка и проверки лицензии**: если `online-mode` и белый список ещё не настроены, а IP уже разослан, вы фактически отдаёте сервер незнакомцам. См. [Настройка сервера](/tutorials/java/config) и [Основы сетевой безопасности](/tutorials/ops/network-security).
3. **Обновление мира без проверки нового ядра**: как только мир открыт новой версией, откатиться на старую очень трудно. Сначала проверьте на копии и только потом трогайте основной мир. См. [Обновление и обслуживание сервера, плагинов и MCDR](/tutorials/ops/updates) и [Частые ошибки и краши Java Edition](/tutorials/faq/errors).

### Нужен только сервер Bedrock?

Длинную цепочку руководств по плагинам Java Edition можно пропустить и идти так:

1. [Типы серверов Bedrock](/tutorials/bedrock/type) — сначала разберитесь, чем BDS отличается от сторонних ядер.
2. [Выбор ядра Bedrock](/tutorials/bedrock/cores) — решите, какое ядро использовать.
3. [Сервер BDS](/tutorials/bedrock/bds) или [Сторонние ядра Bedrock: первые шаги](/tutorials/bedrock/third-party-setup) — разверните согласно выбранному ядру.
4. [Развёртывание в доступной среде](/tutorials/java/deploy) — сделайте сервер доступным из интернета (сетевая часть универсальна).
5. [Диагностика проблем серверов Bedrock](/tutorials/faq/bedrock-issues), [[BE] Частые вопросы](/tutorials/faq/faq-be) — при проблемах начинайте с этих двух статей.
6. [Резервное копирование и восстановление](/tutorials/java/backup) — резервные копии нужны в любом издании.
