MCSOG предоставляет рекламные места для серверов, инструментов и общественных проектов. Каждая реклама проходит проверку до публикации; мы оставляем за собой право отклонить, изменить или снять рекламу.

## Что такое ADS

ADS — рекламная система сайта. Сейчас поддерживаются верхние баннеры, реклама внутри статей и другие места. Для каждой рекламы можно настроить:

- изображение и ссылку перехода;
- основной заголовок, подзаголовок и их цвета.

Содержание рекламы должно быть достоверным, понятным и соответствовать странице перехода.

## Заявка на размещение

Отправьте заявку через форму:

[Подать заявку на рекламу](https://wj.qq.com/s2/28404050/9smy/)

Желательно указать:

- название рекламодателя и контакты;
- материалы и URL страницы перехода;
- желаемое место и сроки размещения;
- нужна ли удалённая реклама (RADS).

После проверки администратор включит место в редакторе рекламы.

## RADS — удалённая реклама

RADS (Remote Advertising Services, служба удалённой рекламы) позволяет рекламодателю поддерживать собственный HTTPS JSON-эндпоинт. MCSOG получает его содержимое при показе рекламы. Это удобно, если изображения, тексты или ссылки часто меняются.

:::warn Внимание
После включения удалённой рекламы функция должна пройти проверку.
:::
## Спецификация API

### Запрос

- Метод: `GET`
- Ответ: `application/json; charset=utf-8`
- Заголовок: `Accept: application/json`
- Cookie не отправляются, token-авторизация не используется; эндпоинт должен быть публично доступен
- CORS: `Access-Control-Allow-Origin: *` или `https://mcsog.ndpreforged.com`

### Пустой шаблон

```json
{
  "settings": {
    "imageUrl": "",
    "clickUrl": "",
    "mainTitle": "",
    "mainTitleColor": "",
    "subTitle": "",
    "subTitleColor": ""
  }
}
```

### Поля

| Поле | Значение | Описание |
| --- | --- | --- |
| `imageUrl` | Изображение | Обязательно; `https://...` или `/assets/...` |
| `clickUrl` | Ссылка перехода | Необязательно; `https://...` или `/...` |
| `mainTitle` | Основной заголовок | Текст, желательно до 80 символов |
| `mainTitleColor` | Цвет заголовка | HEX-цвет |
| `subTitle` | Подзаголовок | Текст, желательно до 120 символов |
| `subTitleColor` | Цвет подзаголовка | HEX-цвет |

Поддерживаются цвета `#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`. Пустой или неверный цвет заменяется цветом по умолчанию.

### Пустые значения и откат

- Пустой `imageUrl`: используется сохранённое локальное изображение; если его нет, реклама не показывается;
- Пустой `clickUrl`: ссылка не создаётся;
- Пустые заголовок или подзаголовок: элемент скрывается;
- HTTP не 200, неверный JSON, отсутствие `settings`, ошибка CORS, таймаут или сеть: откат к локальному содержимому.

### Пример сервера

```php
<?php
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, OPTIONS');
header('Access-Control-Allow-Headers: Accept');
header('Content-Type: application/json; charset=utf-8');

if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(204);
    exit;
}

echo json_encode([
    'settings' => [
        'imageUrl' => 'https://cdn.example.com/ad/banner.png',
        'mainTitle' => 'Добро пожаловать в MCSOG',
        'mainTitleColor' => '#FFFFFF',
        'subTitle' => 'QQ-группа: 1083430859',
        'subTitleColor' => '#FFFFFF'
    ]
], JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
```

## Проверка и нарушения

- Материалы, страницы перехода и содержимое удалённого эндпоинта должны соответствовать правилам сайта и законам;
- Мы можем потребовать изменения, приостановить или снять рекламу без предварительного уведомления;
- Изменения на удалённом эндпоинте также подлежат проверке; удалённые обновления нельзя использовать для обхода проверки.

:::danger Опасно
Внимание: после включения удалённой рекламы при нарушении правил мы применим санкции, включая отзыв доступа, удаление рекламы, остановку кампаний и отсутствие возврата оплаты за текущий месяц.
:::
