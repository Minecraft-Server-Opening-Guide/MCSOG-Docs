После входа, если в правах аккаунта есть **mcsog**, в верхней панели появляется кнопка режима редактирования. После её включения внизу страницы появляется панель инструментов редактирования, а все изменения отправляются в репозиторий GitHub и автоматически синхронизируются с рабочей версией сайта.

## Что можно изменить

:::step Тексты страниц
Нажмите «Тексты», чтобы открыть список словаря (с поиском по ключу или содержимому); можно также **щёлкнуть по любому тексту интерфейса прямо на странице** — соответствующий ключ словаря будет найден автоматически и откроется форма редактирования.
:::

:::step Документы и объявления
На странице руководства, объявления или справки нажмите «Редактировать эту статью» — откроется редактор Markdown; сохранение записывает файл обратно в `docs/` и создаёт коммит.
:::

:::step Создание содержимого
В «Новом документе» достаточно указать тип, категорию, язык, идентификатор и заголовок; в тексте поддерживаются `:::step`, `:::note`, `:::warn`, `:::danger`, блоки кода и таблицы.
:::

:::step Изображения
В разделе «Изображения» загрузите PNG / JPEG / WebP / GIF / AVIF и получите адрес для прямой вставки; файл одновременно отправляется в репозиторий.
:::

:::step Навигация
В разделе «Навигация» можно добавить пункт в любой раздел или удалить существующий (изменения записываются в `nav.config.js`).
:::

:::warn
В режиме редактирования сервер создаёт коммиты и выполняет push с настроенным ключом; перед локальной разработкой сначала выполните `git pull`, чтобы избежать расхождения с коммитами сайта.
:::

## Права и безопасность

- Права берутся из поля `permission`, которое возвращает поставщик OAuth; вход в редактирование показывается только при наличии настроенного токена (по умолчанию `mcsog`);
- Интерфейс записи повторно проверяет права на сервере и отклоняет запросы с чужих сайтов (cross-site);
- Приватный SSH-ключ для push хранится в **зашифрованном виде AES-256-GCM** в `config/edit.php`, при работе расшифровывается во временный файл (0600) и сразу удаляется после push;
- Загрузка изображений ограничена 2 MB и принимает только реальные форматы изображений.
