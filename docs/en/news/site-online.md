MCSOG is live today. The first batch covers Java and Bedrock server guides, a server core index and a version timeline.

## What shipped

:::step Guides for both editions
The "Java Edition" and "Bedrock Edition" tracks run from environment preparation (JDK, BDS) through first boot, tuning and troubleshooting.
:::

:::step Resource index
Server cores, panels and tools with version, size and checksum metadata. Files are served from object storage so mirrors can be switched at any time.
:::

:::step Version wiki
The timeline collects release dates and server support status; the core comparison table helps you choose.
:::

:::note
Downloads require signing in through a third-party OAuth2 account. We never store your password.
:::

## What is next

- A new batch of guides every two weeks, prioritising the most asked FAQ topics;
- Mirrors and versions kept in sync with upstream;
- Community submissions for guides and translations are welcome, see "Contribution".
