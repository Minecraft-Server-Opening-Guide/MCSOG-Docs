This page collects the sites and communities that have linked to MCSOG over the long term. Every link points to an external site whose content is maintained by its own operators.

## Official and tool sites

The official sites you will reach for most often while running a server. Bookmarking them is worthwhile:

- [Minecraft official site](https://www.minecraft.net/): release announcements, official accounts and server software downloads
- [PaperMC](https://papermc.io/): Paper and Velocity servers plus documentation
- [Purpur](https://purpurmc.org/): the Purpur server and its configuration reference
- [Fabric](https://fabricmc.net/): the Fabric loader and server
- [NeoForge](https://neoforged.net/): the NeoForge loader and documentation
- [Modrinth](https://modrinth.com/): mod, plugin and modpack search
- [Hangar](https://hangar.papermc.io/): the plugin platform for the Paper ecosystem
- [GeyserMC](https://geysermc.org/): cross-play between Java and Bedrock
- [PocketMine-MP](https://pmmp.io/): a third-party Bedrock server

## Sources for the guides

The Java server guides on this site were written with reference to the open-source documentation project below, **rewritten to fit this site's structure and wording** rather than copied:

- [NitWikit (Cubic Wiki)](https://nitwikit.8aka.org/): a community documentation project for running Minecraft servers, covering server structure, configuration, plugins, technical play and advanced operations
- [NitWikit source repository (GitHub)](https://github.com/Cubic-Project/NitWikit): the documentation is open source on GitHub, and improvements are welcome

:::note On attribution
Chapters such as "Server Structure", "Configuring the Server", "Common Server Commands", "Plugins", "Technical Play", "Proxies" and "Operations and Management" were informed by that material for **fact-checking and structural organisation**; the exact wording, examples and layout are our own.

Where this site disagrees with the latest upstream content, **upstream takes precedence**; please tell us if you spot an error here as well.
:::

## Link exchange

Sites with related content that are updated regularly are welcome to exchange links. Use the contact details in the footer and include:

- the site name and a one-line description
- the site address (https is preferred)
- the link text you would like us to use

We review each site by hand before deciding whether to list it. The following are not accepted:

- content that involves piracy, cheating tools, cracks or copyright infringement
- sites that are unreachable for long periods, or whose main content is aggregated advertising
- commercial promotion unrelated to Minecraft servers
