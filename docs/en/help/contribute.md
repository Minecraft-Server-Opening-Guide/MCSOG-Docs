This site is maintained by the player community, and guides, corrections and translations are always welcome. All of the content lives in the public repository [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs).

## What you can contribute

- **New guides** for hosting, operations and troubleshooting: the situations where you ran into a problem and solved it
- **Corrections** for outdated commands, wrong paths, version mismatches and typos
- **Translations** of Chinese guides into English, or fixes to existing translations
- **Resource entries** that fill in the download details (version, size, checksum, official homepage)

## How to submit

:::step Create a branch
Fork [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) and create a branch, then add files following the directories and naming in the [editing guide](/help/guide).
:::

:::step Open a pull request
Describe the **scope of the change** in the pull request. Once it is merged into `main`: synced into the main repository within 30 minutes, live within 2 hours.
:::

## Writing rules

:::step Only write what you have verified
Commands and configuration must be things you have run yourself; mark anything you are unsure about with `:::warn` and state the conditions under which it applies.
:::

:::step Aimed at beginners, but never skip the key steps
Every step must be executable. Do not use vague wording such as "configure as needed".
:::

:::step Keep Chinese and English in sync
When you add a Chinese guide, try to provide the English file with the same slug at the same time. If you cannot, that is fine: the page falls back to Chinese and says so.
:::

:::step Follow official sources for versions and commands
Version numbers, commands and download URLs must be checkable, with a link to the official source; when upstream changes, update the content promptly or take it down.
:::

:::danger
Do not upload pirated resources, cracking tools or files that contain someone else's paid content. This site only indexes publicly released resources and links to official sources.
:::

## Copyright and attribution

- Original content you contribute may, by default, be republished and adapted by this site under the same terms;
- Quoting someone else's content requires the source and its licence to be credited;
- If you find infringing content, report it through the email on the "Contact Us" page and we will take it down as soon as we can.

## Community and questions

The **only official community group** for this site is the QQ group [1083430859](https://qm.qq.com/q/nRsqCiwHMm). You can discuss what you are contributing in the group before or after you submit it.

- Want to change something but are unsure how: describe the page and the problem in the group and we will tell you exactly what to do
- Submitted a change and want to follow its progress: just ask in the group instead of opening issue after issue
- Note: the community rules apply in the group as well; advertising and pirated content are removed on sight
