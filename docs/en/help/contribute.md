This site is maintained by the community. Contributions of guides, fixes and translations are welcome, and everything lives in the public repository [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs).

## What you can contribute

- **New guides** for setup, operations or troubleshooting you have solved yourself
- **Corrections** for outdated commands, wrong paths, version mismatches and typos
- **Translations** from Chinese to English, or fixes to existing translations
- **Resource entries** with complete metadata (version, size, checksum, homepage)

## How to submit

:::step Create a branch
Fork [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) and create a branch, then add files following the layout in the [editing guide](/help/guide).
:::

:::step Open a pull request
Describe the **scope of the change**. Once merged into `main`: into the main repository within 30 minutes, live within 2 hours.
:::

## Writing rules

:::step Only document what you verified
Commands and configuration must actually work for you. Mark uncertain parts with `:::warn` and state the applicable conditions.
:::

:::step Beginner friendly, but complete
Every step must be executable. Avoid vague wording such as "configure as needed".
:::

:::step Keep both languages in sync
When adding a Chinese guide, provide the English file with the same slug if you can. If not, the page falls back to Chinese with a badge.
:::

:::step Follow official sources for versions and commands
Version numbers, commands and download URLs must be checkable, with a link to the official source. Update or retire outdated content when upstream changes.
:::

:::danger
Do not upload pirated resources, cracks or paid content. This site only indexes publicly released resources and links to official sources.
:::

## Copyright

- Quoting others requires attribution and a licence note;
- Report infringement through the contact page and we will take it down.

## Community

The **only official community group** is the QQ group [1083430859](https://qm.qq.com/q/nRsqCiwHMm). Feel free to discuss a change before or after opening a pull request.

- Not sure how to make a change: describe the page and the problem in the group and we will suggest a concrete approach
- Want to follow up on a pull request: just ask in the group instead of opening repeated issues
- Note: the community rules apply in the group as well; advertising and pirated content are removed
