This site is maintained by the community. Contributions of guides, fixes and translations are welcome.

## What you can contribute

- **New guides** for setup, operations or troubleshooting you have solved yourself
- **Corrections** for outdated commands, wrong paths, version mismatches and typos
- **Translations** from Chinese to English, or fixes to existing translations
- **Resource entries** with complete metadata (version, size, checksum, homepage)

## Writing rules

:::step Only document what you verified
Commands and configuration must actually work for you. Mark uncertain parts with `:::warn` and state the applicable conditions.
:::

:::step Beginner friendly, but complete
Every step must be executable. Avoid vague wording such as "configure as needed".
:::

:::step Keep both languages in sync
When adding a Chinese guide, provide the English file with the same slug if you can. If not, the page falls back to Chinese with a badge.
:::

:::danger
Do not upload pirated resources, cracks or paid content. This site only indexes publicly released resources and links to official sources.
:::
