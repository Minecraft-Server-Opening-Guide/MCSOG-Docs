Before you open a Bedrock server, decide **which type of server you want to run**. The type determines which cores you can use, what you can install, and how much maintenance it costs.

Bedrock Edition has five mainstream types:

## 1. Vanilla Server

Runs **strictly by the official rules**, with no plugins and no add-ons.

- Yes Authentic, the most stable option, and almost maintenance-free (no worries about plugin compatibility or updates)
- No You get exactly what vanilla offers and nothing more
- Best for: offering a **fair and stable** vanilla experience; **BDS** fits best

## 2. Add-on Server (BDS only)

Loads officially supported **add-ons** (behavior packs / resource packs) on the official **BDS** to extend content.

- Yes Officially supported, good version compatibility, little impact on stability
- No Limited customization (you can add blocks, items, and mobs, but you cannot change server logic)
- Best for: keeping official features while adding some custom content

## 3. Plugin Server

Uses a **third-party server core** (Nukkit / PowerNukkitX / PocketMine-MP, etc.) with plugins to extend functionality substantially.

- Yes Highly customizable, many kinds of plugins, plenty of community tutorials
- No Possible plugin compatibility and stability problems; **official BDS does not support plugins on its own**, so you need a community loader
- Best for: building distinctive gameplay and willing to spend time tuning plugins

## 4. Minigame Server (a kind of plugin server)

Focused on minigames such as The Walls, SkyBlock, and mazes.

- Yes Highly entertaining, fast-paced, good for short sessions
- No Content must be **continuously updated** to keep players, so operating costs are high
- Best for: competitive or casual gameplay with people who can keep producing content

## 5. Hybrid Add-on + Plugin Server (BDS only)

Uses both official add-ons and community plugin loaders.

- Yes Combines official features with the freedom of plugins
- No Complex configuration, two systems to maintain, more compatibility issues, higher performance requirements
- Best for: server owners who are **experienced** and can handle compatibility problems

## How to Choose

| Your goal | Recommendation |
| --- | --- |
| Vanilla survival, stable and low-effort | **Vanilla server + BDS** |
| Add content without touching plugins | **Add-on server + BDS** |
| Rich gameplay and willing to tinker | **Plugin server** (Nukkit / PNX / PMMP) |
| Running minigames | Plugin server + minigame plugins |
| Both official features and plugins | **BDS + plugin loader** |

Once the type is settled, the next step is picking a specific core: see [Choosing a Bedrock Core](/tutorials/bedrock/cores).
