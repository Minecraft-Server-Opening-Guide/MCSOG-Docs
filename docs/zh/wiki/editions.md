Java 版与基岩版不是同一个游戏版本，红石、命令、模组机制都有差异，先看清区别再决定开哪个版本的服务端。

> 端口号与红石差异为官方既定设定；不同版本间细节可能微调，具体以对应版本的官方说明为准。

## 差异对照

| 项目 | Java 版 | 基岩版 |
| --- | --- | --- |
| 红石与命令 | 红石机制完整（含准连接等特性），命令功能最全 | 红石行为有差异（无准连接、活塞与黏性方块表现不同） |
| 模组与插件 | Fabric / Forge / NeoForge 与插件生态 | 以附加包（Add-on）为主 |
| 服务端选择 | Paper / Purpur / Fabric / Forge / Velocity | BDS / Nukkit / PocketMine-MP |
| 默认端口 | 25565（TCP） | 19132（UDP），IPv6 为 19133（UDP） |
| 跨端联机 | Java 服务器需装 Geyser 才能接受基岩版玩家（配 Floodgate 可免 Java 账号登录） | 基岩版服务器无法让 Java 版玩家进入 |
| 性能与优化 | 可选优化分支与启动参数最丰富 | 官方 BDS 优化选项少，主要靠系统调优 |
| 适合人群 | 想要插件、模组、自动化与大规模联机 | 手机 / 主机玩家、开箱即用联机 |

## 注意

基岩版服务端使用 UDP 19132，Java 版使用 TCP 25565。只放行 TCP 是最常见的连不上原因。

跨端工具 Geyser 是单向的：它让基岩版客户端连上 Java 版服务器；反向（Java 客户端进基岩版服务器）没有官方方案。Geyser 需要装在 Java 版服务器侧，基岩版官方服务端 BDS 无法安装。
