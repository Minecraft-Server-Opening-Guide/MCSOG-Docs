基岩版的核心生态比 Java 版小得多，主流就四个：

| 核心 | 语言 | 插件 | 一句话 |
| --- | --- | --- | --- |
| **BDS** | C++ | 需社区加载器 | 官方服务端，**兼容性最好** |
| **Nukkit（NK）** | Java | 原生 | 轻量、像基岩版的 Bukkit |
| **PowerNukkitX（PNX）** | Java | 原生 | Nukkit 的现代继承者，**多核优化** |
| **PocketMine-MP（PMMP）** | PHP | 原生 | 插件生态庞大，用 PHP 写 |

> 完整的逐项对照（性能、插件、生态、适用场景）见 **[服务端核心对比](/wiki/compare#mcsog-h-%E5%9F%BA%E5%B2%A9%E7%89%88%E6%A0%B8%E5%BF%83%E5%AF%B9%E6%AF%94)** 的「基岩版核心对比」一节。

## 一、BDS（官方）

Minecraft 官网提供的官方基岩版服务端，和 Java 版的 Vanilla 在同一页面。

**优势**

- **官方支持**：随官方更新，与最新版客户端兼容性最好；
- **稳定**：官方产品，运行可靠；
- **资源利用**：针对基岩版优化，能高效利用服务器资源；
- **安全更新**：官方会更频繁地修安全问题。

**劣势**

- **不支持插件**：官方服务端本身没有插件系统，要装插件只能靠**社区插件加载器**；
- **单线程瓶颈**：**生物运算跑在一个线程上**，所以流畅度**主要取决于 CPU 单核性能**；地图越大越卡，整体不如支持多核的 Java 服务端；
- **高级功能缺失**：自定义世界生成、高级权限管理等通常要第三方才能做；
- **内存缓慢增长**：占用会慢慢涨，严重时像内存泄漏。注意 **强行清理内存会导致玩家下载材质包/Addon 时进度条卡住**，只能重启服务端解决。

**适合**：要官方支持与兼容性、不需要复杂定制的服。**生存服首选**。

## 二、Nukkit（NK）

基岩版的"Bukkit"——用 **Java** 编写，生态与开发思路都很像 Java 版插件端。

**优势**：轻量（资源需求低）、性能不错、**有原生插件系统**、跨平台（Windows/Linux/macOS）、上手简单。

**劣势**：**更新滞后**（可能跟不上最新版与最新特性）、插件生态比 Spigot/Paper 小、多核优化不足、高质量文档较少、开源项目偶有稳定性问题。

**适合**：初学者与小型服务器。**注意**：原版 Nukkit 已不活跃，实际更推荐它的现代分支（见下）。

## 三、PowerNukkitX（PNX）

Nukkit 的**现代继承者**，目前基岩版第三方核心里的主力。

**优势**

- **支持最新基岩版协议**，能跟上新版本；
- **多核优化**：这是它相对 BDS 与旧 Nukkit 最大的优势；
- **384 格世界高度**；
- 内置 **Terra** 地形生成器，可做丰富地形；
- **完全开源、API 开放**，支持用 Java / Kotlin / Scala / Python / JavaScript / Lua 等 JVM 语言写插件；
- **兼容 Nukkit 生态的大量插件**。

**劣势**：开发强度受原 Nukkit 团队变动影响；生态相对主流 Java 服务端仍小；插件多，新手学习成本高。

**适合**：要**高性能 + 高度自定义**的服主。

## 四、PocketMine-MP（PMMP）

用 **PHP** 编写的基岩版服务端，插件生态最庞大。

**优势**：插件生态庞大、跨平台、**PHP 门槛低**（会 PHP 就能写插件）、社区活跃、自定义程度高。

**劣势**：**高玩家负载下有性能瓶颈**（内存管理与 CPU 效率）；更新滞后；装多个插件时稳定性下降；PHP 是解释型语言，**资源消耗更明显**；配置与插件管理需要学习。

**适合**：重视**插件功能与自定义**、且能接受一定性能妥协的服主。

## 五、怎么选

```
要稳定 + 官方兼容 + 原版生存
   → BDS（要插件就配社区加载器，见「BDS 服务端」）

要高性能 + 多核 + 高度自定义
   → PowerNukkitX

要最庞大的插件生态、会用 PHP
   → PocketMine-MP

想从简单的开始、玩 Nukkit 生态
   → Nukkit 系（但优先选活跃分支）
```

:::tip 先用最小规模验证
核心选定后，**先用小规模跑通**（几个人、少量插件）再对外开放。基岩版核心的兼容性坑比 Java 版多，别一上来就上全套插件。
:::
