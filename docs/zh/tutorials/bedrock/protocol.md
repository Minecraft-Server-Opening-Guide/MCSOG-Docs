基岩版开服最容易踩的坑不是配置，而是**版本**。这一篇讲清两件事：协议版本是什么，以及该选哪个游戏版本。

## 一、协议版本：客户端与服务器的"语言"

把协议版本理解成**双方对话用的语言版本**：

> 1.20.50 说的是"古汉语"（协议 **630**），1.20.60 说的是"现代汉语"（协议 **649**）。
> 两人语言不同就**互相听不懂**——所以 1.20.60 的客户端**连不上**跑 1.20.50 协议的服务器，会提示"所有玩家都应更新到最新版本后再试"。

也就是说：**客户端协议必须与服务端协议一致**才能进服。这与 Java 版的"版本兼容"逻辑不同，基岩版卡得更死。

### 协议什么时候变

- **通常**：修订号**十位**变化时改协议。例如 `1.20.10`–`1.20.15` 同为 **594**；`1.20.30` 起变为 **618**；`1.20.40` 起变为 **622**。
- **例外**：官方有时会在十位内也改协议。例如 `1.19.60`–`62` 与 `1.19.63` 协议不同；`1.21.0`–`1.21.1` 与 `1.21.2`–`1.21.3` 也不同。
- 大致**每五周左右**会有一个改协议的版本。

:::tip 查协议号
具体版本对应哪个协议号，以 **Minecraft Wiki** 的版本列表为准。
:::

## 二、该选哪个游戏版本

**结论先给**：没有明确需求，**就选最新版**。最新版服务端通常支持最新版客户端。

### 几个对玩家影响很大的客户端变化

这些更新官方说得轻描淡写，但对开服影响不小：

| 版本 | 影响 |
| --- | --- |
| **1.20.50** | 大量方块"扁平化"、代码重构 → **该版本以下的跨版本插件兼容性变差** |
| **1.20.40** | 新的触控布局可自定义位置 |
| **1.20.x**（约） | 安卓端出现**严重卡顿**问题，社区长期无解 |
| **1.19.50** | 加入新的触控布局 |
| **1.18.30** | 客户端实装**渲染龙** → **传统光影不能用了**，只能用硬件光追或延迟渲染 |

### 注意 "自动更新"才是最大的坑

各大应用商店默认**自动更新**客户端。基岩版每隔若干版本就要换协议，于是：

> 玩家的客户端在你不知情时自动更新 → **协议变了** → 他**进不了你的服务器** 否

Java 版很少遇到，因为自动更新只在官启里，而玩家不一定用官启。

**应对只有两条路**：

1. **持续跟进最新版**（把服务端也更新到最新）——推荐，也是社区默认做法；
2. **要求玩家固定版本**——但这条会带来下面的问题。

### 强制固定版本的代价

如果你选择固定某个旧版本：

- 否 **失去几乎所有 iOS 玩家**：iOS 系统的机制决定他们**只能装最新版**，无法安装指定安装包（社区至今没有完美解法）；
- 否 **失去所有只玩最新版的玩家**：跟进最新版的服务器与玩家群体都非常庞大；
- 否 客服要**人工指导**不会装 apk / appx 的小白。

此外，玩家本身也倾向于最新版：第三方应用商店优先提供最新版安装包；社区资讯也都围绕最新版；而且基岩版**跨平台切换版本很麻烦**，所以社区形成了"全员跟进最新版"的默契。

:::warn 选择固定版本前先算清损失
只有当上述损失**不会严重影响你的服务器人气**时，才考虑固定版本。否则请把服务端保持最新。
:::
