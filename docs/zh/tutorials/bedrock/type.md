开基岩版服务器前，先想清楚**你要开哪一类服**。类型决定了你能用什么核心、能装什么、以及维护成本。

基岩版主流有五类：

## 一、纯净服（原版服）

**完全按官方规则**跑，不加插件也不加 Addon。

- 可 原汁原味、最稳定、几乎零维护（不用担心插件兼容与更新）
- 否 功能就是原版那点东西
- 适合：想提供**公平稳定**的原版体验；用 **BDS** 最合适

## 二、Addon 服（仅 BDS）

在官方 **BDS** 上加载官方支持的 **Addon**（行为包 / 资源包）来扩展内容。

- 可 官方支持、与版本兼容性好、对稳定性影响小
- 否 定制能力有限（能加方块、物品、生物这类内容，但改不了服务器逻辑）
- 适合：想保留官方特性，又想加些自定义内容

## 三、插件服

用**第三方服务端核心**（Nukkit / PowerNukkitX / PocketMine-MP 等）装插件，大幅扩展功能。

- 可 高度自定义，插件种类多，社区教程多
- 否 可能有插件兼容与稳定性问题；**官方 BDS 本身不支持插件**，要靠社区加载器
- 适合：想做特色玩法、愿意花时间调插件

## 四、小游戏服（插件服的一种）

专注战墙、空岛、迷宫这类小游戏。

- 可 娱乐性强、节奏快、适合短时间游玩
- 否 内容要**持续更新**才能留住人，运营成本高
- 适合：想做竞技/休闲向、且有人力持续做内容

## 五、Addon + 插件混合服（仅 BDS）

既用官方 Addon，也通过社区插件加载器扩展。

- 可 兼得官方特性与插件自由度
- 否 配置复杂，两边都要管，兼容性问题更多，性能要求更高
- 适合：**有经验**、能处理兼容问题的服主

## 怎么选

| 你的目标 | 建议 |
| --- | --- |
| 原版生存、稳定省心 | **纯净服 + BDS** |
| 加内容但不想碰插件 | **Addon 服 + BDS** |
| 要丰富玩法、能折腾 | **插件服**（Nukkit / PNX / PMMP） |
| 做小游戏 | 插件服 + 小游戏插件 |
| 既要官方又要插件 | **BDS + 插件加载器** |

选好类型后，下一步是挑具体核心：见 [基岩版核心选择](/tutorials/bedrock/cores)。
