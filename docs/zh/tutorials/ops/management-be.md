基岩版的经营管理与 Java 版**底层逻辑相同**（见 [JAVA] 经营管理），但玩家群体与客户端形态带来几个**必须单独考虑**的点。这一篇只讲差异。

## 一、基岩版玩家群体的三个特点

| 特点 | 对经营的影响 |
| --- | --- |
| **手机端占比高** | 玩家年龄跨度大、**低龄玩家多**，规则要写得更直白，客服要更有耐心 |
| **客户端版本不可控** | 应用商店自动更新 → **协议一变就进不来**（见「协议版本与版本选择」） |
| **平台分散** | 安卓 / iOS / Windows / 主机，**每个平台的问题都不一样** |

## 二、玩家管理：比 Java 版更需要"前置门槛"

基岩版玩家流动性更高、小号成本更低（尤其安卓端），所以**事后处理很吃力**：

- **白名单 / 进服审核**：强烈建议开。基岩版没有 Java 那样成熟的反作弊生态，**把麻烦挡在门外**比事后封禁有效得多；
- **规则要短**：手机玩家不会读长文，规则写成几条硬性红线即可；
- **公告用图片**：基岩版聊天框小，重要公告做成图片发在群里更有效；
- **管理要在线**：低龄玩家冲突多，**同时段有人值守**是留人的关键。

## 三、客户端分发：基岩版特有的麻烦

Java 版让玩家用官方启动器就行，基岩版却常要**分发客户端安装包**：

- **安卓**：可以分发 `.apk`，但要注意**来源合法**（不要传播破解版）；
- **Windows**：`.appx` / `.msix` 安装对小白很困难，**需要图文教程**；
- **iOS**：注意 **无法安装指定版本**，只能用商店最新版 → **这是无法绕过的硬限制**（见下）。

:::warn iOS 玩家是"版本跟随者"
只要你固定旧版本，**iOS 玩家就全部进不来**。所以除非你明确放弃 iOS 群体，否则**保持服务端跟进最新版**是唯一现实选择。
:::

## 四、平台差异与技术支持

| 平台 | 常见问题 |
| --- | --- |
| **安卓** | 某些版本存在**严重卡顿**（社区长期无解）；安装包来源杂乱 |
| **iOS** | 只能装最新版；无法降级 |
| **Windows** | 渲染龙实装后**传统光影不可用**（1.18.30 起）；appx 安装困难 |
| **主机（Xbox/PS/Switch）** | **不能直接输 IP 加入**，通常只能通过**自定义 DNS 或局域网**连接 |

⇒ 客服工作量大，建议提前写好**分平台的图文教程**，把重复问题挡掉。

## 五、资金与团队

与 Java 版一致（见 [JAVA] 经营管理），补充两点基岩版特点：

- **资源占用更低**：同样的玩家数，基岩版对硬件的要求通常比 Java 版低，**小规模可以更省**；
- **但核心选择影响成本**：BDS 单核吃紧 → 想要更多玩家可能得**换更强的单核**；第三方核心（如 PowerNukkitX）能吃多核，但插件与稳定性要自己担。

## 六、时间：依然是最大门槛

这一条与 Java 版完全相同，且对基岩版**更严重**：

- 玩家以手机为主 → **在线时间更碎片化**，问题随时冒出来；
- 平台差异多 → 同一个问题要分四种客户端排查；
- 低龄玩家多 → 冲突调解占用的时间更多。

**先诚实评估自己每周能稳定投入多少小时**，再决定规模。

## 七、清单

- [ ] 规则写好（短、直白、可执行）
- [ ] 白名单 / 进服审核已开
- [ ] 分平台图文教程已备（安卓 / iOS / Windows / 主机）
- [ ] 管理同时段有人在线
- [ ] 服务端版本策略已定（推荐跟进最新版，否则失去 iOS 玩家）
- [ ] 自动备份已开（见「备份与恢复」）
- [ ] 玩家交流平台（群）已建并有人维护
