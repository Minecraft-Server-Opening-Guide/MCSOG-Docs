插件是**插件端**（Paper / Purpur / Spigot 等）最大的价值：不改客户端、不用玩家装任何东西，就能给服务器加功能。

## 一、先分清插件和模组

| | 插件 | 模组 |
| --- | --- | --- |
| 装在 | 服务端 `plugins/` | 客户端 + 服务端 `mods/` |
| 玩家要装东西吗 | **不用** | 通常要 |
| 用于 | 插件端核心 | 模组端核心（Fabric / Forge / NeoForge） |
| 能混用吗 | **不能**：插件端加载不了模组，模组端加载不了插件（除非用混合端或桥接方案） |

## 二、安装插件的标准流程

1. 下载插件的 `.jar` 文件。
2. 放进服务端根目录的 `plugins/` 文件夹。
3. **重启服务端**（多数插件不支持首次热加载）。
4. 看控制台：插件启动时通常会打印自己的名字与版本，报错也会在这里。
5. 用 `plugins` 指令确认状态（见下）。

### 用 `plugins` 判断加载状态

```
plugins          （简写 pl）
```

- **绿色**：已加载 可（注意：只代表**这次加载上了**，不代表运行时不会报错）
- **红色**：加载失败 否（服务端认出了它，但没加载成功，去控制台看报错）
- **完全没有**：服务端**根本没识别**它是插件 → 检查文件是否真的在 `plugins/`、后缀是否为 `.jar`、是否下错了核心类型（比如把模组当插件装）

## 三、前置插件（依赖）

很多插件自己不干活，只提供公共能力，**必须先装它**，否则目标插件会加载失败：

| 前置 | 提供什么 |
| --- | --- |
| **Vault** | 经济 / 权限 / 聊天的统一接口，大量插件依赖 |
| **PlaceholderAPI**（PAPI） | 变量占位符（如显示玩家余额、在线人数），插件间互相取数的通用方案 |
| **ProtocolLib** | 底层协议操作能力，许多高级插件的前置 |
| **LuckPerms** | 权限管理，精细控制谁能用什么指令 |

## 四、配置文件与 YAML

插件配置基本都在 `plugins/插件名/` 下，常见 `config.yml`。写 YAML 时最容易踩的坑：

- **缩进只能用空格，不能用 Tab**（这是 YAML 报错的第一大来源）。
- 冒号后面要有一个空格，如 `enabled: true`。
- 层级靠缩进表达，同一层缩进必须一致。

:::warn 中文乱码
配置文件里出现中文时如果显示成乱码，多半是**文件编码不是 UTF-8**（Windows 记事本另存为时容易变成 ANSI/GBK）。用 VS Code 之类的编辑器，另存为 **UTF-8** 即可。
:::

### 颜色代码

服务端文本（MOTD、聊天、插件提示）用 `&` 加字母表示颜色与样式，例如：

```
&a绿色  &c红色  &l加粗  &o斜体  &r重置
```

具体支持范围取决于服务端版本与插件。

## 五、改完配置怎么生效

| 方式 | 说明 |
| --- | --- |
| `/插件名 reload` 或 `/插件缩写 reload` | 多数插件支持，**首选**（如 `/tab reload`） |
| 重启服务端 | 最保险，但不支持热重载的插件只能这样 |
| `/reload`（原版指令） | **不推荐**，容易让插件状态错乱 |

## 六、按用途挑插件

| 用途 | 常见选择 |
| --- | --- |
| 权限 | LuckPerms |
| 基础功能（家、传送、礼包） | EssentialsX、CMI |
| **防破坏与回溯** | CoreProtect（查方块记录，出事能查是谁干的） |
| 领地保护 | Residence、Dominion、GriefDefender |
| 世界编辑 | WorldEdit（创世神）、WorldGuard（区域保护） |
| 多世界 | Multiverse-Core |
| 聊天格式 | TrChat、Carbon |
| 菜单 / GUI | DeluxeMenus、TrMenu |
| MOTD 与服务器列表 | MiniMOTD |
| 皮肤（离线模式必备） | SkinsRestorer |
| 登录（离线模式） | AuthMe、LibreLogin |
| 跨版本兼容 | ViaVersion + ViaBackwards |
| 插件热管理 | PlugManX |

一套常见的起步组合：**LuckPerms + EssentialsX + CoreProtect + WorldEdit/WorldGuard + Vault + PlaceholderAPI**，再按玩法加。

## 七、安全：插件也有"毒"

插件是**以服务端权限运行的第三方代码**，装错了后果很严重：

- **只从可信来源下载**：官方发布渠道（如 SpigotMC、Modrinth、Hangar）或作者仓库。论坛、群文件里转手的 jar 风险最高。
- **警惕后门**：有人会把正常插件重新打包，塞进执行任意指令、给特定玩家 OP、上传文件之类的代码。
- **注意维护状态**：长期不更新、作者跑路的插件，遇到新版本可能直接崩服。
- **不确定就先在测试服试**：别在主力服上直接装来路不明的插件。

:::tip 出问题先怀疑插件
服务器突然卡顿或报奇怪的错，**先把最近新装的插件禁用**，再逐个启用定位——这比读日志快得多。
:::
