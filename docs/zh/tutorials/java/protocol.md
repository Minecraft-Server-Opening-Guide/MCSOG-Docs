开服之前有两件事必须先定下来：**协议上能不能这么开**，以及**机器扛不扛得住**。这两件没弄清楚，后面装环境、装核心都是在浪费时间和钱。
:::note 这篇解决什么
① 官方协议对个人开服的边界；② 最低配置与推荐配置；③ 为什么 CPU 比内存更关键。
:::

## 一、官方协议：能做什么，不能做什么

Java 版服务端启动时必须同意 [Minecraft 最终用户许可协议（EULA）](https://aka.ms/MinecraftEULA)。做法很简单：第一次启动会生成 `eula.txt`，把 `eula=false` 改成 `eula=true`。**不改就是启动后立刻退出。**

| 事项 | 说明 |
| --- | --- |
| 私人服务器 | 可以自由搭建，朋友之间联机没有任何限制 |
| 分发服务端程序 | **不可以**转分发官方服务端 jar，只能从官方或核心官方渠道下载 |
| 收费 | 可以对服务器收费，但不能卖游戏本体、不能卖影响公平的原版游戏内容；具体以各核心与平台官方条款为准 |
| 使用官方名义 | **不可以**让玩家误以为你的服务器是 Mojang 官方运营的 |
| 正版验证 | `server.properties` 中 `online-mode=true` 为默认值，会校验正版账号 |
:::warn 关于离线模式
`online-mode=false`（俗称离线服）能降低门槛，但会同时失去账号保护：任何人都能冒用任意 ID 进服，也无法使用正版皮肤与 UUID 绑定。**仅在你完全清楚风险、且服务器不对外公开时使用。**
:::

## 二、配置推荐

### 最低配置（1～3 人，小服试水）

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| CPU | **2 核**（推荐 3GHz+ 单核高频） | 看单核性能，不看核心数 |
| 内存 | **4GB**（系统 1GB + MC 3GB） | 必须给系统留出余量 |
| 硬盘 | **20GB SSD** | 机械硬盘加载会很慢 |
| 网络 | 上行带宽**至少 10Mbps** | 上行才是瓶颈，下行大没有用 |

### 推荐配置（10 人以内，稳定长期开）

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| CPU | **4 核** | 单核频率仍然优先 |
| 内存 | **8GB**（MC 分配 6GB） | 剩下的留给系统与缓存 |
| 硬盘 | **50GB SSD** | 存档、备份、日志都会涨 |
| 网络 | 上行带宽 **30Mbps+** | 人多、装插件后更需要余量 |

### 为什么 CPU 比内存更关键

**Minecraft 服务端对 CPU 单核性能的要求远高于对内存的要求。** 主线程要串行处理实体、区块、红石与插件逻辑，这些几乎都压在**一个核心**上——核心再多，主线程也只有一个。

所以会出现这种情况：**一台 2 核 4G、但单核跑到 3.5GHz 的机器，实际比 8 核 2G 的机器更流畅。** 前者单核强、主线程不卡；后者核心虽多，却因为频率低、内存又不够，TPS 一样会掉。

选机器时的优先级：

1. **单核频率**（越高越好，3.5GHz 以上体验明显更好）
2. **内存容量**（够用即可，不足会 OOM 或频繁 GC）
3. **硬盘类型**（SSD 是硬性要求，影响区块加载与存档写入）
4. **核心数**（插件服、多开、代理端才需要更多核心）
:::tip 内存不是越大越好
分配给 MC 的 `-Xmx` 过大会带来两个副作用：① 单次 GC 停顿变长，表现为周期性卡顿；② 系统可用内存被挤占，反而更慢。**10 人以内分 4～6GB 通常足够**，剩下的留给系统。
:::

### 其他影响体验的因素

- **硬盘 IO**：世界越大、跑图越频繁，IO 压力越大。SSD 不只是"启动快"，它直接影响跑图时的卡顿。
- **上行带宽**：家用宽带通常上行远小于下行。开服前先确认**上行**有多少，而不是看套餐标的"500M"。
- **网络延迟**：玩家与服务器之间的物理距离决定基础延迟，国内玩家玩国内机房的服体验最好。
- **是否长期在线**：家用电脑睡眠或断电就会掉线；打算长期开服，云服务器或独立主机更合适。

## 三、接下来做什么

1. **选操作系统**：见 [操作系统选择](/tutorials/java/os)——长期开服优先 Linux，本地和熟人玩 Windows 也够用
2. **装环境**：见 [环境准备（Windows 与 Linux）](/tutorials/java/environment)——装对 Java、放行端口、建好目录
3. **选核心**：见 [服务端核心对比](/wiki/compare#mcsog-h-%E6%A0%B8%E5%BF%83%E5%AF%B9%E7%85%A7)——第一次开服通常直接选 Paper
:::note 小结
协议同意到位、**单核频率优先于核心数与内存**、SSD 与上行带宽达标——满足这三点，这台机器就能稳定开服。
:::
