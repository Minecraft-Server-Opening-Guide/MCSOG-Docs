很多玩家只在**手机 / 平板 / 主机**上玩 Minecraft，那是**基岩版**。默认情况下基岩版玩家**进不了 Java 版服务器**——两个版本协议完全不同。

用 **Geyser** 可以打通这条路，让你的 Java 服也能被手机玩家加入。

## 一、Geyser 是单向的（这点必须先搞清）

Geyser 官方 FAQ 写得很明确：

> **能否用 Geyser 让 Java 玩家连上我的基岩版服务器？**
> **不能。这是一个让基岩版玩家连上 Java 服务器的转换工具，反过来不行。**

所以：

| 方向 | 是否可行 | 方案 |
| --- | --- | --- |
| 基岩版玩家 → **Java 服** | 可行 | **Geyser**（+ Floodgate） |
| Java 玩家 → 基岩版服 | 无官方方案 | 不存在 |

**Geyser 装在 Java 服这一侧**；基岩版官方服务端（BDS）**装不了 Geyser**。

## 二、装在哪、怎么装

Geyser 有多个形态，按你的 Java 服类型选：

- **插件形态**：Spigot / Paper / Purpur 等插件端（最常见）
- **代理形态**：Velocity / BungeeCord（跨服结构下装在代理端）
- **模组形态**：Fabric / NeoForge
- **独立形态（standalone）**：不依赖上述平台，单独运行

装好后重启服务端，Geyser 会生成自己的配置文件。

## 三、关键：要开 UDP 端口

这是最容易漏的一步：

| 端口 | 协议 | 用途 |
| --- | --- | --- |
| `25565` | **TCP** | Java 玩家连接 |
| `19132` | **UDP** | **基岩版玩家连接（Geyser 监听）** |
| `19133` | UDP | 基岩版 IPv6 默认端口 |

:::warn 只开 TCP 是手机玩家连不上的头号原因
云服务器安全组、系统防火墙**两处**都要放行 **UDP 19132**。很多人只放行了 TCP 25565，然后一直纳闷"手机为什么连不上"。
:::

手机玩家在"添加服务器"里填：**地址 = 你的 IP 或域名，端口 = 19132**。

## 四、Floodgate：让手机玩家不用 Java 账号

默认情况下，Java 服开了正版验证，基岩版玩家**没有 Java 账号**，会被拒之门外。

**Floodgate** 就是解决这个的：它让基岩版玩家**用 Xbox 账号直接进入**，不需要购买 Java 版。

要点：

- Floodgate 通常与 Geyser 搭配安装；
- 基岩版玩家的名字会带一个**前缀**（默认 `.`），用来和 Java 玩家区分；
- 因此**白名单、封禁、指令**里写名字时要注意这个前缀，必要时用引号包住；
- 也可以用 Floodgate 的账号绑定功能，把基岩版账号与已有 Java 账号关联。

## 五、已知限制（提前告知玩家）

- **主机平台受限**：Xbox / PlayStation / Switch 玩家**不能直接输 IP 加入**，通常只能通过**自定义 DNS** 或**局域网**方式连接。
- **远距离视觉异常**：基岩版客户端是 32 位、Java 是 64 位，跑得很远时可能出现奇怪的位置/渲染问题（社区有非官方的缓解方案）。
- **部分插件不兼容**：Geyser 模拟的是 Java 客户端，绝大多数插件能用，但少数深度介入登录/协议的插件会冲突。
- **资源包要转格式**：Java 的资源包基岩版读不了，需要转成基岩版格式再给 Geyser 用。
- **模组服有限制**：如果服务器要求客户端装模组才能进，那 Geyser 也带不进去（"原版客户端能进，Geyser 才能进"）。

## 六、要不要开跨端

**适合开**：想扩大玩家来源、服里有手机玩家群体、玩法偏生存/建筑（对精确红石不敏感）。

**谨慎开**：**生电服**。基岩版与 Java 版的红石行为本就不同，跨端玩家看到的机制不一致，容易引发争议。
