本站由玩家社区维护，欢迎补充教程、修正错误、完善翻译。

## 可以贡献什么

- **新教程**：开服、运维、排障中你踩过坑并已解决的场景
- **修正**：命令过时、路径写错、版本不匹配、错别字
- **翻译**：把中文教程翻成英文，或修正现有译文
- **资源条目**：补全下载信息（版本、大小、校验和、官方主页）

## 写作规范

:::step 只写你验证过的内容
命令与配置必须是你亲自跑通的；不确定的地方标 `:::warn` 说明适用条件。
:::

:::step 面向新手，但不要省略关键步骤
每一步都能被执行，不要出现「按需配置」这类含糊表述。
:::

:::step 中英同步
新增中文教程时尽量同时提供英文文件（同 slug）。暂不提供也可以，页面会回退中文并标注。
:::

:::danger
不要上传任何盗版资源、破解工具或包含他人付费内容的文件。本站只收录公开发布的资源并跳转到官方来源。
:::

## 版权与署名

- 你贡献的原创内容默认允许本站以相同方式转载与修改；
- 引用他人内容必须注明来源与许可；
- 发现侵权内容请通过「联系我们」页面的邮箱反馈，我们会尽快下架。
