本页适用于本站的评论、交流群与任何以 MCSOG 名义进行的交流。目标是让提问的人得到答案，让回答的人愿意继续回答。

## 基本准则

- 友善交流：对事不对人，不人身攻击、不地域歧视、不嘲讽新手
- 尊重版权：不发布盗版资源、破解工具、外挂或规避正版验证的方法
- 不刷屏：不重复发同一条内容，不连续 @ 他人，不发布无意义字符
- 不广告：未经允许不发布服务器宣传、代开服、收费代维等商业内容
- 不违法：不讨论、不传播任何违反所在地法律法规的内容

## 提问规范

一句「开服失败怎么办」无法被回答。请尽量提供：

- 你用的**服务端核心与版本**（例如 Paper 1.21.4）
- 你用的**启动方式**（面板、systemd、命令行）
- **完整的报错日志**（贴文本，不要只截图，也不要只贴最后一行）
- 你已经**试过什么**，结果如何

## 编辑与投稿

- 修正错别字、补充命令输出、更新过期版本号，都欢迎直接提交
- 新增教程请先说明目标读者与前置条件，避免只写「点这里、点那里」
- 涉及第三方软件时请给出官方下载地址，不要放网盘转载
- 编辑规范详见「编辑指南」与「贡献与规范」

## 违规处理

| 情形 | 处理 |
| --- | --- |
| 首次轻微违规（刷屏、跑题） | 提醒并删除内容 |
| 重复违规或广告 | 禁言并清理历史内容 |
| 发布盗版、外挂、违法内容 | 直接移出，不再接受申诉 |
| 冒充他人或官方 | 直接移出 |
