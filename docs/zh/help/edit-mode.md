登录后如果账号权限里包含 **mcsog**，顶栏会出现编辑模式按钮。开启后页面底部出现编辑工具条，所有修改都会提交到 GitHub 仓库并自动同步到线上。

## 能改什么

:::step 页面文案
点「文案」打开词典列表（可按词条或内容搜索），也可以**直接点击页面上任意一句界面文字**，会反向查到对应的词典键并打开编辑框。
:::

:::step 文档与公告
在教程 / 公告 / 帮助页点「编辑本文」会打开 Markdown 编辑器，保存即写回 `docs/` 并提交。
:::

:::step 新建内容
「新建文档」填写类型、分类、语言、标识与标题即可创建，正文支持 `:::step`、`:::note`、`:::warn`、`:::danger`、代码围栏与表格。
:::

:::step 图片
「图片」上传 PNG / JPEG / WebP / GIF / AVIF，返回可直接引用的地址，同时提交进仓库。
:::

:::step 导航
「导航」可以给任意板块新增导航项，或删除现有项（改动写入 `nav.config.js`）。
:::

:::warn
编辑模式下服务器会以配置的密钥提交并推送；本地开发前请先 `git pull`，避免与线上提交分叉。
:::

## 权限与安全

- 权限来自 OAuth 提供方返回的 `permission` 字段，只有包含配置的令牌（默认 `mcsog`）才会显示编辑入口；
- 写入接口在服务端二次校验权限，并拒绝跨站来源的请求；
- 用于推送的 SSH 私钥以 **AES-256-GCM 加密**存放在 `config/edit.php`，运行时才解密到临时文件（0600）并在推送后立即删除；
- 图片上传限制 2 MB 且只接受真实图片类型。
