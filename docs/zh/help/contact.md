遇到问题、发现错误，或想提交资源与教程，都可以通过下面的渠道联系我们。

## 联系方式

:::step 内容纠错
在对应教程页面记录「页面路径 + 具体段落 + 你的修正建议」，发到下面的邮箱，标题建议以「纠错」开头。
:::

:::step 资源与友链
提供资源名称、官方主页、版本与许可信息；友链请附站名、链接与一句话简介。
:::

:::step 侵权与举报
请提供权利证明与具体链接，我们会在核实后处理。

:::note
本站是玩家社区维护的非官方网站，不提供 Minecraft 官方客服，也无法处理账号封禁、正版验证等官方事务。
:::

## 响应时间

| 类型 | 预计响应 |
|---|---|
| 侵权举报 | 3 个工作日内 |
| 内容纠错 | 7 个工作日内 |
| 友链与投稿 | 7 个工作日内 |
