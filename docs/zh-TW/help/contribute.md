本站由玩家社群維護，歡迎補充教學、修正錯誤、完善翻譯。所有內容都在公開倉庫 [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) 裡。

## 可以貢獻什麼

- **新教學**：開服、維運、排障中你踩過坑並已解決的場景
- **修正**：指令過時、路徑寫錯、版本不匹配、錯別字
- **翻譯**：把中文教學翻成英文，或修正現有譯文
- **資源條目**：補全下載資訊（版本、大小、校驗和、官方主頁）

## 提交流程

:::step 新建分支
Fork [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) 後新建分支，按[編輯指南](/help/guide)裡的目錄與命名新增檔案。
:::

:::step 提交 Pull Request
在 PR 裡說明**改動範圍**。合併進 `main` 後：30 分鐘內同步進主倉庫，2 小時內上線。
:::

## 寫作規範

:::step 只寫你驗證過的內容
指令與配置必須是你親自跑通的；不確定的地方標 `:::warn` 說明適用條件。
:::

:::step 面向新手，但不要省略關鍵步驟
每一步都能被執行，不要出現「按需配置」這類含糊表述。
:::

:::step 中英同步
新增中文教學時儘量同時提供英文檔案（同 slug）。暫不提供也可以，頁面會回退中文並標註。
:::

:::step 版本與指令以官方為準
版本號、指令、下載網址要能核對，並給出官方來源連結；上游變化後請及時更新或下線過期內容。
:::

:::danger
不要上傳任何盜版資源、破解工具或包含他人付費內容的檔案。本站只收錄公開發佈的資源並跳轉到官方來源。
:::

## 版權與署名

- 你貢獻的原創內容預設允許本站以相同方式轉載與修改；
- 引用他人內容必須註明來源與許可；
- 發現侵權內容請通過「聯絡我們」頁面的信箱回饋，我們會盡快下架。
