登入後如果帳號權限裡包含 **mcsog**，頂欄會出現編輯模式按鈕。開啟後頁面底部出現編輯工具列，所有修改都會提交到 GitHub 倉庫並自動同步到線上。

## 能改什麼

:::step 頁面文案
點「文案」開啟詞典列表（可按詞條或內容搜尋），也可以**直接點選頁面上任意一句介面文字**，會反向查到對應的詞典鍵並開啟編輯框。
:::

:::step 文件與公告
在教學 / 公告 / 幫助頁點「編輯本文」會開啟 Markdown 編輯器，儲存即寫回 `docs/` 並提交。
:::

:::step 新建內容
「新建文件」填寫類型、分類、語言、標識與標題即可建立，正文支援 `:::step`、`:::note`、`:::warn`、`:::danger`、程式碼圍欄與表格。
:::

:::step 圖片
「圖片」上傳 PNG / JPEG / WebP / GIF / AVIF，返回可直接引用的位址，同時提交進倉庫。
:::

:::step 導航
「導航」可以給任意板塊新增導航項，或刪除現有項（改動寫入 `nav.config.js`）。
:::

:::warn
編輯模式下伺服器會以配置的金鑰提交併推送；本地開發前請先 `git pull`，避免與線上提交分叉。
:::

## 權限與安全

- 權限來自 OAuth 提供方返回的 `permission` 欄位，只有包含配置的權杖（預設 `mcsog`）才會顯示編輯入口；
- 寫入介面在服務端二次校驗權限，並拒絕跨站來源的請求；
- 用於推送的 SSH 私鑰以 **AES-256-GCM 加密**存放在 `config/edit.php`，執行時才解密到臨時檔案（0600）並在推送後立即刪除；
- 圖片上傳限制 2 MB 且只接受真實圖片類型。
