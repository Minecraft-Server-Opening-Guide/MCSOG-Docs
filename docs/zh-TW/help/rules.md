本頁適用於本站的評論、交流群與任何以 MCSOG 名義進行的交流。目標是讓提問的人得到答案，讓回答的人願意繼續回答。

## 基本準則

- 友善交流：對事不對人，不人身攻擊、不地域歧視、不嘲諷新手
- 尊重版權：不發佈盜版資源、破解工具、外掛或規避正版驗證的方法
- 不刷屏：不重複發同一條內容，不連續 @ 他人，不發佈無意義字元
- 不廣告：未經允許不發佈伺服器宣傳、代開服、收費代維等商業內容
- 不違法：不討論、不傳播任何違反所在地法律法規的內容

## 提問規範

一句「開服失敗怎麼辦」無法被回答。請儘量提供：

- 你用的**服務端核心與版本**（例如 Paper 1.21.4）
- 你用的**啟動方式**（面板、systemd、命令列）
- **完整的報錯日誌**（貼文本，不要只截圖，也不要只貼最後一行）
- 你已經**試過什麼**，結果如何

## 編輯與投稿

- 修正錯別字、補充指令輸出、更新過期版本號，都歡迎直接提交
- 新增教學請先說明目標讀者與前置條件，避免只寫「點這裡、點那裡」
- 涉及第三方軟體時請給出官方下載網址，不要放網盤轉載
- 編輯規範詳見「編輯指南」與「貢獻與規範」

## 違規處理

| 情形 | 處理 |
| --- | --- |
| 首次輕微違規（刷屏、跑題） | 提醒並刪除內容 |
| 重複違規或廣告 | 禁言並清理歷史內容 |
| 發佈盜版、外掛、違法內容 | 直接移出，不再接受申訴 |
| 冒充他人或官方 | 直接移出 |
