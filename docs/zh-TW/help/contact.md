## 聯絡方式

:::step 內容糾錯
在對應教學頁面記錄「頁面路徑 + 具體段落 + 你的修正建議」，發到下面的信箱，標題建議以「糾錯」開頭。
:::

:::step 資源與友鏈
提供資源名稱、官方主頁、版本與許可資訊；友鏈請附站名、連結與一句話簡介。
:::

:::step 侵權與舉報
請提供權利證明與具體連結，我們會在核實後處理。

本站是玩家社群維護的非官方網站，不提供 Minecraft 官方客服，也無法處理帳號封禁、正版驗證等官方事務。
:::
