Java 版與基岩版不是同一個遊戲版本，紅石、命令、模組機制都有差異，先看清區別再決定開哪個版本的服務端。

> 埠號與紅石差異為官方既定設定；不同版本間細節可能微調，具體以對應版本的官方說明為準。

## 差異對照

| 專案 | Java 版 | 基岩版 |
| --- | --- | --- |
| 紅石與命令 | 紅石機制完整（含準連線等特性），命令功能最全 | 紅石行為有差異（無準連線、活塞與黏性方塊表現不同） |
| 模組與插件 | Fabric / Forge / NeoForge 與插件生態 | 以附加包（Add-on）為主 |
| 服務端選擇 | Paper / Purpur / Fabric / Forge / Velocity | BDS / Nukkit / PocketMine-MP |
| 預設埠 | 25565（TCP） | 19132（UDP），IPv6 為 19133（UDP） |
| 跨端聯機 | Java 伺服器需裝 Geyser 才能接受基岩版玩家（配 Floodgate 可免 Java 帳號登入） | 基岩版伺服器無法讓 Java 版玩家進入 |
| 效能與最佳化 | 可選最佳化分支與啟動參數最豐富 | 官方 BDS 最佳化選項少，主要靠系統調優 |
| 適合人群 | 想要插件、模組、自動化與大規模聯機 | 手機 / 主機玩家、開箱即用聯機 |

## 注意

基岩版服務端使用 UDP 19132，Java 版使用 TCP 25565。只放行 TCP 是最常見的連不上原因。

跨端工具 Geyser 是單向的：它讓基岩版客戶端連上 Java 版伺服器；反向（Java 客戶端進基岩版伺服器）沒有官方方案。Geyser 需要裝在 Java 版伺服器側，基岩版官方服務端 BDS 無法安裝。
