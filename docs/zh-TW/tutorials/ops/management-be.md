基岩版的經營管理與 Java 版**底層邏輯相同**（見 [JAVA] 經營管理），但玩家群體與客戶端形態帶來幾個**必須單獨考慮**的點。這一篇只講差異。

## 一、基岩版玩家群體的三個特點

| 特點 | 對經營的影響 |
| --- | --- |
| **手機端佔比高** | 玩家年齡跨度大、**低齡玩家多**，規則要寫得更直白，客服要更有耐心 |
| **客戶端版本不可控** | 應用商店自動更新 → **協議一變就進不來**（見「協議版本與版本選擇」） |
| **平台分散** | 安卓 / iOS / Windows / 主機，**每個平台的問題都不一樣** |

## 二、玩家管理：比 Java 版更需要"前置門檻"

基岩版玩家流動性更高、小號成本更低（尤其安卓端），所以**事後處理很吃力**：

- **白名單 / 進服審核**：強烈建議開。基岩版沒有 Java 那樣成熟的反作弊生態，**把麻煩擋在門外**比事後封禁有效得多；
- **規則要短**：手機玩家不會讀長文，規則寫成幾條硬性紅線即可；
- **公告用圖片**：基岩版聊天框小，重要公告做成圖片發在群裡更有效；
- **管理要線上**：低齡玩家衝突多，**同時段有人值守**是留人的關鍵。

## 三、客戶端分發：基岩版特有的麻煩

Java 版讓玩家用官方啟動器就行，基岩版卻常要**分發客戶端安裝包**：

- **安卓**：可以分發 `.apk`，但要注意**來源合法**（不要傳播破解版）；
- **Windows**：`.appx` / `.msix` 安裝對小白很困難，**需要圖文教學**；
- **iOS**：注意 **無法安裝指定版本**，只能用商店最新版 → **這是無法繞過的硬限制**（見下）。

:::warn iOS 玩家是"版本跟隨者"
只要你固定舊版本，**iOS 玩家就全部進不來**。所以除非你明確放棄 iOS 群體，否則**保持服務端跟進最新版**是唯一現實選擇。
:::

## 四、平台差異與技術支援

| 平台 | 常見問題 |
| --- | --- |
| **安卓** | 某些版本存在**嚴重卡頓**（社群長期無解）；安裝包來源雜亂 |
| **iOS** | 只能裝最新版；無法降級 |
| **Windows** | 渲染龍實裝後**傳統光影不可用**（1.18.30 起）；appx 安裝困難 |
| **主機（Xbox/PS/Switch）** | **不能直接輸 IP 加入**，通常只能通過**自定義 DNS 或區域網路**連線 |

⇒ 客服工作量大，建議提前寫好**分平台的圖文教學**，把重複問題擋掉。

## 五、資金與團隊

與 Java 版一致（見 [JAVA] 經營管理），補充兩點基岩版特點：

- **資源佔用更低**：同樣的玩家數，基岩版對硬體的要求通常比 Java 版低，**小規模可以更省**；
- **但核心選擇影響成本**：BDS 單核吃緊 → 想要更多玩家可能得**換更強的單核**；第三方核心（如 PowerNukkitX）能吃多核，但插件與穩定性要自己擔。

## 六、時間：依然是最大門檻

這一條與 Java 版完全相同，且對基岩版**更嚴重**：

- 玩家以手機為主 → **線上時間更碎片化**，問題隨時冒出來；
- 平台差異多 → 同一個問題要分四種客戶端排查；
- 低齡玩家多 → 衝突調解佔用的時間更多。

**先誠實評估自己每週能穩定投入多少小時**，再決定規模。

## 七、清單

- [ ] 規則寫好（短、直白、可執行）
- [ ] 白名單 / 進服審核已開
- [ ] 分平台圖文教學已備（安卓 / iOS / Windows / 主機）
- [ ] 管理同時段有人線上
- [ ] 服務端版本策略已定（推薦跟進最新版，否則失去 iOS 玩家）
- [ ] 自動備份已開（見「備份與恢復」）
- [ ] 玩家交流平台（群）已建並有人維護
