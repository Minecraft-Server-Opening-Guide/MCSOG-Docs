基岩版開服最容易踩的坑不是配置，而是**版本**。這一篇講清兩件事：協議版本是什麼，以及該選哪個遊戲版本。

## 一、協議版本：客戶端與伺服器的"語言"

把協議版本理解成**雙方對話用的語言版本**：

> 1.20.50 說的是"古漢語"（協議 **630**），1.20.60 說的是"現代漢語"（協議 **649**）。
> 兩人語言不同就**互相聽不懂**——所以 1.20.60 的客戶端**連不上**跑 1.20.50 協議的伺服器，會提示"所有玩家都應更新到最新版本後再試"。

也就是說：**客戶端協議必須與服務端協議一致**才能進服。這與 Java 版的"版本相容"邏輯不同，基岩版卡得更死。

### 協議什麼時候變

- **通常**：修訂號**十位**變化時改協議。例如 `1.20.10`–`1.20.15` 同為 **594**；`1.20.30` 起變為 **618**；`1.20.40` 起變為 **622**。
- **例外**：官方有時會在十位內也改協議。例如 `1.19.60`–`62` 與 `1.19.63` 協議不同；`1.21.0`–`1.21.1` 與 `1.21.2`–`1.21.3` 也不同。
- 大致**每五週左右**會有一個改協議的版本。

:::tip 查協議號
具體版本對應哪個協議號，以 **Minecraft Wiki** 的版本列表為準。
:::

## 二、該選哪個遊戲版本

**結論先給**：沒有明確需求，**就選最新版**。最新版服務端通常支援最新版客戶端。

### 幾個對玩家影響很大的客戶端變化

這些更新官方說得輕描淡寫，但對開服影響不小：

| 版本 | 影響 |
| --- | --- |
| **1.20.50** | 大量方塊"扁平化"、程式碼重構 → **該版本以下的跨版本插件相容性變差** |
| **1.20.40** | 新的觸控佈局可自定義位置 |
| **1.20.x**（約） | 安卓端出現**嚴重卡頓**問題，社群長期無解 |
| **1.19.50** | 加入新的觸控佈局 |
| **1.18.30** | 客戶端實裝**渲染龍** → **傳統光影不能用了**，只能用硬體光追或延遲渲染 |

### 注意 "自動更新"才是最大的坑

各大應用商店預設**自動更新**客戶端。基岩版每隔若干版本就要換協議，於是：

> 玩家的客戶端在你不知情時自動更新 → **協議變了** → 他**進不了你的伺服器** 否

Java 版很少遇到，因為自動更新只在官啟裡，而玩家不一定用官啟。

**應對只有兩條路**：

1. **持續跟進最新版**（把服務端也更新到最新）——推薦，也是社群預設做法；
2. **要求玩家固定版本**——但這條會帶來下面的問題。

### 強制固定版本的代價

如果你選擇固定某個舊版本：

- 否 **失去幾乎所有 iOS 玩家**：iOS 系統的機制決定他們**只能裝最新版**，無法安裝指定安裝包（社群至今沒有完美解法）；
- 否 **失去所有隻玩最新版的玩家**：跟進最新版的伺服器與玩家群體都非常龐大；
- 否 客服要**人工指導**不會裝 apk / appx 的小白。

此外，玩家本身也傾向於最新版：第三方應用商店優先提供最新版安裝包；社群資訊也都圍繞最新版；而且基岩版**跨平台切換版本很麻煩**，所以社群形成了"全員跟進最新版"的默契。

:::warn 選擇固定版本前先算清損失
只有當上述損失**不會嚴重影響你的伺服器人氣**時，才考慮固定版本。否則請把服務端保持最新。
:::
