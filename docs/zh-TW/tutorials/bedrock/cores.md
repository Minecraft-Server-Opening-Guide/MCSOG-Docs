基岩版的核心生態比 Java 版小得多，主流就四個：

| 核心 | 語言 | 插件 | 一句話 |
| --- | --- | --- | --- |
| **BDS** | C++ | 需社群載入器 | 官方服務端，**相容性最好** |
| **Nukkit（NK）** | Java | 原生 | 輕量、像基岩版的 Bukkit |
| **PowerNukkitX（PNX）** | Java | 原生 | Nukkit 的現代繼承者，**多核最佳化** |
| **PocketMine-MP（PMMP）** | PHP | 原生 | 插件生態龐大，用 PHP 寫 |

> 完整的逐項對照（效能、插件、生態、適用場景）見 **[服務端核心對比](/wiki/compare#mcsog-h-%E5%9F%BA%E5%B2%A9%E7%89%88%E6%A0%B8%E5%BF%83%E5%AF%B9%E6%AF%94)** 的「基岩版核心對比」一節。

## 一、BDS（官方）

Minecraft 官網提供的官方基岩版服務端，和 Java 版的 Vanilla 在同一頁面。

**優勢**

- **官方支援**：隨官方更新，與最新版客戶端相容性最好；
- **穩定**：官方產品，執行可靠；
- **資源利用**：針對基岩版最佳化，能高效利用伺服器資源；
- **安全更新**：官方會更頻繁地修安全問題。

**劣勢**

- **不支援插件**：官方服務端本身沒有插件系統，要裝插件只能靠**社群插件載入器**；
- **單執行緒瓶頸**：**生物運算跑在一個執行緒上**，所以流暢度**主要取決於 CPU 單核效能**；地圖越大越卡，整體不如支援多核的 Java 服務端；
- **高階功能缺失**：自定義世界生成、高階權限管理等通常要第三方才能做；
- **記憶體緩慢增長**：佔用會慢慢漲，嚴重時像記憶體洩漏。注意 **強行清理記憶體會導致玩家下載材質包/Addon 時進度條卡住**，只能重啟服務端解決。

**適合**：要官方支援與相容性、不需要複雜定製的服。**生存服首選**。

## 二、Nukkit（NK）

基岩版的"Bukkit"——用 **Java** 編寫，生態與開發思路都很像 Java 版插件端。

**優勢**：輕量（資源需求低）、效能不錯、**有原生插件系統**、跨平台（Windows/Linux/macOS）、上手簡單。

**劣勢**：**更新滯後**（可能跟不上最新版與最新特性）、插件生態比 Spigot/Paper 小、多核最佳化不足、高質量文件較少、開源專案偶有穩定性問題。

**適合**：初學者與小型伺服器。**注意**：原版 Nukkit 已不活躍，實際更推薦它的現代分支（見下）。

## 三、PowerNukkitX（PNX）

Nukkit 的**現代繼承者**，目前基岩版第三方核心裡的主力。

**優勢**

- **支援最新基岩版協議**，能跟上新版本；
- **多核最佳化**：這是它相對 BDS 與舊 Nukkit 最大的優勢；
- **384 格世界高度**；
- 內建 **Terra** 地形生成器，可做豐富地形；
- **完全開源、API 開放**，支援用 Java / Kotlin / Scala / Python / JavaScript / Lua 等 JVM 語言寫插件；
- **相容 Nukkit 生態的大量插件**。

**劣勢**：開發強度受原 Nukkit 團隊變動影響；生態相對主流 Java 服務端仍小；插件多，新手學習成本高。

**適合**：要**高效能 + 高度自定義**的服主。

## 四、PocketMine-MP（PMMP）

用 **PHP** 編寫的基岩版服務端，插件生態最龐大。

**優勢**：插件生態龐大、跨平台、**PHP 門檻低**（會 PHP 就能寫插件）、社群活躍、自定義程度高。

**劣勢**：**高玩家負載下有效能瓶頸**（記憶體管理與 CPU 效率）；更新滯後；裝多個插件時穩定性下降；PHP 是解釋型語言，**資源消耗更明顯**；配置與插件管理需要學習。

**適合**：重視**插件功能與自定義**、且能接受一定效能妥協的服主。

## 五、怎麼選

```
要稳定 + 官方兼容 + 原版生存
   → BDS（要插件就配社区加载器，见「BDS 服务端」）

要高性能 + 多核 + 高度自定义
   → PowerNukkitX

要最庞大的插件生态、会用 PHP
   → PocketMine-MP

想从简单的开始、玩 Nukkit 生态
   → Nukkit 系（但优先选活跃分支）
```

:::tip 先用最小規模驗證
核心選定後，**先用小規模跑通**（幾個人、少量插件）再對外開放。基岩版核心的相容性坑比 Java 版多，別一上來就上全套插件。
:::
