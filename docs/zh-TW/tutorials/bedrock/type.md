開基岩版伺服器前，先想清楚**你要開哪一類服**。類型決定了你能用什麼核心、能裝什麼、以及維護成本。

基岩版主流有五類：

## 一、純淨服（原版服）

**完全按官方規則**跑，不加插件也不加 Addon。

- 可 原汁原味、最穩定、幾乎零維護（不用擔心插件相容與更新）
- 否 功能就是原版那點東西
- 適合：想提供**公平穩定**的原版體驗；用 **BDS** 最合適

## 二、Addon 服（僅 BDS）

在官方 **BDS** 上載入官方支援的 **Addon**（行為包 / 資源包）來擴充內容。

- 可 官方支援、與版本相容性好、對穩定性影響小
- 否 定製能力有限（能加方塊、物品、生物這類內容，但改不了伺服器邏輯）
- 適合：想保留官方特性，又想加些自定義內容

## 三、插件服

用**第三方服務端核心**（Nukkit / PowerNukkitX / PocketMine-MP 等）裝插件，大幅擴充功能。

- 可 高度自定義，插件種類多，社群教學多
- 否 可能有插件相容與穩定性問題；**官方 BDS 本身不支援插件**，要靠社群載入器
- 適合：想做特色玩法、願意花時間調插件

## 四、小遊戲服（插件服的一種）

專注戰牆、空島、迷宮這類小遊戲。

- 可 娛樂性強、節奏快、適合短時間遊玩
- 否 內容要**持續更新**才能留住人，運營成本高
- 適合：想做競技/休閒向、且有人力持續做內容

## 五、Addon + 插件混合服（僅 BDS）

既用官方 Addon，也通過社群插件載入器擴充。

- 可 兼得官方特性與插件自由度
- 否 配置複雜，兩邊都要管，相容性問題更多，效能要求更高
- 適合：**有經驗**、能處理相容問題的服主

## 怎麼選

| 你的目標 | 建議 |
| --- | --- |
| 原版生存、穩定省心 | **純淨服 + BDS** |
| 加內容但不想碰插件 | **Addon 服 + BDS** |
| 要豐富玩法、能折騰 | **插件服**（Nukkit / PNX / PMMP） |
| 做小遊戲 | 插件服 + 小遊戲插件 |
| 既要官方又要插件 | **BDS + 插件載入器** |

選好類型後，下一步是挑具體核心：見 [基岩版核心選擇](/tutorials/bedrock/cores)。
