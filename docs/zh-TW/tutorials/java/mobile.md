很多玩家只在**手機 / 平板 / 主機**上玩 Minecraft，那是**基岩版**。預設情況下基岩版玩家**進不了 Java 版伺服器**——兩個版本協議完全不同。

用 **Geyser** 可以打通這條路，讓你的 Java 服也能被手機玩家加入。

## 一、Geyser 是單向的（這點必須先搞清）

Geyser 官方 FAQ 寫得很明確：

> **能否用 Geyser 讓 Java 玩家連上我的基岩版伺服器？**
> **不能。這是一個讓基岩版玩家連上 Java 伺服器的轉換工具，反過來不行。**

所以：

| 方向 | 是否可行 | 方案 |
| --- | --- | --- |
| 基岩版玩家 → **Java 服** | 可行 | **Geyser**（+ Floodgate） |
| Java 玩家 → 基岩版服 | 無官方方案 | 不存在 |

**Geyser 裝在 Java 服這一側**；基岩版官方服務端（BDS）**裝不了 Geyser**。

## 二、裝在哪、怎麼裝

Geyser 有多個形態，按你的 Java 服類型選：

- **插件形態**：Spigot / Paper / Purpur 等插件端（最常見）
- **代理形態**：Velocity / BungeeCord（跨服結構下裝在代理端）
- **模組形態**：Fabric / NeoForge
- **獨立形態（standalone）**：不依賴上述平台，單獨執行

裝好後重啟服務端，Geyser 會生成自己的設定檔。

## 三、關鍵：要開 UDP 埠

這是最容易漏的一步：

| 埠 | 協議 | 用途 |
| --- | --- | --- |
| `25565` | **TCP** | Java 玩家連線 |
| `19132` | **UDP** | **基岩版玩家連線（Geyser 監聽）** |
| `19133` | UDP | 基岩版 IPv6 預設埠 |

:::warn 只開 TCP 是手機玩家連不上的頭號原因
雲伺服器安全組、系統防火牆**兩處**都要放行 **UDP 19132**。很多人只放行了 TCP 25565，然後一直納悶"手機為什麼連不上"。
:::

手機玩家在"新增伺服器"裡填：**位址 = 你的 IP 或域名，埠 = 19132**。

## 四、Floodgate：讓手機玩家不用 Java 帳號

預設情況下，Java 服開了正版驗證，基岩版玩家**沒有 Java 帳號**，會被拒之門外。

**Floodgate** 就是解決這個的：它讓基岩版玩家**用 Xbox 帳號直接進入**，不需要購買 Java 版。

要點：

- Floodgate 通常與 Geyser 搭配安裝；
- 基岩版玩家的名字會帶一個**字首**（預設 `.`），用來和 Java 玩家區分；
- 因此**白名單、封禁、指令**裡寫名字時要注意這個字首，必要時用引號包住；
- 也可以用 Floodgate 的帳號繫結功能，把基岩版帳號與已有 Java 帳號關聯。

## 五、已知限制（提前告知玩家）

- **主機平台受限**：Xbox / PlayStation / Switch 玩家**不能直接輸 IP 加入**，通常只能通過**自定義 DNS** 或**區域網路**方式連線。
- **遠距離視覺異常**：基岩版客戶端是 32 位、Java 是 64 位，跑得很遠時可能出現奇怪的位置/渲染問題（社群有非官方的緩解方案）。
- **部分插件不相容**：Geyser 模擬的是 Java 客戶端，絕大多數插件能用，但少數深度介入登入/協議的插件會衝突。
- **資源包要轉格式**：Java 的資源包基岩版讀不了，需要轉成基岩版格式再給 Geyser 用。
- **模組服有限制**：如果伺服器要求客戶端裝模組才能進，那 Geyser 也帶不進去（"原版客戶端能進，Geyser 才能進"）。

## 六、要不要開跨端

**適合開**：想擴大玩家來源、服裡有手機玩家群體、玩法偏生存/建築（對精確紅石不敏感）。

**謹慎開**：**生電服**。基岩版與 Java 版的紅石行為本就不同，跨端玩家看到的機制不一致，容易引發爭議。
