開服之前有兩件事必須先定下來：**協議上能不能這麼開**，以及**機器扛不扛得住**。這兩件沒弄清楚，後面裝環境、裝核心都是在浪費時間和錢。
:::note 這篇解決什麼
① 官方協議對個人開服的邊界；② 最低配置與推薦配置；③ 為什麼 CPU 比記憶體更關鍵。
:::

## 一、官方協議：能做什麼，不能做什麼

Java 版服務端啟動時必須同意 [Minecraft 最終使用者許可協議（EULA）](https://aka.ms/MinecraftEULA)。做法很簡單：第一次啟動會生成 `eula.txt`，把 `eula=false` 改成 `eula=true`。**不改就是啟動後立刻退出。**

| 事項 | 說明 |
| --- | --- |
| 私人伺服器 | 可以自由搭建，朋友之間連線沒有任何限制 |
| 分發服務端程式 | **不可以**轉分發官方服務端 jar，只能從官方或核心官方渠道下載 |
| 收費 | 可以對伺服器收費，但不能賣遊戲本體、不能賣影響公平的原版遊戲內容；具體以各核心與平台官方條款為準 |
| 使用官方名義 | **不可以**讓玩家誤以為你的伺服器是 Mojang 官方運營的 |
| 正版驗證 | `server.properties` 中 `online-mode=true` 為預設值，會校驗正版帳號 |
:::warn 關於離線模式
`online-mode=false`（俗稱離線服）能降低門檻，但會同時失去帳號保護：任何人都能冒用任意 ID 進服，也無法使用正版皮膚與 UUID 繫結。**僅在你完全清楚風險、且伺服器不對外公開時使用。**
:::

## 二、配置推薦

### 最低配置（1～3 人，小服試水）

| 專案 | 要求 | 說明 |
| --- | --- | --- |
| CPU | **2 核**（推薦 3GHz+ 單核高頻） | 看單核效能，不看核心數 |
| 記憶體 | **4GB**（系統 1GB + MC 3GB） | 必須給系統留出餘量 |
| 硬碟 | **20GB SSD** | 機械硬碟載入會很慢 |
| 網路 | 上行頻寬**至少 10Mbps** | 上行才是瓶頸，下行大沒有用 |

### 推薦配置（10 人以內，穩定長期開）

| 專案 | 要求 | 說明 |
| --- | --- | --- |
| CPU | **4 核** | 單核頻率仍然優先 |
| 記憶體 | **8GB**（MC 分配 6GB） | 剩下的留給系統與快取 |
| 硬碟 | **50GB SSD** | 存檔、備份、日誌都會漲 |
| 網路 | 上行頻寬 **30Mbps+** | 人多、裝插件後更需要餘量 |

### 生電服配置（跑機器與世吞）

| 專案 | 要求 | 說明 |
| --- | --- | --- |
| CPU | **8 核**（推薦 4.5GHz+ 單核高頻） | 世吞、切門與大型機器幾乎全壓在一個核心上，核心數主要是給子服與後台留餘量 |
| 記憶體 | **16~32GB** | 考慮到開多個子服：每個子服都要獨立分配記憶體，系統與快取也要留出餘量 |
| 硬碟 | **120GB+** | 考慮到備份：機器一動土，存檔與備份的增長速度遠快於普通生存服 |
| 網路 | 上行頻寬 **100Mbps+** | 投影同步、多人同屏與大量實體資料包都要走上行，餘量必須留夠 |

### 為什麼 CPU 比記憶體更關鍵

**Minecraft 服務端對 CPU 單核效能的要求遠高於對記憶體的要求。** 主執行緒要序列處理實體、區塊、紅石與插件邏輯，這些幾乎都壓在**一個核心**上——核心再多，主執行緒也只有一個。

所以會出現這種情況：**一台 2 核 4G、但單核跑到 3.5GHz 的機器，實際比 8 核 2G 的機器更流暢。** 前者單核強、主執行緒不卡；後者核心雖多，卻因為頻率低、記憶體又不夠，TPS 一樣會掉。

選機器時的優先順序：

1. **單核頻率**（越高越好，3.5GHz 以上體驗明顯更好）
2. **記憶體容量**（夠用即可，不足會 OOM 或頻繁 GC）
3. **硬碟類型**（SSD 是硬性要求，影響區塊載入與存檔寫入）
4. **核心數**（插件服、多開、代理端才需要更多核心）
:::tip 記憶體不是越大越好
分配給 MC 的 `-Xmx` 過大會帶來兩個副作用：① 單次 GC 停頓變長，表現為週期性卡頓；② 系統可用記憶體被擠佔，反而更慢。**10 人以內分 4～6GB 通常足夠**，剩下的留給系統。
:::

### 其他影響體驗的因素

- **硬碟 IO**：世界越大、跑圖越頻繁，IO 壓力越大。SSD 不只是"啟動快"，它直接影響跑圖時的卡頓。
- **上行頻寬**：家用寬頻通常上行遠小於下行。開服前先確認**上行**有多少，而不是看套餐標的"500M"。
- **網路延遲**：玩家與伺服器之間的物理距離決定基礎延遲，國內玩家玩國內機房的服體驗最好。
- **是否長期線上**：家用電腦睡眠或斷電就會掉線；打算長期開服，雲伺服器或獨立主機更合適。

## 三、接下來做什麼

1. **選作業系統**：見 [作業系統選擇](/tutorials/java/os)——長期開服優先 Linux，本地和熟人玩 Windows 也夠用
2. **裝環境**：見 [環境準備（Windows 與 Linux）](/tutorials/java/environment)——裝對 Java、放行埠、建好目錄
3. **選核心**：見 [服務端核心對比](/wiki/compare#mcsog-h-%E6%A0%B8%E5%BF%83%E5%AF%B9%E7%85%A7)——第一次開服通常直接選 Paper
:::note 小結
協議同意到位、**單核頻率優先於核心數與記憶體**、SSD 與上行頻寬達標——滿足這三點，這台機器就能穩定開服。
:::
