插件是**插件端**（Paper / Purpur / Spigot 等）最大的價值：不改客戶端、不用玩家裝任何東西，就能給伺服器加功能。

## 一、先分清插件和模組

| | 插件 | 模組 |
| --- | --- | --- |
| 裝在 | 服務端 `plugins/` | 客戶端 + 服務端 `mods/` |
| 玩家要裝東西嗎 | **不用** | 通常要 |
| 用於 | 插件端核心 | 模組端核心（Fabric / Forge / NeoForge） |
| 能混用嗎 | **不能**：插件端載入不了模組，模組端載入不了插件（除非用混合端或橋接方案） |

## 二、安裝插件的標準流程

1. 下載插件的 `.jar` 檔案。
2. 放進服務端根目錄的 `plugins/` 資料夾。
3. **重啟服務端**（多數插件不支援首次熱載入）。
4. 看控制台：插件啟動時通常會列印自己的名字與版本，報錯也會在這裡。
5. 用 `plugins` 指令確認狀態（見下）。

### 用 `plugins` 判斷載入狀態

```
plugins          （简写 pl）
```

- **綠色**：已載入 可（注意：只代表**這次載入上了**，不代表執行時不會報錯）
- **紅色**：載入失敗 否（服務端認出了它，但沒載入成功，去控制台看報錯）
- **完全沒有**：服務端**根本沒識別**它是插件 → 檢查檔案是否真的在 `plugins/`、字尾是否為 `.jar`、是否下錯了核心類型（比如把模組當插件裝）

## 三、前置插件（依賴）

很多插件自己不幹活，只提供公共能力，**必須先裝它**，否則目標插件會載入失敗：

| 前置 | 提供什麼 |
| --- | --- |
| **Vault** | 經濟 / 權限 / 聊天的統一介面，大量插件依賴 |
| **PlaceholderAPI**（PAPI） | 變數佔位符（如顯示玩家餘額、線上人數），插件間互相取數的通用方案 |
| **ProtocolLib** | 底層協議操作能力，許多高階插件的前置 |
| **LuckPerms** | 權限管理，精細控制誰能用什麼指令 |

## 四、設定檔與 YAML

插件配置基本都在 `plugins/插件名/` 下，常見 `config.yml`。寫 YAML 時最容易踩的坑：

- **縮排只能用空格，不能用 Tab**（這是 YAML 報錯的第一大來源）。
- 冒號後面要有一個空格，如 `enabled: true`。
- 層級靠縮排表達，同一層縮排必須一致。

:::warn 中文亂碼
設定檔裡出現中文時如果顯示成亂碼，多半是**檔案編碼不是 UTF-8**（Windows 記事本另存為時容易變成 ANSI/GBK）。用 VS Code 之類的編輯器，另存為 **UTF-8** 即可。
:::

### 顏色程式碼

服務端文本（MOTD、聊天、插件提示）用 `&` 加字母表示顏色與樣式，例如：

```
&a绿色  &c红色  &l加粗  &o斜体  &r重置
```

具體支援範圍取決於服務端版本與插件。

## 五、改完配置怎麼生效

| 方式 | 說明 |
| --- | --- |
| `/插件名 reload` 或 `/插件缩写 reload` | 多數插件支援，**首選**（如 `/tab reload`） |
| 重啟服務端 | 最保險，但不支援熱過載的插件只能這樣 |
| `/reload`（原版指令） | **不推薦**，容易讓插件狀態錯亂 |

## 六、按用途挑插件

| 用途 | 常見選擇 |
| --- | --- |
| 權限 | LuckPerms |
| 基礎功能（家、傳送、禮包） | EssentialsX、CMI |
| **防破壞與回溯** | CoreProtect（查方塊記錄，出事能查是誰幹的） |
| 領地保護 | Residence、Dominion、GriefDefender |
| 世界編輯 | WorldEdit（創世神）、WorldGuard（區域保護） |
| 多世界 | Multiverse-Core |
| 聊天格式 | TrChat、Carbon |
| 選單 / GUI | DeluxeMenus、TrMenu |
| MOTD 與伺服器列表 | MiniMOTD |
| 皮膚（離線模式必備） | SkinsRestorer |
| 登入（離線模式） | AuthMe、LibreLogin |
| 跨版本相容 | ViaVersion + ViaBackwards |
| 插件熱管理 | PlugManX |

一套常見的起步組合：**LuckPerms + EssentialsX + CoreProtect + WorldEdit/WorldGuard + Vault + PlaceholderAPI**，再按玩法加。

## 七、安全：插件也有"毒"

插件是**以服務端權限執行的第三方程式碼**，裝錯了後果很嚴重：

- **只從可信來源下載**：官方發佈渠道（如 SpigotMC、Modrinth、Hangar）或作者倉庫。論壇、群檔案裡轉手的 jar 風險最高。
- **警惕後門**：有人會把正常插件重新打包，塞進執行任意指令、給特定玩家 OP、上傳檔案之類的程式碼。
- **注意維護狀態**：長期不更新、作者跑路的插件，遇到新版本可能直接崩服。
- **不確定就先在測試服試**：別在主力服上直接裝來路不明的插件。

:::tip 出問題先懷疑插件
伺服器突然卡頓或報奇怪的錯，**先把最近新裝的插件停用**，再逐個啟用定位——這比讀日誌快得多。
:::
