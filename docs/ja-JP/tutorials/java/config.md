サーバーを初めて起動すると、ルートディレクトリに `server.properties` が生成されます。**変更はサーバーの再起動後に反映されます**（ホットリロードはされません）。

テキストエディタで開いてください。以下は最もよく変更する項目です。

## 1. 最もよく変更する項目

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| `server-port` | `25565` | サーバーが待ち受けるポート。変更したらファイアウォール／セキュリティグループも合わせて変更する |
| `online-mode` | `true` | **正規アカウント認証**。`true` のままだと非正規のクライアントは入れない。`false` にするとオフラインモード |
| `max-players` | `20` | 同時接続の最大人数 |
| `motd` | — | サーバー一覧に表示される 1 行（カラーコードに対応） |
| `difficulty` | `easy` | `peaceful`/`easy`/`normal`/`hard`（`0`〜`3` も可） |
| `gamemode` | `survival` | 新規プレイヤーの既定モード：`survival`/`creative`/`adventure`/`spectator` |
| `force-gamemode` | `false` | `true` にすると、参加のたびに既定モードへ強制で戻す |
| `pvp` | `true` | プレイヤー同士の攻撃を許可するか |
| `allow-flight` | `false` | サバイバルで飛行を許可するか（飛行系プラグインを入れる場合は有効化を推奨） |
| `spawn-protection` | `16` | スポーン地点の保護半径。この範囲内で破壊・設置ができるのは OP のみ。`0` で無効 |
| `allow-nether` | `true` | ネザーへの移動を許可するか（`false` でネザーが無効になる） |
| `generate-structures` | `true` | 新しいチャンクに村などの構造物を生成するか |
| `level-seed` | 空 | ワールドのシード。空ならランダム |
| `enable-command-block` | `false` | コマンドブロックを有効にするか。**基本的に有効化は推奨しない**（下記参照） |
| `white-list` | `false` | ホワイトリストを有効にするか |
| `view-distance` | `10` | **描画距離**。性能への影響が最も大きい項目のひとつ |
| `simulation-distance` | `10` | **シミュレーション距離**。この範囲内のエンティティ／レッドストーンだけが演算される |

### 描画距離とシミュレーション距離について

この 2 つは**性能への負荷が最も大きいつまみ**で、コアを替えるより即効性があります：

- `view-distance` はプレイヤーが「見える」距離を決めます。下げると帯域と CPU を大幅に節約できますが、遠くが霧がかって見えます。
- `simulation-distance` はどの距離までのチャンクが**実際に演算される**か（スポーン、レッドストーン、作物の成長）を決めます。描画距離を下げるより節約効果が大きく、見た目にも影響しません。

:::tip まずこの 2 つを調整し、そのあとハードウェアの増強を検討する
「サーバーが重い」の多くは、`simulation-distance` を 10 から 6 に下げるだけで明らかに改善します。
:::

### コマンドブロックについて

`enable-command-block` は既定で無効で、**多くの場合に有効化は推奨しません**。コマンドブロックのサーバー側実装は効率が低く、その機能のほとんどはプラグインでより効率よく実現できます（しかもプラグインなら権限制御と監査も可能）。バニラのコマンドブロックによるゲームプレイが本当に必要な場合だけ有効にしてください。

## 2. 正規アカウント認証とオフラインモード

- `online-mode=true`（既定）：Mojang にアカウントを照会し、非正規のクライアントは入れません。
- `online-mode=false`：誰でも入れますが、**誰でも任意の ID を騙って入れ**、正規のスキンや UUID の紐づけも使えません。

特別な理由でオフラインモードを使う必要がある場合は、通常 `SkinsRestorer` などのスキンプラグインを併用してスキン表示を補います。

:::warn オフラインモードの代償
オフラインモードではアカウントに一切の保証がありません。BAN は別の ID で回避でき、管理者権限もなりすまされやすくなります。**公開サーバーでは正規アカウント認証を無効にしないことをおすすめします。**
:::

## 3. ゲームルール（gamerule）

難易度やスポーン保護などは `server.properties` で変更しますが、**ゲームルールはコマンドで変更**します：

```
/gamerule keepInventory true        死亡不掉落
/gamerule doDaylightCycle false     关闭昼夜更替
/gamerule mobGriefing false         苦力怕不破坏方块
/gamerule announceAdvancements false 不公告进度达成
```

コンソールまたはゲーム内（OP が必要）で実行すれば、**即座に反映され保存されます**。

## 4. 設定変更の基本的な流れ

1. `server.properties` を変更する前に**サーバーを停止**する（ワールド関連の設定を変えるときは特に必須。書き込みの競合を避けるため）。
2. 変更する前に**元のファイルをバックアップ**しておけば、問題が起きたときすぐ戻せます。
3. 再起動後に `logs/latest.log` を見て、設定関連のエラーがないか確認する。
4. プラグインの設定は `plugins/プラグイン名/config.yml` にあり、多くは `/プラグイン名 reload` でホットリロードできますが、**サーバー自身の設定はホットリロードできません**。
