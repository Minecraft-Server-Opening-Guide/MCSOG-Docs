統合版のコアのエコシステムは Java 版よりずっと小さく、主流は 4 つです：

| コア | 言語 | プラグイン | ひとこと |
| --- | --- | --- | --- |
| **BDS** | C++ | コミュニティのローダーが必要 | 公式サーバー。**互換性が最良** |
| **Nukkit（NK）** | Java | ネイティブ | 軽量。統合版の Bukkit のようなもの |
| **PowerNukkitX（PNX）** | Java | ネイティブ | Nukkit の現代的な後継。**マルチコア最適化** |
| **PocketMine-MP（PMMP）** | PHP | ネイティブ | プラグインのエコシステムが巨大。PHP で書く |

> 項目ごとの完全な対照（性能、プラグイン、エコシステム、用途）は **[サーバーコア比較](/wiki/compare#mcsog-h-%E5%9F%BA%E5%B2%A9%E7%89%88%E6%A0%B8%E5%BF%83%E5%AF%B9%E6%AF%94)** の「統合版コアの比較」節を参照。

## 1. BDS（公式）

Minecraft 公式サイトが提供する公式の統合版サーバーで、Java 版の Vanilla と同じページにあります。

**強み**

- **公式サポート**：公式の更新に追随し、最新版クライアントとの互換性が最良；
- **安定**：公式製品で、動作が信頼できる；
- **リソース利用**：統合版向けに最適化され、サーバー資源を効率よく使える；
- **セキュリティ更新**：公式がセキュリティ問題をより頻繁に修正する。

**弱み**

- **プラグイン非対応**：公式サーバー自体にプラグインの仕組みがなく、プラグインを入れるには**コミュニティのプラグインローダー**に頼るしかない；
- **シングルスレッドのボトルネック**：**モブの演算が 1 つのスレッドで動く**ため、快適さは**主に CPU のシングルコア性能**で決まる。マップが大きいほど重く、全体としてはマルチコア対応の Java サーバーに劣る；
- **高度な機能の欠如**：カスタムのワールド生成や高度な権限管理は通常サードパーティでしかできない；
- **メモリがゆっくり増える**：使用量が徐々に増え、ひどいとメモリリークのように見える。**無理にメモリを解放すると、プレイヤーのリソースパック／Addon のダウンロードで進行バーが止まり**、サーバーの再起動でしか解決できない。

**向いている**：公式サポートと互換性が必要で、複雑なカスタマイズを要さないサーバー。**サバイバルサーバーの第一候補**。

## 2. Nukkit（NK）

統合版の「Bukkit」—— **Java** で書かれ、エコシステムも開発の発想も Java 版のプラグイン系によく似ています。

**強み**：軽量（リソース要件が低い）、性能も悪くない、**ネイティブのプラグインシステムがある**、クロスプラットフォーム（Windows/Linux/macOS）、導入が簡単。

**弱み**：**更新が遅れがち**（最新版や最新の機能に追随できないことがある）、プラグインのエコシステムは Spigot/Paper より小さい、マルチコア最適化が不十分、高品質なドキュメントが少ない、オープンソースプロジェクトには時折安定性の問題がある。

**向いている**：初心者と小規模サーバー。**注意**：オリジナルの Nukkit はすでに活発ではなく、実際にはその現代的な分岐を勧めます（下記）。

## 3. PowerNukkitX（PNX）

Nukkit の**現代的な後継**で、現在の統合版サードパーティコアの主力です。

**強み**

- **最新の統合版プロトコルに対応**し、新バージョンに追随できる；
- **マルチコア最適化**：BDS や旧 Nukkit に対する最大の利点；
- **384 ブロックのワールド高さ**；
- **Terra** 地形生成器を内蔵し、豊かな地形を作れる；
- **完全オープンソース、API 公開**。Java / Kotlin / Scala / Python / JavaScript / Lua などの JVM 言語でプラグインが書ける；
- **Nukkit エコシステムの多数のプラグインと互換**。

**弱み**：開発の勢いは元の Nukkit チームの異動に影響される。エコシステムは主流の Java サーバーに比べるとまだ小さい。プラグインが多く、初心者の学習コストが高い。

**向いている**：**高性能 + 高度なカスタマイズ**を求める運営者。

## 4. PocketMine-MP（PMMP）

**PHP** で書かれた統合版サーバーで、プラグインのエコシステムが最も大きいです。

**強み**：プラグインのエコシステムが巨大、クロスプラットフォーム、**PHP の敷居が低い**（PHP が書ければプラグインが書ける）、コミュニティが活発、カスタマイズの自由度が高い。

**弱み**：**プレイヤー負荷が高いと性能のボトルネック**がある（メモリ管理と CPU 効率）。更新が遅れがち。プラグインを複数入れると安定性が下がる。PHP はインタプリタ言語で**リソース消費がより目立つ**。設定とプラグイン管理を学ぶ必要がある。

**向いている**：**プラグインの機能とカスタマイズ**を重視し、ある程度の性能の妥協を受け入れられる運営者。

## 5. 選び方

```
安定 + 公式互換 + バニラのサバイバル
   → BDS（プラグインが必要ならコミュニティのローダーを併用。「BDS サーバー」を参照）

高性能 + マルチコア + 高度なカスタマイズ
   → PowerNukkitX

最大のプラグインエコシステム、PHP が使える
   → PocketMine-MP

簡単なところから始めたい、Nukkit のエコシステムで遊びたい
   → Nukkit 系（ただし活発な分岐を優先）
```

:::tip まず最小規模で検証する
コアを決めたら、**まず小規模で動かして**（数人、少数のプラグイン）から公開してください。統合版のコアは互換性の落とし穴が Java 版より多く、最初からプラグインを全部入れるのは避けましょう。
:::
