統合版のサーバー構築で最もつまずきやすいのは設定ではなく**バージョン**です。本記事は 2 つのことを整理します：プロトコルバージョンとは何か、そしてどのゲームバージョンを選ぶべきか。

## 1. プロトコルバージョン：クライアントとサーバーの「言語」

プロトコルバージョンは**二者が会話に使う言語のバージョン**だと考えると分かりやすいです：

> 1.20.50 は「古い中国語」（プロトコル **630**）を話し、1.20.60 は「現代中国語」（プロトコル **649**）を話す。
> 言語が違えば**互いに通じない** —— だから 1.20.60 のクライアントは 1.20.50 のプロトコルで動くサーバーに**接続できず**、「すべてのプレイヤーが最新バージョンに更新してから再試行してください」と表示されます。

つまり：**クライアントのプロトコルがサーバーのプロトコルと一致**しないと入れません。Java 版の「バージョン互換」とは論理が違い、統合版はより厳格です。

### プロトコルはいつ変わるか

- **通常**：リビジョン番号の**十の位**が変わるときにプロトコルが変わります。たとえば `1.20.10`–`1.20.15` は同じ **594**；`1.20.30` から **618**；`1.20.40` から **622**。
- **例外**：十の位の範囲内でもプロトコルが変わる場合があります。たとえば `1.19.60`–`62` と `1.19.63` はプロトコルが違い、`1.21.0`–`1.21.1` と `1.21.2`–`1.21.3` も異なります。
- おおよそ**5 週間前後**ごとに、プロトコルが変わるバージョンが出ます。

:::tip プロトコル番号の調べ方
具体的なバージョンがどのプロトコル番号に対応するかは、**Minecraft Wiki** のバージョン一覧を優先してください。
:::

## 2. どのゲームバージョンを選ぶか

**先に結論**：明確な要件がなければ、**最新版を選ぶ**。最新版のサーバーは通常、最新版のクライアントに対応します。

### プレイヤーへの影響が大きいクライアントの変化

これらの更新は公式があっさり説明していますが、サーバー構築への影響は小さくありません：

| バージョン | 影響 |
| --- | --- |
| **1.20.50** | 多数のブロックの「フラット化」、コードの再構成 → **このバージョン未満のバージョン間互換プラグインの互換性が悪化** |
| **1.20.40** | 新しいタッチ操作のレイアウトで位置をカスタマイズ可能 |
| **1.20.x**（前後） | Android で**深刻なラグ**の問題が発生し、コミュニティでも長期的に解決策なし |
| **1.19.50** | 新しいタッチ操作のレイアウトを追加 |
| **1.18.30** | クライアントに**RenderDragon** が実装 → **従来のシェーダーが使えなくなり**、ハードウェアレイトレーシングかディファードレンダリングのみ |

### 「自動更新」こそが最大の落とし穴

各アプリストアは既定でクライアントを**自動更新**します。統合版は数バージョンごとにプロトコルが変わるため：

> プレイヤーのクライアントがあなたの知らないうちに自動更新 → **プロトコルが変わった** → その人は**あなたのサーバーに入れなくなる**

Java 版ではほとんど起きません。自動更新は公式ランチャーの中だけで、プレイヤーが必ずしも公式ランチャーを使うとは限らないからです。

**対処は 2 つしかありません**：

1. **最新版に追随し続ける**（サーバーも最新版に更新する）—— 推奨。コミュニティの既定のやり方でもあります；
2. **プレイヤーにバージョン固定を求める** —— ただしこれは下記の問題を伴います。

### バージョン固定を強制する代償

古いバージョンに固定する場合：

- × **ほぼすべての iOS プレイヤーを失う**：iOS の仕組み上、**最新版しかインストールできず**、指定したインストールパッケージは入れられません（コミュニティでも完璧な解決策は今もありません）；
- × **最新版しか遊ばないプレイヤーをすべて失う**：最新版に追随するサーバーとプレイヤー層は非常に大きいです；
- × サポートが apk / appx を入れられない初心者を**手取り足取り案内**する必要がある。

さらに、プレイヤー自身も最新版に傾きます：サードパーティのアプリストアは最新版のインストールパッケージを優先的に提供し、コミュニティの情報も最新版を中心に回っており、しかも統合版は**プラットフォームをまたいだバージョン切り替えが面倒**なので、コミュニティには「全員が最新版に追随する」という暗黙の了解ができています。

:::warn バージョン固定を選ぶ前に損失を計算する
上記の損失が**サーバーの人気に深刻な影響を与えない**と確認できたときだけ、バージョン固定を検討してください。そうでなければサーバーを最新版に保ってください。
:::
