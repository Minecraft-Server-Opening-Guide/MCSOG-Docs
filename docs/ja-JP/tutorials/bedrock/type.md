統合版のサーバーを開く前に、**どの種類のサーバーを開くのか**をはっきりさせてください。種類が、使えるコア、入れられるもの、そして維持コストを決めます。

統合版の主流は 5 種類です：

## 1. バニラサーバー（公式のみ）

**完全に公式のルールどおり**に動かし、プラグインも Addon も入れません。

- ○ 純粋そのもの、最も安定、ほぼメンテナンス不要（プラグインの互換性や更新を気にしなくてよい）
- × 機能はバニラにあるものだけ
- 向いている：**公平で安定した**バニラ体験を提供したい。**BDS** が最適

## 2. Addon サーバー（BDS のみ）

公式の **BDS** に、公式が対応する **Addon**（ビヘイビアパック / リソースパック）を読み込んで内容を拡張します。

- ○ 公式対応、バージョンとの互換性がよく、安定性への影響が小さい
- × カスタマイズ能力は限られる（ブロック、アイテム、モブのような内容は足せるが、サーバーのロジックは変えられない）
- 向いている：公式の特性を保ちつつ、独自の内容も足したい

## 3. プラグインサーバー

**サードパーティのサーバーコア**（Nukkit / PowerNukkitX / PocketMine-MP など）にプラグインを入れて、機能を大きく拡張します。

- ○ 高度にカスタマイズでき、プラグインの種類も多く、コミュニティのチュートリアルも多い
- × プラグインの互換性や安定性の問題がありうる。**公式の BDS 自体はプラグインに対応しておらず**、コミュニティのローダーに頼る必要がある
- 向いている：特色のある遊びを作りたい、プラグインの調整に時間をかける気がある

## 4. ミニゲームサーバー（プラグインサーバーの一種）

ウォール、スカイブロック、迷路といったミニゲームに特化します。

- ○ 娯楽性が高く、テンポが速く、短時間の遊びに向く
- × 人を留めるには内容を**継続的に更新**する必要があり、運営コストが高い
- 向いている：対戦／カジュアル寄りで、内容を作り続けられる人手がある

## 5. Addon + プラグインの混成サーバー（BDS のみ）

公式の Addon も使い、コミュニティのプラグインローダーでも拡張します。

- ○ 公式の特性とプラグインの自由度を両取りできる
- × 設定が複雑で両方を管理する必要があり、互換性の問題が増え、性能要件も高い
- 向いている：**経験があり**、互換性の問題を処理できる運営者

## 選び方

| あなたの目標 | 提案 |
| --- | --- |
| バニラのサバイバル、安定と手軽さ | **バニラサーバー + BDS** |
| 内容は足したいがプラグインは触りたくない | **Addon サーバー + BDS** |
| 豊富な遊びが欲しい、いじり倒せる | **プラグインサーバー**（Nukkit / PNX / PMMP） |
| ミニゲームを作る | プラグインサーバー + ミニゲームプラグイン |
| 公式もプラグインも欲しい | **BDS + プラグインローダー** |

種類を決めたら、次は具体的なコアを選びます：[統合版のコア選択](/tutorials/bedrock/cores) を参照。
