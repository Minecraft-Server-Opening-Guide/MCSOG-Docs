統合版のクライアントで Java 版のサーバーに入りたい、というプレイヤーは多くいます。手順の全体を 1 ページの早見表にまとめました。

## 要点

:::step 原理
Geyser が統合版のプロトコルを Java 版のプロトコルに変換し、Floodgate が統合版のプレイヤーに Java アカウントなしでもログイン認証を完了させます。
:::

:::step どこに入れるか
プロキシ（Velocity、BungeeCord）にも、単体の Paper サーバーにも入れられます。プロキシに入れるほうが一括管理しやすいです。
:::

:::step 開放が必要なポート
Java 版は既定で TCP 25565、統合版は既定で UDP 19132 を使います。ファイアウォールとクラウドサーバーのセキュリティグループの両方で開放が必要です。
:::

:::danger
公開サーバーでログインの問題を「解決」しようとして正規アカウント認証を切らないでください。誰でも任意の名前で入れるようになるのと同じです。正しいやり方は Floodgate を適切に設定することです。
:::

詳しい手順は「スマホプレイヤーの受け入れ」を参照してください。
