## 権利侵害への対応

当サイトのコンテンツがあなたの権利を侵害していると思われる場合は、「お問い合わせ」ページのメールアドレスまで以下の情報をお送りください。確認のうえ、速やかに削除または訂正します：

- 権利の証明とご本人の情報；
- 権利侵害が疑われるコンテンツの具体的なリンク；
- 侵害の事実の説明と連絡先。

:::danger
悪意のある通報や虚偽の権利主張は、法的責任を負う可能性があります。
:::
