ログイン後、アカウントの権限に **mcsog** が含まれていると、トップバーに編集モードのボタンが表示されます。有効にするとページ下部に編集ツールバーが現れ、変更はすべて GitHub リポジトリへコミットされ、本番へ自動的に同期されます。

## 変更できるもの

:::step ページの文言
「文言」をクリックすると辞書一覧が開きます（語句や内容で検索できます）。また、**ページ上の任意の UI テキストを直接クリック**すると、対応する辞書キーを逆引きして編集ダイアログが開きます。
:::

:::step ドキュメントとお知らせ
チュートリアル／お知らせ／ヘルプのページで「本文を編集」をクリックすると Markdown エディタが開き、保存すると `docs/` に書き戻されコミットされます。
:::

:::step 新しいコンテンツ
「新規ドキュメント」で種類・分類・言語・識別子・タイトルを入力するだけで作成できます。本文では `:::step`、`:::note`、`:::warn`、`:::danger`、コードフェンス、表が使えます。
:::

:::step 画像
「画像」から PNG / JPEG / WebP / GIF / AVIF をアップロードすると、そのまま参照できる URL が返り、同時にリポジトリにもコミットされます。
:::

:::step ナビゲーション
「ナビゲーション」では任意のセクションに項目を追加したり、既存の項目を削除したりできます（変更は `nav.config.js` に書き込まれます）。
:::

:::warn
編集モードでは、サーバーが設定された鍵を使ってコミットとプッシュを行います。ローカルで開発する前に `git pull` を実行し、本番のコミットと分岐しないようにしてください。
:::

## 権限とセキュリティ

- 権限は OAuth プロバイダーが返す `permission` フィールドに由来し、設定されたトークン（既定は `mcsog`）を含む場合のみ編集の入り口が表示されます；
- 書き込み API はサーバー側で権限を再検証し、クロスサイト由来のリクエストを拒否します；
- プッシュ用の SSH 秘密鍵は **AES-256-GCM で暗号化**して `config/edit.php` に保存され、実行時にのみ一時ファイル（0600）へ復号され、プッシュ後すぐに削除されます；
- 画像アップロードは 2 MB までで、実際の画像形式のみ受け付けます。
