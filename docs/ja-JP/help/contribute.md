当サイトはプレイヤーコミュニティによって運営されています。チュートリアルの追加、誤りの修正、翻訳の改善などを歓迎します。すべてのコンテンツは公開リポジトリ [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) にあります。

## 貢献できること

- **新しいチュートリアル**：サーバー構築・運用・トラブルシューティングで、実際につまずいて解決した事例
- **修正**：古くなったコマンド、誤ったパス、バージョンの不一致、誤字
- **翻訳**：中国語チュートリアルの英語化、または既存訳の修正
- **リソース情報**：ダウンロード情報（バージョン、サイズ、チェックサム、公式サイト）の補完

## 投稿の流れ

:::step ブランチを作成
[MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) を Fork してブランチを作成し、[編集ガイド](/help/guide)のディレクトリと命名に従ってファイルを追加します。
:::

:::step Pull Request を送信
PR で**変更範囲**を説明してください。`main` にマージされると、30 分以内にメインリポジトリへ同期され、2 時間以内に公開されます。
:::

## 執筆ルール

:::step 自分で検証した内容だけを書く
コマンドと設定は、ご自身で実際に動作確認したものを使ってください。不確かな箇所は `:::warn` で適用条件を明記します。
:::

:::step 初心者向けでも、重要な手順は省略しない
どの手順もそのまま実行できるようにしてください。「必要に応じて設定」のような曖昧な表現は避けます。
:::

:::step 中国語と英語を同期する
新しい中国語チュートリアルを追加するときは、できるだけ同じ slug で英語版も用意してください。用意しない場合でも、ページは中国語にフォールバックし、その旨が表示されます。
:::

:::step バージョンとコマンドは公式に従う
バージョン番号、コマンド、ダウンロード URL は検証できるものにし、公式の出典リンクを添えてください。上流に変更があった場合は速やかに更新するか、期限切れの内容は公開を終了してください。
:::

:::danger
海賊版リソース、クラックツール、第三者の有料コンテンツを含むファイルはアップロードしないでください。当サイトは公開されているリソースのみを掲載し、公式の出典へリンクします。
:::

## 著作権とクレジット

- あなたが投稿したオリジナルコンテンツは、当サイトが同条件で転載・改変することを既定で許諾したものとみなします；
- 他者のコンテンツを引用する場合は、出典とライセンスを明記してください；
- 権利侵害を見つけた場合は「お問い合わせ」ページのメールアドレスまでご連絡ください。確認次第速やかに公開を停止します。

## 交流と質問

当サイトの**唯一の公式交流グループ**は QQ グループ [1083430859](https://qm.qq.com/q/nRsqCiwHMm) です。投稿の前後どちらでもグループで相談できます。

- 直したいが方法がわからない：ページと問題点をグループで説明してください。具体的な進め方をお伝えします
- 提案した修正の進捗を知りたい：グループで直接聞いてください。何度も Issue を立てる必要はありません
- 注意：グループ内でも「コミュニティ規則」が適用されます。広告や海賊版コンテンツはそのまま削除されます
