本ページは、当サイトのコメント、交流グループ、および MCSOG の名義で行われるあらゆる交流に適用されます。目的は、質問した人が答えを得られ、答えた人が引き続き答えたいと思える状態を保つことです。

## 基本原則

- 友好的に：人ではなく事柄を論じ、人格攻撃・地域差別・初心者への嘲笑をしない
- 著作権を尊重：海賊版リソース、クラックツール、チート、正規アカウント認証を回避する方法を投稿しない
- 連投しない：同じ内容を繰り返さない、他人を連続で @ しない、意味のない文字列を投稿しない
- 宣伝しない：許可なくサーバーの宣伝、構築代行、有料保守などの商業的内容を投稿しない
- 法令を守る：居住地の法令に反する内容を議論・拡散しない

## 質問のルール

「サーバー構築に失敗しました。どうすれば？」だけでは回答できません。できるだけ以下を添えてください：

- 使用している**サーバーコアとバージョン**（例：Paper 1.21.4）
- 使用している**起動方法**（パネル、systemd、コマンドライン）
- **エラーログの全文**（テキストで貼ってください。スクリーンショットだけ、最後の 1 行だけでは不十分です）
- すでに**試したこと**と、その結果

## 編集と投稿

- 誤字の修正、コマンド出力の追記、古いバージョン番号の更新は、直接の投稿を歓迎します
- 新しいチュートリアルは、対象読者と前提条件を先に示してください。「ここをクリック、次にあそこをクリック」だけの説明は避けます
- サードパーティ製ソフトが関わる場合は公式のダウンロード先を示し、クラウドストレージの転載リンクは使わないでください
- 編集の詳細は「編集ガイド」と「貢献ガイド」を参照してください

## 違反への対応

| 状況 | 対応 |
| --- | --- |
| 初回の軽微な違反（連投、脱線） | 注意したうえで内容を削除 |
| 繰り返しの違反または宣伝 | ミュートし、過去の投稿も整理 |
| 海賊版・チート・違法コンテンツの投稿 | 即時追放。異議申し立ては受け付けない |
| 他人や運営のなりすまし | 即時追放 |
