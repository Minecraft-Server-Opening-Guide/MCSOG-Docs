Java 版と統合版は同じゲームの別エディションであり、レッドストーン、コマンド、MOD の仕組みにも違いがあります。まず違いを把握してから、どちらのサーバーを立てるかを決めてください。

> ポート番号とレッドストーンの差異は公式の仕様です。バージョンによって細部が変わる場合があるため、最終的には該当バージョンの公式説明を確認してください。

## 差異の対照表

| 項目 | Java 版 | 統合版 |
| --- | --- | --- |
| レッドストーンとコマンド | レッドストーンの仕組みが完全（準接続などの特性を含む）。コマンド機能も最も充実 | レッドストーンの挙動に差異がある（準接続がなく、ピストンと粘着ブロックの挙動も異なる） |
| MOD とプラグイン | Fabric / Forge / NeoForge とプラグインのエコシステム | アドオン（Add-on）が中心 |
| サーバーの選択肢 | Paper / Purpur / Fabric / Forge / Velocity | BDS / Nukkit / PocketMine-MP |
| 既定のポート | 25565（TCP） | 19132（UDP）、IPv6 は 19133（UDP） |
| クロスプレイ | Java サーバーは Geyser を導入すると統合版のプレイヤーを受け入れられる（Floodgate 併用で Java アカウントでのログインを省略可能） | 統合版サーバーに Java 版のプレイヤーは入れない |
| 性能と最適化 | 最適化フォークと起動オプションが最も豊富 | 公式 BDS の最適化オプションは少なく、主に OS 側のチューニングに頼る |
| 向いている人 | プラグイン、MOD、自動化、大規模なマルチプレイを求める人 | スマートフォン／家庭用ゲーム機のプレイヤー、すぐにつながるマルチプレイを求める人 |

## 注意

統合版サーバーは UDP 19132、Java 版は TCP 25565 を使います。TCP だけを開放していることが、接続できない最もよくある原因です。

クロスプレイツールの Geyser は一方向です。統合版のクライアントを Java 版サーバーへ接続させるもので、逆方向（Java クライアントから統合版サーバーへ）の公式な方法はありません。Geyser は Java 版サーバー側に導入する必要があり、統合版の公式サーバー BDS には導入できません。
