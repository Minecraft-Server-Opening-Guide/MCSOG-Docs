## حدّد إصدارك أولًا

- **إصدار Java**: الإصدار الرسمي على Windows / macOS / Linux، وهو الأوسع اختيارًا لنوى الخوادم (Paper وPurpur وFabric وForge وVelocity).
- **إصدار Bedrock**: الإصدار المخصص للهواتف وأجهزة الألعاب وWindows، وخادمه الرسمي هو BDS، أما الحلول المجتمعية فتشمل Nukkit وPocketMine-MP.

ويمكن ربط الإصدارين عبر Geyser + Floodgate، ليدخل لاعبو Bedrock مباشرة إلى خادم إصدار Java.

## ترتيب القراءة الموصى به
:::step تأكيد بيئة التشغيل
ابدأ بـ «إعداد خادم إصدار Java ← JDK ومصفوفة الإصدارات» لتحديد إصدار Java، ثم قرّر أي نواة خادم ستستخدم.
:::
:::step نشر الخادم
اتبع «نشر خادم Paper على Linux» أو «نشر خادم BDS الرسمي» حتى تنجح أول عملية تشغيل من الصفر.
:::
:::step إكمال الإعدادات الأساسية
اقرأ «شرح server.properties» و«المنافذ وجدار الحماية والاختراق إلى الشبكة الداخلية» ليتمكن اللاعبون من الاتصال.
:::
:::step التشغيل والصيانة على المدى الطويل
اضبط «النسخ الاحتياطي والرجوع»، وتعلّم تشخيص التلعثم بـ «TPS / MSPT».
:::
:::note
يتطلب تنزيل الموارد تسجيل الدخول. والموقع يقتصر على الفهرسة والإحالة، وحقوق الموارد تعود لمؤلفيها الأصليين.
:::

### الأخطاء الثلاثة الأكثر شيوعًا

1. **التحديث دون نسخة احتياطية**: خذ نسخة احتياطية قبل تحديث النواة أو ملحق أو MCDR، وتأكد أن هذه النسخة **قابلة للاستعادة فعلًا**. راجع [النسخ الاحتياطي والاستعادة](/tutorials/java/backup) و[تحديث وصيانة الخادم والملحقات وMCDR](/tutorials/ops/updates).
2. **نشر العنوان قبل ضبط القائمة البيضاء والتحقق من النسخ الأصلية**: نشر IP قبل إتمام `online-mode` والقائمة البيضاء يعني تسليم الخادم للغرباء. راجع [إعداد الخادم](/tutorials/java/config) و[أساسيات أمن الشبكات](/tutorials/ops/network-security).
3. **ترقية العالم دون اختبار النواة الجديدة**: متى فُتح العالم بإصدار جديد صار الرجوع إلى الإصدار القديم صعبًا جدًا. اختبر على نسخة أولًا، ثم المسّ الحفظ الرسمي. راجع [تحديث وصيانة الخادم والملحقات وMCDR](/tutorials/ops/updates) و[تشخيص الأخطاء والانهيارات الشائعة في إصدار Java](/tutorials/faq/errors).

### تريد خادم Bedrock فقط؟

يمكنك تجاوز سلسلة دروس ملحقات إصدار Java الطويلة، واتباع هذا المسار مباشرة:

1. [أنواع خوادم إصدار Bedrock](/tutorials/bedrock/type) —— افهم أولًا الفرق بين BDS ونوى الأطراف الثالثة.
2. [اختيار نواة Bedrock](/tutorials/bedrock/cores) —— حدّد النواة التي ستستخدمها.
3. [خادم BDS](/tutorials/bedrock/bds) أو [البدء مع نوى Bedrock من أطراف ثالثة](/tutorials/bedrock/third-party-setup) —— انشر النواة التي اخترتها.
4. [النشر في بيئة يمكن الوصول إليها](/tutorials/java/deploy) —— تمكين الاتصال من الإنترنت (جزء الشبكة مشترك).
5. [تشخيص مشكلات تشغيل خوادم Bedrock](/tutorials/faq/bedrock-issues)، [[BE] الأسئلة الشائعة](/tutorials/faq/faq-be) —— اقرأ هاتين الصفحتين أولًا عند حدوث مشكلة.
6. [النسخ الاحتياطي والاستعادة](/tutorials/java/backup) —— النسخ الاحتياطي إلزامي في كل الإصدارات.
