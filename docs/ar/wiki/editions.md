إصدار Java وإصدار Bedrock ليسا الإصدار نفسه من اللعبة، فآليات الريدستون والأوامر والمودات تختلف بينهما؛ فاعرف الفرق أولًا ثم قرّر أي إصدار ستشغّل خادمه.

> أرقام المنافذ وفروق الريدستون من الإعدادات الرسمية الثابتة؛ وقد تختلف التفاصيل اختلافًا يسيرًا بين الإصدارات، والمعتمد هو التوضيح الرسمي للإصدار المعني.

## جدول الفروق

| البند | إصدار Java | إصدار Bedrock |
| --- | --- | --- |
| الريدستون والأوامر | آلية ريدستون مكتملة (بما فيها خصائص مثل quasi-connectivity)، والأوامر هي الأكمل وظيفيًا | سلوك الريدستون مختلف (لا quasi-connectivity، وسلوك المكابس والكتل اللاصقة مختلف) |
| المودات والملحقات | Fabric / Forge / NeoForge ومنظومة الملحقات | يعتمد أساسًا على الحزم الإضافية (Add-on) |
| اختيار الخادم | Paper / Purpur / Fabric / Forge / Velocity | BDS / Nukkit / PocketMine-MP |
| المنفذ الافتراضي | 25565 (TCP) | 19132 (UDP)، وعلى IPv6 هو 19133 (UDP) |
| اللعب المشترك بين الإصدارين | يحتاج خادم Java إلى Geyser ليقبل لاعبي Bedrock (ومع Floodgate يمكن الدخول دون حساب Java) | لا يستطيع خادم Bedrock أن يقبل لاعبي إصدار Java |
| الأداء والتحسين | أكثر تنوّعًا في فروع التحسين ومعاملات التشغيل المتاحة | خيارات التحسين في BDS الرسمي قليلة، ويعتمد أساسًا على ضبط النظام |
| الفئة المناسبة | من يريد الملحقات والمودات والأتمتة واللعب الجماعي الواسع | لاعبو الهواتف وأجهزة الألعاب، واللعب الجماعي الجاهز فورًا |

## تنبيه

خادم Bedrock يستخدم UDP 19132، وخادم Java يستخدم TCP 25565. والسماح بمرور TCP وحده هو السبب الأكثر شيوعًا لتعذر الاتصال.

أداة اللعب المشترك Geyser أحادية الاتجاه: فهي تتيح لعميل Bedrock الاتصال بخادم إصدار Java؛ أما العكس (دخول عميل Java إلى خادم Bedrock) فلا حل رسمي له. ويجب تثبيت Geyser على جهة خادم إصدار Java، ولا يمكن تثبيته على خادم BDS الرسمي لإصدار Bedrock.
