بعد تشغيل الخادم تظهر في دليله حزمة من الملفات والمجلدات. و**معرفة ما يمكن المساس به وما لا يجوز لمسه إطلاقًا** أساس كل العمليات اللاحقة (تثبيت الملحقات، النسخ الاحتياطي، النقل).

وفيما يلي نأخذ خادم الملحقات (مثل Paper / Purpur) مثالًا.

## أولًا: المجلدات

| المجلد | الوظيفة | هل يمكن المساس به |
| --- | --- | --- |
| `plugins/` | توضع فيه الملحقات | يُمسّ به كثيرًا |
| `world/` | بيانات **العالم الرئيسي** | يُنسخ كاملًا فقط، ولا يُعدَّل يدويًا |
| `world_nether/` | بيانات العالم السفلي | كما سبق |
| `world_the_end/` | بيانات عالم النهاية | كما سبق |
| `logs/` | سجلات التشغيل، وعليها يعتمد تشخيص المشكلات | يمكن حذف القديم |
| `crash-reports/` | تقارير الانهيار، وأول ما تراجعه عند الخطأ | يمكن حذف القديم |
| `config/` | الإعدادات الأساسية لنوى عائلة Paper (مثل `paper-world-defaults.yml`) | انسخ قبل التعديل |
| `libraries/` `versions/` `cache/` | مكتبات الاعتماد والذاكرة المؤقتة، **تُولَّد تلقائيًا** | لا تمسّها |
| `mods/` | يوجد فقط في **خادم المودات** (Fabric / Forge) والخوادم المختلطة | يُمسّ به كثيرًا |

## ثانيًا: الملفات المهمة في الدليل الجذر

| الملف | الوظيفة |
| --- | --- |
| `server.properties` | **أساس إعدادات الخادم** (المنفذ، والتحقق من النسخ الأصلية، ومدى الرؤية...) |
| `eula.txt` | ملف الموافقة على الاتفاقية، ويجب أن يكون `eula=true` |
| `核心名.jar` | ملف نواة الخادم نفسه |
| `ops.json` | قائمة OP (المسؤولين) |
| `whitelist.json` | قائمة القائمة البيضاء |
| `banned-players.json` / `banned-ips.json` | قائمتا الحجب |
| `usercache.json` | ذاكرة أسماء اللاعبين وUUID |
| `bukkit.yml` / `spigot.yml` | إعدادات طبقة Bukkit / Spigot (موجودة في عائلة Paper) |
| `purpur.yml` / `paper.yml` | إعدادات النواة نفسها (توجد بعد تغيير النواة) |
| `commands.yml` | الأسماء البديلة للأوامر وتعيينات الاعتراض |
| `permissions.yml` | تعريفات الصلاحيات الافتراضية |

## ثالثًا: ماذا في مجلد العالم

داخل `world/` يقع الحفظ الحقيقي، و**عند النسخ الاحتياطي يُنسخ `world` كاملًا**:

| الدليل الفرعي | المحتوى |
| --- | --- |
| `region/` | **بيانات القطع** (الكتل والتضاريس هنا، وهو الأكبر حجمًا) |
| `playerdata/` | حقائب اللاعبين ومواقعهم ونقاط صحتهم |
| `entities/` | بيانات الكائنات (العناصر الساقطة والكائنات الحية وتجارة القرويين وغيرها) |
| `poi/` | نقاط الاهتمام (محطات عمل القرويين والأسرّة وغيرها) |
| `data/` | بيانات على مستوى العالم (الخرائط ولوحات النقاط وغيرها) |
| `datapacks/` | حزم البيانات |
| `advancements/` `stats/` | الإنجازات والإحصاءات |

:::warn لا تعدّل ملفات العالم يدويًا
تعديل الملفات في `region/` مباشرةً قد **يفسد الحفظ** بدرجة كبيرة. ولمن يريد تغيير العالم فليستخدم ملحقًا مثل `WorldEdit`، أو يوقف الخادم أولًا.
:::

## رابعًا: ما تخبرك به هذه البنية

1. **ما الذي يُنسخ احتياطيًا**: مجلدات العوالم الثلاثة `world*` + إعدادات `plugins/` + `server.properties`، والباقي يُعاد بناؤه تلقائيًا في الغالب. التفاصيل في «النسخ الاحتياطي والاستعادة».
2. **كيف تُنقل**: انسخ دليل الخادم كاملًا إلى الجهاز الجديد، وثبّت Java بالإصدار نفسه، ولا تجعل المسار يحتوي صينيًا أو مسافات.
3. **من أين تُشخّص**: ابدأ بـ `logs/latest.log`، وعند الانهيار راجع `crash-reports/`.
