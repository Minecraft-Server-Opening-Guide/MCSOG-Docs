المتطلبات المسبقة جاهزة: **Java مثبتة، والمنفذ مفتوح، والدلائل منشأة، والنواة مختارة ومنزّلة**. وهذا المقال يشغّل الخادم فعليًا.

:::note يمكن تخطي هذا المقال مع إصدارات Forge وNeoForge الحديثة
إصدارات **Forge** و**NeoForge** الحديثة، بعد تثبيتها بـ**المثبّت** الرسمي، **تولّد سكربت تشغيل تلقائيًا** في دليل الخادم (`run.bat` / `run.sh`). فإن كنت تستخدمها فشغّل ذلك السكربت مباشرة، دون كتابة سكربت تشغيل يدويًا.
:::

## أولًا: كتابة سكربت التشغيل

ضع نواة الخادم المنزّلة (`.jar`) في دليل النشر، مثلًا:

```
C:\mcserver\survival\        (في Linux المقابل /opt/mcserver/survival/)
├── paper-1.21.4.jar         ← النواة التي نزّلتها
└── (بقية الملفات تُولَّد تلقائيًا عند أول تشغيل)
```

### Windows: `start.bat`

1. أنشئ في هذا الدليل **مستندًا نصيًا** جديدة، وغيّر اسم الملف إلى `start.bat` (أي غيّر الامتداد من `.txt` إلى `.bat`).
2. انقر بزر الفأرة الأيمن ← افتحه بمحرر نصوص، واكتب المحتوى التالي واحفظ:

```bat
@echo off
cd /d "%~dp0"
java -Xms2G -Xmx2G -jar <core-name>.jar --nogui
pause
```

استبدل `<core-name>.jar` باسم ملفك الفعلي (مثل `paper-1.21.4.jar`).

- `cd /d "%~dp0"` يثبّت دليل العمل على دليل السكربت، ليجد ملف النواة عند النقر المزدوج.
- `--nogui` يعني عدم فتح النافذة الرسومية المرفقة بالخادم، ويخرج كل شيء إلى سطر الأوامر (`nogui` اسم قديم مكافئ له).
- `pause` يمنع إغلاق النافذة **فورًا** بعد خروج الخادم، لتتمكن من قراءة الخطأ، والتفاصيل في «توسعة» أدناه.

### Linux: `start.sh`

```bash
#!/bin/sh
cd "$(dirname "$0")"
exec java -Xms2G -Xmx2G -jar <core-name>.jar --nogui
```

امنحه صلاحية التنفيذ ثم شغّله:

```bash
chmod +x start.sh
./start.sh
```

## ثانيًا: أول تشغيل: انتظر التنزيل ثم وافق على EULA

**في أول تشغيل تُنزَّل أولًا الملفات اللازمة للتشغيل**، فتظهر في سطر الأوامر مخرجات مثل `Downloading mojang_x.x.x.jar` — وهذا طبيعي، **فانتظر اكتمال التنزيل** (وإذا تعطّل على الشبكة المحلية فتحتاج وسيلة تسريع خاصة).

وبعد اكتمال التنزيل **لا يبدأ الخادم مباشرة**، بل يطبع:

```
You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

افتح حينها بمحرر نصوص ملف **`eula.txt` المولَّد تلقائيًا** في الدليل، وغيّر:

```
eula=false
```

إلى:

```
eula=true
```

وبعد الحفظ **أعد تشغيل سكربت التشغيل**. وهذا الإجراء يعني أنك قرأت [اتفاقية Minecraft EULA](https://aka.ms/MinecraftEULA) ووافقت عليها.

:::warn بدون التعديل لا يقلع
عند `eula=false` **يخرج الخادم فور التشغيل**، وهذه أكثر عقبة يقع فيها المبتدئ.
:::

## ثالثًا: كيف تعرف أن التشغيل ناجح

عندما يظهر في سطر الأوامر السطر التالي فالخادم **بدأ بنجاح**:

```
Done (6.554s)! For help, type "help"
```

وزمن الثواني بين القوسين يختلف بحسب الجهاز. وعندها:

- من **الجهاز نفسه** يمكن الدخول بـ `localhost:25565`؛
- ويمكن للآخرين الدخول بـ**IP العام** (أو اسم النطاق) مع المنفذ الافتراضي `25565`؛
- وكتابة `stop` في وحدة التحكم **تغلق الخادم بأمان** (**لا تغلق النافذة مباشرة**، فذلك يفسد الحفظ).

## رابعًا: توسعة: ثلاث حِيَل عملية

### 1. أضف `pause` لترى السجل عند الانهيار

عند تشغيل ملف `.bat` في Windows بالنقر المزدوج، إذا انهار الخادم **تمر النافذة سريعًا** فلا ترى شيئًا. أضف `pause` في **آخر سطر** من السكربت:

```bat
java -Xms2G -Xmx2G -jar <core-name>.jar --nogui
pause
```

فيتوقف العرض بعد خروج الخادم وتُقرأ رسالة الخطأ بوضوح (وفي Linux المكافئ إضافة `read -n 1 -p "按任意键继续..."` في نهاية السكربت).

### 2. استخدم wildcard فلا تعدّل السكربت عند تغيير الإصدار

تعديل اسم الملف في السكربت مع كل تحديث للنواة أمر مزعج. استخدم **wildcard** للمطابقة:

```bash
java -jar *.jar
java -jar paper-*.jar
java -jar leaf-*.jar
```

:::warn wildcard لا يعمل في ملف .bat على Windows
هذا فرق **مؤكد بالاختبار الفعلي**: **shell في Linux / macOS يوسّع wildcard**، أما **cmd في Windows فلا** — بل يمرّر `*.jar` كما هو إلى Java، فلا يجد الملف فيُخطئ.

وفي Windows استخدم حلقة `for` لتحقيق الأثر نفسه:

```bat
@echo off
cd /d "%~dp0"
for %%f in (paper-*.jar) do (
  java -Xms2G -Xmx2G -jar "%%f" --nogui
  goto :done
)
:done
pause
```

استبدل `paper-*.jar` بسابقة نواتك (مثل `leaf-*.jar`)، فلا تحتاج تعديل السكربت عند تحديث الإصدار.
:::

### 3. إعادة تشغيل تلقائية بعد الانهيار

**Windows** (`start.bat`):

```bat
@echo off
cd /d "%~dp0"
:start
java -Xmx4G -Xms1G -jar server.jar nogui
echo تعطّل الخادم، إعادة التشغيل خلال 3 ثوانٍ...
timeout /t 3
goto start
```

**Linux** (`start.sh`):

```bash
#!/bin/bash
cd "$(dirname "$0")"
while true; do
    java -Xmx4G -Xms1G -jar server.jar nogui
    echo "أُوقف الخادم، إعادة التشغيل خلال 3 ثوانٍ..."
    sleep 3
done
```

:::warn فكّر جيدًا قبل الإعادة التلقائية
الإعادة التلقائية تناسب **الخوادم الطويلة بلا إشراف**. لكن إذا فشل الخادم بسبب **خطأ إعدادات** (كإصدار Java خاطئ أو منفذ مشغول)، فسـ**يعيد التشغيل كل 3 ثوانٍ ويغرق الشاشة**، فيغطي الخطأ الحقيقي. **لا تستخدم الإعادة التلقائية في أول تجربة**، بل شغّله يدويًا حتى ينجح.
:::

:::tip systemd أنسب للتشغيل الطويل في Linux
حلقة `while` أعلاه تُقتل عند انقطاع SSH. ولمن يريد **إقلاعًا مع النظام، وإعادة تشغيل بعد الانهيار، واستمرارًا عند خروج SSH**، فإدارة systemd أنسب — راجع الخطوة الخامسة في «تهيئة البيئة (Windows وLinux)».
:::
