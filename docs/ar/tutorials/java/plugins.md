الملحقات هي أكبر قيمة في **خوادم الملحقات** (Paper / Purpur / Spigot وغيرها): تضيف وظائف للخادم دون تعديل العميل ودون أن يثبّت اللاعبون شيئًا.

## أولًا: ميّز الملحق من المود

|  | الملحق | المود |
| --- | --- | --- |
| مكان التثبيت | `plugins/` في الخادم | `mods/` في العميل + الخادم |
| هل يثبّت اللاعب شيئًا | **لا** | عادةً نعم |
| يُستخدم مع | نوى خوادم الملحقات | نوى خوادم المودات (Fabric / Forge / NeoForge) |
| هل يختلطان | **لا**: خادم الملحقات لا يحمّل المودات، وخادم المودات لا يحمّل الملحقات (إلا بخادم مختلط أو حل جسر) |

## ثانيًا: العملية القياسية لتثبيت الملحقات

1. نزّل ملف الملحق بامتداد `.jar`.
2. ضعه في مجلد `plugins/` في الدليل الجذر للخادم.
3. **أعد تشغيل الخادم** (معظم الملحقات لا تدعم التحميل الساخن في المرة الأولى).
4. راقب وحدة التحكم: يطبع الملحق عادةً اسمه وإصداره عند التشغيل، والأخطاء تظهر هنا أيضًا.
5. تحقق من الحالة بالأمر `plugins` (راجع أدناه).

### الحكم على حالة التحميل بالأمر `plugins`

```
plugins          (اختصار: pl)
```

- **الأخضر**: محمّل (تنبيه: يعني فقط أنه **حُمّل هذه المرة**، ولا يعني عدم ظهور أخطاء أثناء التشغيل)
- **الأحمر**: فشل التحميل (تعرّف عليه الخادم لكنه لم يُحمّله، فراجع الخطأ في وحدة التحكم)
- **غائب تمامًا**: الخادم **لم يتعرّف عليه** ملحقًا ← تحقق أن الملف فعلًا في `plugins/`، وأن الامتداد `.jar`، وأن نوع النواة صحيح (كأن ثُبّت مود على أنه ملحق)

## ثالثًا: الملحقات التمهيدية (الاعتماديات)

كثير من الملحقات لا تعمل بذاتها بل تقدّم قدرات مشتركة، و**يجب تثبيتها أولًا** وإلا فشل تحميل الملحق الهدف:

| التمهيدي | ما يقدمه |
| --- | --- |
| **Vault** | واجهة موحدة للاقتصاد / الصلاحيات / الدردشة، وتعتمد عليه ملحقات كثيرة |
| **PlaceholderAPI** (PAPI) | متغيرات نائبة (مثل عرض رصيد اللاعب أو عدد المتصلين)، وحل عام لتبادل البيانات بين الملحقات |
| **ProtocolLib** | قدرة على التعامل مع البروتوكول منخفض المستوى، وتمهيدي لكثير من الملحقات المتقدمة |
| **LuckPerms** | إدارة الصلاحيات، وضبط دقيق لمن يستطيع استخدام أي أمر |

## رابعًا: ملفات الإعداد وYAML

إعدادات الملحقات تكون غالبًا تحت `plugins/<plugin-name>/`، والشائع `config.yml`. وأكثر أخطاء YAML شيوعًا:

- **الإزاحة بالمسافات فقط، لا بـ Tab** (وهذا أكبر مصدر لأخطاء YAML).
- بعد النقطتين مسافة واحدة، مثل `enabled: true`.
- التراتب يُعبَّر عنه بالإزاحة، وإزاحة المستوى نفسه يجب أن تتساوى.

:::warn تشويش النص الصيني
إذا ظهر النص الصيني في ملف الإعدادات مشوّهًا فالسبب غالبًا **أن ترميز الملف ليس UTF-8** (مفكرة Windows تحوّله إلى ANSI/GBK عند الحفظ باسم). استخدم محررًا مثل VS Code واحفظ بترميز **UTF-8**.
:::

### رموز الألوان

نصوص الخادم (MOTD والدردشة ورسائل الملحقات) تستخدم `&` مع حرف للتعبير عن اللون والنمط، مثل:

```
&aأخضر  &cأحمر  &lعريض  &oمائل  &rإعادة ضبط
```

ونطاق الدعم الدقيق يتوقف على إصدار الخادم والملحق.

## خامسًا: كيف يسري التعديل بعد تغيير الإعدادات

| الطريقة | الشرح |
| --- | --- |
| `/<plugin-name> reload` أو `/اختصار-الملحق reload` | تدعمه معظم الملحقات، و**هو الخيار الأول** (مثل `/tab reload`) |
| إعادة تشغيل الخادم | الأضمن، ولا سبيل غيره للملحقات التي لا تدعم التحميل الساخن |
| `/reload` (الأمر الأصلي) | **غير موصى به**، ويسهل أن يخلط حالة الملحقات |

## سادسًا: اختيار الملحقات بحسب الاستخدام

| الاستخدام | الخيارات الشائعة |
| --- | --- |
| الصلاحيات | LuckPerms |
| الوظائف الأساسية (المنزل، النقل، الحزم) | EssentialsX، CMI |
| **الحماية من التخريب والرجوع** | CoreProtect (يسجّل الكتل، فيُعرف الفاعل عند الحادث) |
| حماية المناطق | Residence، Dominion، GriefDefender |
| تحرير العالم | WorldEdit (العصا السحرية)، WorldGuard (حماية المناطق) |
| عوالم متعددة | Multiverse-Core |
| تنسيق الدردشة | TrChat، Carbon |
| القوائم / GUI | DeluxeMenus، TrMenu |
| MOTD وقائمة الخوادم | MiniMOTD |
| الأزياء (ضرورية في الوضع دون اتصال) | SkinsRestorer |
| تسجيل الدخول (الوضع دون اتصال) | AuthMe، LibreLogin |
| التوافق بين الإصدارات | ViaVersion + ViaBackwards |
| إدارة الملحقات الساخنة | PlugManX |

ومجموعة بداية شائعة: **LuckPerms + EssentialsX + CoreProtect + WorldEdit/WorldGuard + Vault + PlaceholderAPI**، ثم أضف بحسب أسلوب اللعب.

## سابعًا: الأمان: للملحقات «سموم» أيضًا

الملحقات **شيفرة طرف ثالث تعمل بصلاحيات الخادم**، وسوء اختيارها خطير جدًا:

- **نزّل من مصادر موثوقة فقط**: قنوات النشر الرسمية (مثل SpigotMC وModrinth وHangar) أو مستودع المؤلف. وملفات jar المتداولة في المنتديات ومجموعات الملفات هي الأخطر.
- **احذر الأبواب الخلفية**: قد يُعاد تعبئة ملحق سليم بشيفرة تنفّذ أوامر عشوائية أو تمنح OP للاعبين معينين أو ترفع ملفات.
- **انتبه لحالة الصيانة**: الملحق غير المحدث منذ زمن والمهجور من مؤلفه قد يُسقط الخادم مع الإصدارات الجديدة.
- **إن لم تكن متأكدًا فجرّب على خادم اختبار**: لا تثبّت ملحقًا مجهول المصدر على الخادم الرئيسي مباشرةً.

:::tip عند حدوث مشكلة اشتبه في الملحقات أولًا
إذا تلعثم الخادم فجأة أو أظهر أخطاء غريبة، **عطّل آخر الملحقات المثبّتة** ثم فعّلها واحدًا واحدًا لتحديد المتسبب — وهذا أسرع بكثير من قراءة السجلات.
:::
