إدارة الخادم اليومية تدور على هذه الأوامر نفسها. و**التنفيذ في وحدة تحكم الخادم لا يحتاج `/`**، أما في مربع الدردشة داخل اللعبة فيحتاج `/`.

## أولًا: التشغيل والإيقاف والحفظ

| الأمر | الوظيفة |
| --- | --- |
| `stop` | **إغلاق آمن** للخادم (يحفظ ثم يخرج). **استخدمه دائمًا للإغلاق، ولا تغلق النافذة مباشرة** |
| `save-all` | حفظ كل بيانات العالم فورًا |
| `save-off` / `save-on` | إيقاف / استعادة الحفظ التلقائي (**قبل النسخ الاحتياطي** أوقفه لتجنّب نسخ حفظ نصف مكتوب) |
| `reload` | إعادة تحميل حزم البيانات وبعض الإعدادات. **بحذر**: قد يخلط حالة الملحقات، فإن أمكن استخدام `reload` الخاص بالملحق فلا تستخدمه |
| `restart` | إعادة تشغيل الخادم (تدعمه بعض النوى) |

:::tip الطريقة القياسية لإغلاق الخادم
`save-all` ثم `save-off` ثم النسخ الاحتياطي ثم `stop`. وإغلاق النافذة مباشرة قد يتلف الحفظ أو يتراجع بالبيانات.
:::

## ثانيًا: إدارة اللاعبين

| الأمر | الوظيفة |
| --- | --- |
| `list` | سرد اللاعبين **المتصلين حاليًا** |
| `kick <玩家> [原因]` | طرد لاعب، و**يمكنه الدخول مجددًا** |
| `ban <玩家> [原因]` | حجب لاعب، و**لا يدخل ما لم يُرفع الحجب** |
| `pardon <玩家>` | رفع الحجب عن لاعب (في الإصدارات القديمة قد يكون `unban`) |
| `ban-ip <IP>` | الحجب بحسب IP (**كل من على هذا IP لا يدخل**، فاستخدمه بحذر) |
| `pardon-ip <IP>` | رفع الحجب عن IP |
| `op <玩家>` | منح صلاحية OP (المسؤول) |
| `deop <玩家>` | سحب OP |

### القائمة البيضاء

```
whitelist on                   فعّل القائمة البيضاء
whitelist add <اللاعب>         أضف لاعبًا
whitelist remove <اللاعب>      أزل لاعبًا
whitelist list                 اعرض القائمة
whitelist reload               أعد القراءة من whitelist.json
```

بعد التعديل بالأوامر تُكتب القائمة في `whitelist.json`؛ وإذا **عدّلت هذا الملف مباشرةً** فتذكّر تنفيذ `whitelist reload` ليُعمَل به.

## ثالثًا: الملحقات والتشخيص

| الأمر | الوظيفة |
| --- | --- |
| `plugins` (الاختصار `pl`) | سرد الملحقات. **الأخضر = محمّل**، و**الأحمر = فشل التحميل** (راجع الخطأ في وحدة التحكم) |
| `version <插件>` | عرض إصدار الملحق |
| `help` | المساعدة |

وإذا لم يظهر ملحق **حتى بالأحمر**، فالخادم لم يعرّفه ملحقًا أصلًا — والسبب عادةً أن الملف لم يُوضع في `plugins/`، أو أن الامتداد خاطئ، أو أن نوع النواة غير متوافق.

### إن أردت إخفاء قائمة الملحقات عن اللاعبين

صلاحيات الأوامر الثلاثة `plugins` و`version` و`help` مفتوحة افتراضيًا للجميع. لإغلاقها اضبط عُقد الصلاحيات التالية على `false`:

```
bukkit.command.plugins
bukkit.command.version
bukkit.command.help
```

:::warn إغلاق الأمر لا يعني إخفاءه
بعض عملاء الغش يستنتجون الملحقات المثبّتة من استجابة **الإكمال التلقائي**. وإن كان الأمر مهمًا فعلًا فيلزم تثبيت ملحق إخفاء إضافي (مثل PluginHide) للتعامل معه.
:::

## رابعًا: أوامر الإدارة الشائعة داخل اللعبة

| الأمر | الوظيفة |
| --- | --- |
| `gamemode <模式> [玩家]` | تبديل نمط اللعب |
| `tp <玩家> <目标>` | النقل |
| `give <玩家> <物品> [数量]` | إعطاء عناصر |
| `time set day` / `weather clear` | ضبط الوقت / الطقس |
| `difficulty <难度>` | تغيير الصعوبة |
| `gamerule <规则> <值>` | تغيير قواعد اللعبة |
| `say <内容>` | بثّ باسم الخادم |
| `whitelist` / `op` وغيرها | كما سبق (وتحتاج OP داخل اللعبة) |

## خامسًا: الصلاحيات والإكمال التلقائي

- الخادم الأصلي يضبط الصلاحيات بـ**مستوى OP**؛ وبعد تثبيت ملحق صلاحيات (مثل LuckPerms) يُنتقل إلى **عُقد الصلاحيات ومجموعاتها** بتحكم أدق وأأمن بكثير من منح OP.
- **الإكمال التلقائي** يكمل الأوامر والمعاملات، وهو أسرع طريقة للتحقق من «هل هذا الأمر موجود أصلًا»؛ ويستطيع اللاعبون استخدامه أيضًا لمعرفة الملحقات المثبّتة (كما سبق).
