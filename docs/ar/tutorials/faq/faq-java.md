هنا مجموعة أكثر الأخطاء والمزالق شيوعًا في مراحل فتح خادم نسخة Java، **ابحث بالعَرَض مباشرةً**. وكل بند مذكور معه الفصل المصدر، فإن احتجت التفصيل فانقر عليه.

## أولًا: لا يبدأ

| العَرَض | السبب | المعالجة | المصدر |
| --- | --- | --- | --- |
| **خروج فوري** بعد البدء، والسجل يذكر EULA | لم توافق على الاتفاقية | غيّر `eula.txt` إلى `eula=true` | [تشغيل الخادم](/tutorials/java/start) |
| `UnsupportedClassVersionError ... class file version 65.0` | **إصدار Java خطأ** (65 = Java 21) | بدّل إلى Java المقابل وفق جدول الإصدارات | [تجهيز البيئة](/tutorials/java/environment) |
| `'java' ليس أمرًا داخليًا أو خارجيًا معروفًا` / `java: command not found` | Java غير مثبّت، أو `PATH` غير مضبوط، أو **النافذة لم تُفتح من جديد** | افحص `PATH`، وأعد المحاولة في طرفية **جديدة** | [تجهيز البيئة](/tutorials/java/environment) |
| نافذة سكربت التشغيل **تظهر وتختفي** عند النقر المزدوج | النافذة تُغلق تلقائيًا بعد الخطأ | أضف `pause` في آخر السكربت، أو شغّله داخل طرفية | [تشغيل الخادم](/tutorials/java/start) |
| `Address already in use` | المنفذ 25565 مشغول | `netstat -ano \| findstr :25565` (Win) / `ss -tlnp \| grep 25565` (Linux) لمعرفة PID ثم أنهِ العملية | [تجهيز البيئة](/tutorials/java/environment) |
| `Could not reserve enough space for object heap` | `-Xmx` يتجاوز الذاكرة المتاحة | قلّل `-Xmx` | [تجهيز البيئة](/tutorials/java/environment) |
| التشغيل الأول يتوقف عند `Downloading mojang_x.x.x.jar` | يجري تنزيل ملفات التشغيل | اصبر؛ وإن طال التوقف على شبكات المنطقة فجهّز وسيلة تسريع | [تشغيل الخادم](/tutorials/java/start) |

## ثانيًا: الآخرون لا يتصلون

| العَرَض | السبب | المعالجة | المصدر |
| --- | --- | --- | --- |
| `telnet` يعمل منك والآخرون لا يتصلون | **ضبطت جدار الحماية المحلي فقط، ولم تفتح مجموعة أمان السحابة** | أضف قاعدة واردة `TCP 25565` في لوحة السحابة | [النشر في بيئة متاحة للجميع](/tutorials/java/deploy) |
| فحص المنفذ يُظهر أنه مغلق | المنفذ لا يُستمع عليه إن **لم يبدأ** الخادم | شغّل الخادم أولًا ثم اختبر | [تجهيز البيئة](/tutorials/java/environment) |
| حوّلت المنفذ في الموجّه المنزلي وما زال لا يعمل | الأرجح **لا يوجد IPv4 عام** | قارن IP منفذ WAN في الموجّه بـ«IP العام لدي»؛ فإن اختلفا فاطلب عنوانًا أو انتقل إلى خادم سحابي أو نفق شبكة | [النشر في بيئة متاحة للجميع](/tutorials/java/deploy) |
| **لاعبو الهاتف لا يتصلون** | فتحت TCP فقط | نسخة Bedrock / العبور بين النسختين يحتاج فتح **UDP 19132** إضافةً | [دعم لاعبي الهاتف](/tutorials/java/mobile) |

## ثالثًا: المسارات والصلاحيات

| العَرَض | السبب | المعالجة | المصدر |
| --- | --- | --- | --- |
| الملحق/المود يشتكي من أخطاء مسارات غريبة | الدليل يحوي **محارف غير لاتينية أو مسافات** | انقله إلى مسار إنجليزي قصير مثل `C:\mcserver` أو `/opt/mcserver` | [بنية الخادم](/tutorials/java/structure) |
| `Permission denied` في Linux | الخادم أُنشئ بـ root، والمستخدم العادي لا يملك صلاحية الكتابة | `sudo chown -R mcserver:mcserver /opt/mcserver` | [تجهيز البيئة](/tutorials/java/environment) |
| تلف الحفظ بعد تعديل ملفات العالم | عدّلت ملفات داخل `region/` يدويًا | **لا تعدّل** ملفات العالم يدويًا، بل استخدم WorldEdit أو ما شابه، أو أوقف الخادم أولًا | [بنية الخادم](/tutorials/java/structure) |

## رابعًا: ما يتعلق بالملحقات

| العَرَض | السبب | المعالجة | المصدر |
| --- | --- | --- | --- |
| بند **أحمر** في `/plugins` | فشل التحميل (تعرّف عليه الخادم لكنه لم يُحمّل) | اقرأ الخطأ في الكونسول، وهو عادةً متطلب مسبق ناقص أو إصدار غير متطابق | [مدخل الملحقات](/tutorials/java/plugins) |
| **لا يظهر حتى الأحمر** في `/plugins` | الخادم **لم يتعرّف عليه** كملحق أصلًا | تحقق هل وضعته في `plugins/`، وهل لاحقته `.jar`، وهل نزّلت نوع النواة الخطأ | [مدخل الملحقات](/tutorials/java/plugins) |
| الملحق يخطئ YAML | **استُخدم Tab في الإزاحة** (وYAML لا تسمح إلا بالمسافات) | استبدله بمسافات | [مدخل الملحقات](/tutorials/java/plugins) |
| النص العربي في الإعداد يظهر مشوّشًا | ترميز الملف ليس UTF-8 | احفظه **UTF-8** من VS Code | [مدخل الملحقات](/tutorials/java/plugins) |
| التعديل لم يسري | يحتاج إعادة تحميل | `/اسم-الملحق reload`؛ وما لا يدعمها لا يبقى إلا إعادة التشغيل (**لا تستخدم `/reload` الأصلي**) | [مدخل الملحقات](/tutorials/java/plugins) |
| تقطيع مفاجئ أو أخطاء غريبة | ملحق ثُبّت حديثًا | **عطّل آخر ملحق ثبّتته** ثم فعّل واحدًا واحدًا للتحديد | [مدخل الملحقات](/tutorials/java/plugins) |

| مخاطر الوضع دون اتصال | يمكن لأي شخص انتحال المعرّف، ويمكن تجاوز الحجب | **لا يُنصح** بإغلاق التحقق الأصلي في الخادم العام | [إعداد الخادم](/tutorials/java/config) |
| هروب المزوّد / حادث مركز البيانات | البيانات على جهاز واحد فقط | **نزّل نسخة احتياطية إلى موضع آخر دوريًا على الأقل** | [النسخ الاحتياطي والاستعادة](/tutorials/java/backup) |
