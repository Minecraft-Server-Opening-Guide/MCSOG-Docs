منظومة نوى Bedrock أصغر بكثير من نسخة Java، والرئيسية أربع فقط:

| النواة | اللغة | الملحقات | في سطر |
| --- | --- | --- | --- |
| **BDS** | C++ | تحتاج محمّلًا مجتمعيًا | الخادم الرسمي، و**أفضل توافقًا** |
| **Nukkit (NK)** | Java | أصلية | خفيف، كأنه Bukkit نسخة Bedrock |
| **PowerNukkitX (PNX)** | Java | أصلية | الوريث الحديث لـ Nukkit، مع **تحسين تعدد الأنوية** |
| **PocketMine-MP (PMMP)** | PHP | أصلية | منظومة ملحقات ضخمة، ويُكتب بـ PHP |

> وللمقارنة الكاملة بندًا بندًا (الأداء والملحقات والمنظومة وحالات الاستخدام) انظر قسم «مقارنة نوى Bedrock» في **[مقارنة نوى الخادم](/wiki/compare#mcsog-h-%E5%9F%BA%E5%B2%A9%E7%89%88%E6%A0%B8%E5%BF%83%E5%AF%B9%E6%AF%94)**.

## أولًا: BDS (الرسمي)

خادم Bedrock الرسمي الذي يوفّره موقع Minecraft، وهو في الصفحة نفسها مع Vanilla في نسخة Java.

**المزايا**

- **دعم رسمي**: يتحدّث مع المسؤولين، وأفضل توافقًا مع عميل الأحدث؛
- **الاستقرار**: منتج رسمي وتشغيله موثوق؛
- **استخدام الموارد**: محسّن لنسخة Bedrock، ويستفيد من موارد الخادم بكفاءة؛
- **تحديثات الأمان**: يصدر المسؤولون إصلاحات الأمان بوتيرة أعلى.

**العيوب**

- **لا يدعم الملحقات**: الخادم الرسمي نفسه بلا منظومة ملحقات، وتثبيتها لا يبقى إلا بـ**محمّل ملحقات مجتمعي**؛
- **عنق الخيط الواحد**: **حساب الكائنات يجري على خيط واحد**، فالسلاسة **تعتمد أساسًا على أداء نواة المعالج الواحدة**؛ وكلما كبرت الخريطة زاد التقطيع، وهو عمومًا أقل من خادم Java الذي يدعم تعدد الأنوية؛
- **غياب الوظائف المتقدمة**: توليد العالم المخصص وإدارة الصلاحيات المتقدمة يحتاجان طرفًا ثالثًا عادةً؛
- **نمو الذاكرة البطيء**: الاستهلاك يزيد تدريجيًا، ويشتد فيظهر كتسريب ذاكرة. وانتبه إلى أن **تنظيف الذاكرة قسرًا يجعل شريط تقدّم تنزيل اللاعبين لحزم المواد/الإضافات يتوقف**، ولا يبقى إلا إعادة تشغيل الخادم.

**يناسب**: الخوادم التي تريد دعمًا رسميًا وتوافقًا ولا تحتاج تخصيصًا معقّدًا. **وهو الخيار الأول لخوادم البقاء**.

## ثانيًا: Nukkit (NK)

«Bukkit» نسخة Bedrock — مكتوب بـ **Java**، ومنظومته وفكرة تطويره شبيهتان بجهة ملحقات نسخة Java.

**المزايا**: خفيف (متطلبات موارد منخفضة)، وأداؤه جيد، و**له منظومة ملحقات أصلية**، وعابر للمنصات (Windows/Linux/macOS)، والبدء به سهل.

**العيوب**: **تأخّر التحديثات** (قد لا يلحق الأحدث وأحدث الخصائص)، ومنظومة ملحقاته أصغر من Spigot/Paper، وتحسين تعدد الأنوية فيه ناقص، والتوثيق عالي الجودة قليل، والمشاريع المفتوحة المصدر قد تظهر فيها مشكلات استقرار.

**يناسب**: المبتدئين والخوادم الصغيرة. **وانتبه**: Nukkit الأصلية صارت غير نشطة، والواقع أن فرعه الحديث أوصى (انظر أدناه).

## ثالثًا: PowerNukkitX (PNX)

**الوريث الحديث** لـ Nukkit، وهو الآن الفرع الرئيسي بين نوى Bedrock من طرف ثالث.

**المزايا**

- **يدعم أحدث بروتوكول Bedrock**، فيلحق الإصدارات الجديدة؛
- **تحسين تعدد الأنوية**: وهذه أكبر ميزة له على BDS وNukkit القديمة؛
- **ارتفاع عالم 384 كتلة**؛
- مولّد تضاريس **Terra** مدمج، لتضاريس غنية؛
- **مفتوح المصدر بالكامل وAPI مفتوح**، ويدعم كتابة الملحقات بلغات JVM مثل Java / Kotlin / Scala / Python / JavaScript / Lua؛
- **متوافق مع كثير من ملحقات منظومة Nukkit**.

**العيوب**: يتأثر إيقاع التطوير بتغيّرات فريق Nukkit الأصلي؛ ومنظومته ما زالت أصغر من خوادم Java الرئيسية؛ وكثرة الملحقات ترفع كلفة تعلّم المبتدئ.

**يناسب**: المالكين الذين يريدون **أداءً عاليًا + تخصيصًا عاليًا**.

## رابعًا: PocketMine-MP (PMMP)

خادم Bedrock مكتوب بـ **PHP**، وله أكبر منظومة ملحقات.

**المزايا**: منظومة ملحقات ضخمة، وعابر للمنصات، و**عتبة PHP منخفضة** (من يعرف PHP يكتب الملحقات)، ومجتمع نشط، ودرجة تخصيص عالية.

**العيوب**: **عنق أداء عند حمل اللاعبين العالي** (إدارة الذاكرة وكفاءة المعالج)؛ وتأخّر التحديثات؛ وتراجع الاستقرار مع عدة ملحقات؛ وPHP لغة تفسيرية فـ**استهلاك الموارد أوضح**؛ ويحتاج تعلّمًا للإعداد وإدارة الملحقات.

**يناسب**: المالكين الذين يقدّمون **وظائف الملحقات والتخصيص** ويقبلون بعض المقايضة في الأداء.

## خامسًا: كيف تختار

```
تريد الاستقرار + التوافق الرسمي + البقاء الأصلي
   → BDS، وإن أردت الملحقات فمع محمّل مجتمعي (انظر «خادم BDS»)

تريد أداءً عاليًا + تعدد أنوية + تخصيصًا عاليًا
   → PowerNukkitX

تريد أكبر منظومة ملحقات وتتقن PHP
   → PocketMine-MP

تريد البدء ببساطة واللعب في منظومة Nukkit
   → عائلة Nukkit (لكن قدّم الفرع النشط)
```

:::tip تحقّق بأصغر نطاق أولًا
بعد اختيار النواة، **شغّلها على نطاق صغير** (بضعة لاعبين وملحقات قليلة) قبل الإعلان. فمزالق توافق نوى Bedrock أكثر من نسخة Java، فلا تبدأ بالطقم الكامل من أول مرة.
:::
